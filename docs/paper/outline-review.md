## 7. 승인 요청 항목

controller 가 사용자에게 확인해야 할 세 가지를 질문 형태로 정리한다.

**(a) §1 의 논지 순서에 동의하는가?**
현재 순서는 P1(검증 안 된 전제) → P2(51.7% 무손실 감소) → P3(기존 계보의 두 한계) →
P4(뉴런 사용 차이 13.1%, 등가성은 동기 서술로만, 핵심 관찰) → P5(실기/침묵뉴런, G7·G5 게이트) →
P6(기여 3개). 이 순서는 "얼마나 발화하는지 모른다 → 절반은 줄여도 된다 → 왜 기존
방법으로는 안 되는가 → 우리가 보는 것은 곡선이 아니라 내부 상태다 → 실기에서는? →
그래서 기여는" 흐름이다. **질문: 이 순서로 확정해도 되는가, 아니면 P3(관련 연구
한계)을 P1 직후로 당겨 동기를 먼저 세우는 편이 나은가?**

**(b) §2 소절 구성과 분량에 동의하는가?**
6개 소절(2.1 직접 학습, 2.2 스파이크 규제[가장 중요, 10~11줄], 2.3 가지치기/선점
대응[9줄], 2.4 보조 손실 균형[G4 조건부, 미완 시 §5 로 이동], 2.5 에너지 회계[G7
조건부], 2.6 측면 억제[동기 서술 전용, 4~5줄])로 구성돼 있다. **질문: (i) 2.4 를
G4 완료 전까지 §2 에 남겨 둘지 지금 바로 §5 로 옮길지, (ii) 2.6 을 §1 P1 으로 합치고
소절 자체를 없애는 스펙의 대안(넘칠 경우)을 지금 채택할지 여부를 확정해 달라.**

**(c) 기각한 세 주장(plain L2 대비 정확도 우위 / WTA·측면억제가 일어난다 / 전 층
집중)에 여전히 동의하는가?**
2026-09-14 스펙 §3 에서 이미 명시적으로 기각됐고, 이번 검토(§3 항목)에서 개요 전체를
훑어 위반 사례가 0건임을 확인했다. **질문: 이 세 기각을 그대로 유지해 영문 초고에
