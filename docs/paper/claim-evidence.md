# 주장–증거 대조표 (Task 6, 2026-09-14)

`docs/paper/outline-ko.md` 전체(§1–§6)에서 **[주장] 으로 태그된 줄만** 모은다. §2·§4.1·§5·§6

과거형 재서술) 여기 포함되지 않는다 — 브리프 Step 7 의 스코프 그대로다.
