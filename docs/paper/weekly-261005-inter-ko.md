# 주간 정리 (09-29 ~ 10-05): 경쟁 범위로 ours_inter_ch 채택

기준: R19, T=4. 정확도는 val acc, 스파이크는 test 샘플당 스파이크 수. 모든 수치에 n 을 붙인다 (시드 수). 시드 간 정확도 SD 는 C10 0.10%p, C100 0.22%p — 이보다 작은 차이는 판정하지 않는다. 원장 10-05 집계.

## 1. 요약

- 세 경쟁 범위(intra / layer / inter) 중 **ours_inter_ch(채널끼리 경쟁)** 를 제안법으로 정한다 (10-05 결정).
- 근거 ①: C10 320~345K 대역(스파이크 −30%)에서 baseline 평균(96.73)에 붙어 있는 것은 inter(342K, 96.74, n=3) 하나뿐이다. 같은 대역의 BPSR 96.66 · intra w¹ 96.61 · layer w¹ 96.61 · plain L2 96.55 (각 n=3). 스파이크로 보정하면 다른 팔 합동보다 +0.076%p (95% CI [0.007, 0.144], p=0.031, n=35 중 inter 9). 단 이 대역은 결과를 보고 고른 것이고 팔별 비교는 다중비교 보정 후 유의하지 않다 → 미리 정한 비교점(340K)에서 시드를 늘려 확정할 예정.
- 근거 ②: 같은 스파이크에서 죽은 채널 제거로 줄일 수 있는 MACs 가 다른 팔 합동보다 +2.3%p (300~420K, [+1.3, +3.3], p<0.001). 제거 시 정확도 변화는 0.00 (28런, 제거 채널은 테스트에서 한 번도 발화하지 않음 — 구조상 0).
- 한계: ~300K(−38%) 아래에서는 inter 가 다른 팔보다 0.16~0.24%p 낮다 (inter 점은 n=1). 주장 범위는 n=3 이 있는 302~405K(−17~−38%). C100 은 inter 가 전부 n=1 이라 판단 불가.
- inter 위에 얹어 본 요소(늦은 시작, Taylor 채널 중요도, 가중 모양 변경)는 모두 같은 스파이크 기준 곡선과의 차이를 검출하지 못했다.
- 상세 통계: `analysis/inter_deep_261005.md` (A~H 절).

## 2. 세 경쟁 범위

| 이름 | 코드 플래그 | 겨루는 상대 | 가중 w |
|---|---|---|---|
| ours_intra_ch | within_channel | 같은 채널 안의 다른 위치 | 1 − (위치 스파이크 / 채널 안 최대) |
| ours_layer | none | 층의 모든 뉴런 | 1 − (뉴런 스파이크 / 층 최대) |
| ours_inter_ch | channel | 다른 채널 | 1 − (채널 스파이크 합 / 최대 채널 합), 채널 안에서는 같은 값 |

공통: 규제 항 λ·‖spike ⊙ w‖₂, λ 는 loss-ratio(λ = ρ·L_task/R)로 자동, vmem readiness, final_step, wta_rev 기울기.

### 4-1. −30% 구간에서 baseline 정확도를 유지하는 것은 inter 뿐

| 대역 | 방법 | 스파이크 | val acc | n |
|---|---|---|---|---|
| ~400K | ours_inter_ch | 405K | 96.75 | 3 |
| | ours_intra_ch (w¹) | 401K | 96.75 | 2 |
| | BPSR | 412K | 96.73 | 3 |
| | plain L2 | 388K | 96.73 | 3 |
| **320~345K** | **ours_inter_ch** | **342K** | **96.74** | 3 |
| | BPSR | 319K | 96.66 | 3 |
| | ours_intra_ch (w¹) | 324K | 96.61 | 3 |
| | ours_layer (w¹) | 334K | 96.61 | 3 |
| | plain L2 | 326K | 96.55 | 3 |

- 400K 근처(−17%)에서는 모든 팔이 baseline(96.73 ± 0.10, n=6)과 같다. −30% 까지 내려와도 baseline 평균에 붙어 있는 것은 inter 하나다.
- 통계 (시드 단위 ANCOVA, acc = a_팔 + b·ln 스파이크): 320~420K 에서 inter − 다른 팔 합동 +0.076%p [0.007, 0.144], p=0.031. 팔별로는 ours_layer (w¹) +0.094 (p=0.034) 가 가장 크지만 Holm 보정 후 최소 p=0.138.
- 약점: (1) 대역 사후 선택 — 250~420K 로 넓히면 +0.044 (p=0.117), 180~420K 면 −0.008 (p=0.79). (2) 체크포인트 — 최고 에폭 대신 마지막 에폭이면 +0.052 (p=0.199). (3) 차이 0.076 은 시드 SD(0.112)보다 작다.
- 그래서 "inter 가 다른 팔보다 높다"가 아니라 "**−30% 에서 baseline 정확도를 유지하는 유일한 팔**"로 말하고, 340K 를 미리 정한 비교점으로 시드를 늘려 확정한다.

### 4-4. 분포 지표와 정확도의 관계

[그림 붙일 자리: EIP_fig/inter_deep_resid_ko_26-10-05.png]

- npz (테스트 1만 장, 뉴런별 발화) 기준 inter 는 같은 스파이크에서 죽은 채널이 가장 많고 (plain L2·BPSR 대비 +44~48, p<0.001) 50% 집중도가 가장 낮다 (스파이크 절반을 내는 뉴런 비율, 15.5% vs 16.7~19.1%).
- 그러나 같은 팔·같은 스파이크 안에서는 죽은 채널이 많은 런일수록 정확도가 낮았다 (부분상관 r=−0.38, p=0.017, n=40). 따라서 "채널을 더 죽여서 정확도가 높다"는 데이터가 지지하지 않는다 (시드 간 관찰 상관이라 인과로 읽지 않는다). 채널 죽음은 정확도와 별개인 구조적 이득으로 본다 (4-3).
- 층 배분·SynOps: ~340K 에서 감소분의 conv2 비중 68~71%, 스파이크당 SynOps 차이 1.3% 이내 — 팔 간 거의 같다.

### 4-5. 한계

- ~300K 아래에서 inter 가 꺾이는 기전은 모른다. "채널을 통째로 끄는 것 말고는 줄일 방법이 없어서"라는 이전 설명은 틀렸다 — inter 의 스파이크 감소 중 채널 사망 몫은 9.3% ± 2.1 (n=19)이고, 300K 아래 사망 가속은 ours_layer (w¹)·BPSR 에도 있다.
- C100: inter 4점 모두 n=1 (250~420K 에서 inter − 나머지 +0.003 [−0.227, +0.232]). 0.15%p 차이를 검정력 80% 로 보려면 팔당 약 24런.
- 정확도는 val=test 1만 장의 최고 에폭이다. 마지막 에폭 기준 결과를 함께 보고한다.

| plain L2 + loss-ratio | 96.87 @360K, 96.51 @396K, 96.64 @339K, 96.50 @267K (각 n=1) | plain L2 곡선 위 |
| 경쟁 범위 intra / layer | 4장 표 | inter 보다 낮음 (높은 구간) |

공통 결론: 가중의 **모양**을 바꾸면 R 이 함께 바뀌고 loss-ratio 가 λ 로 되갚아서, 같은 ρ 에서의 착지점(ρ 눈금)만 움직이고 정확도–스파이크 곡선은 그대로다. 경쟁 범위(inter)도 곡선 **전체**를 올리지는 못했다 (250~420K 팔 효과 F p=0.59, 하이퍼볼륨 차 0). inter 가 바꾼 것은 곡선의 **모양**(−30% 까지 평평, ~300K 아래 꺾임)이다.

### 5-4. 진행 중 (수요일 결과)
- inter 어블레이션 4개 (− vmem / − final_step / − 1− 반전 / − loss-ratio), 각 n=1, ~340K 착지 목표
- 끝 구간 규제 해제 (마지막 40 에폭 λ=0): inter 3e-3, 2e-3
- inter × intra 곱 가중 (전환 없이 전 구간을 덮는 시도): ~340K, ~240K
- Suetake 벌점 재현 (아래 6장), QKFormer C10·C100 inter (GPU 대기)

## 6. 우리와 비슷한 방법들

공통 주의: CIFAR 에서 샘플당 스파이크 수를 표로 낸 논문은 없다 (모두 발화율·SOPs·에너지·평균 T). 모델·T 도 달라 논문 수치를 그대로 같은 표에 놓을 수 없다. 그래서 가까운 것은 우리 코드로 같은 조건(R19 T=4)에서 재현한다.

| 방법 | 무엇을 하나 | 우리와 비슷한 점 | 다른 점 | 수치 (논문) |
|---|---|---|---|---|
| **Suetake et al.** (arXiv 2302.01500, TMLR 2024 추정) | 손실에 Σ ψ·s, ψ = 뉴런의 fan-out (시냅스 연산 = 에너지에 비례) | 스파이크 벌점 항 하나, 모델 그대로 — 가장 가까운 선례 | 가중이 층별 상수(경쟁 없음), λ 수동 격자, T=1 | R18 C10: 91.32 → 91.40 @ 에너지 −42% (n=3) |
