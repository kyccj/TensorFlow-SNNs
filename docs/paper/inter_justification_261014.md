## 1. 결론

**inter 의 근거는 구조다. 같은 스파이크에서 균등 규제(BPSR, plain L2)보다 채널을 통째로 더 끄고, 그래서 밀집 연산에서 지울 수 있는 몫이 크다. 정확도 우위와 "경쟁 범위로서 intra·layer 보다 낫다"는 지금 데이터로 주장할 수 없다.**

채택 경위도 함께 적어 둔다.
- 09-19 에 `ours_ch` 는 "곡선 위, 팔 종료" 로 닫혔다 (각 n=1, `decisions.md:161-164`).
- 그 뒤 시드가 추가된 근거는 decisions.md 에 없다.
- 10-05 에는 결과를 보고 고른 구간(320~345K)에서의 baseline 유지를 근거로 사용자가 inter 를 택했다. 그때 검토자는 intra 를 권했다.
- 따라서 논문에서는 inter 를 "사전에 정한 최선의 범위" 로 쓰지 않는다. "구조적 희소성을 목표로 고른 범위" 로 쓴다.

### 주장 계층

**A. 강함 — 경계 문구와 함께 쓸 수 있다**

1. **(코드 사실)**
   - inter 는 이미지마다 같은 층 채널의 공간합 순위로 가중을 매긴다.
   - 실효 기울기는 λ·w²/R_l 이다. 서로게이트 창 안의 침묵 뉴런에도 걸리고, 1등 채널은 면제된다.
2. **(R19 C10, 같은 스파이크, 균등 규제 대비) 줄이는 방식이 다르다.**
   - BPSR·plain L2 는 채널 활동 분포의 모양을 그대로 두고 크기만 줄인다. 발화 뉴런당 스텝을 깎는다.
   - inter 는 분포를 넓히고 뉴런·채널을 끈다.
3. **(R19 C10, 300~420K, 균등 규제 대비) 지울 수 있는 연산이 많다.**
   - 죽은 채널은 BPSR 보다 +49/4,736, plain L2 보다 +56 많다.
   - 밀집 MACs 제거는 +3.4%p / +4.1%p 더 크다.
   - 함께 적을 것: baseline 자체가 이미 MACs 19.4% 를 지울 수 있다. SynOps 이득은 없다. 실기 측정이 없다.
4. **(학습 비용)** 다른 경쟁 범위 팔과 스텝당 시간이 같다. 고를 이유가 아니라 불리함이 없다는 근거다.

**B. 약함·조건부 — 단서와 함께, 부록이나 보조 문장으로만**

5. **−30% 에서 baseline 과 동등.**
   - inter ρ 3e-3 은 96.72 ±0.12 (n=4) 이고 baseline 은 96.73 ±0.10 (n=6) 이다. 90% 구간은 [−0.15, +0.13]%p 다.
   - 함께 적을 것 1: 다른 팔도 ±0.2 마진이면 더 깊은 감소에서 동등하다. 예: ours_intra_ch (w²) −52%, n=7.
   - 함께 적을 것 2: 축에 따라 감소율이 다르다. s_count 축에서는 −30.1% 이고 npz 축에서는 −27~−28% 다.
6. 이미지당 활성 뉴런이 균등 규제보다 5.7~6.7% 적다 (n=36).
   - 단, 이것은 maxnorm 계열(inter·intra·layer) 공통 성질이다.
   - 다른 경쟁 범위 대비 차이는 1~2.5% 뿐이다.
7. **상위 채널 활동은 줄지 않는다.**
   - BPSR 은 상위 1% 채널을 −14% 줄이고, inter 는 +6.5% (p=0.076) 다.
   - "유지" 까지만 쓰고, "증가" 는 쓰지 않는다.
8. **스파이크 감소 방향은 R19·QK·VGG-DVS·SDT-V3 에서 같다.**
   - 함께 적을 것: 과제가 어려울수록 무손실 폭이 준다. DVS·SDT 는 n=1 이다. 경쟁 범위 비교는 R19 에만 있다.
9. **ρ→스파이크 대응이 C10↔C100 에서 그대로 옮겨진다.**
   - loss-ratio 의 성질로 쓴다. ours_layer (w¹) 도 옮겨진다. inter 고유 성질이 아니다.

**C. 쓰면 안 되는 문장**

- 같은 스파이크 정확도에서 다른 팔(BPSR 포함)보다 높다. 같은 정확도에서 스파이크가 적다. "BPSR 대비 −17%" 도 여기에 해당한다.
- "−30% 에서 무손실인 유일한 방법"
- 경쟁 범위로서 inter 가 ours_intra_ch·ours_layer 보다 낫다. 높은 구간 비교에는 w² 와 w¹ 의 차이가 섞여 있다.
- 채널을 죽이는 것이 정확도 이점의 원인이다. 팔 안에서는 반대 방향이다.
- "강한 채널은 더 강해진다", "죽음/생존 두 끌개"
- SynOps·이벤트 구동 하드웨어 에너지 이득
- 트랜스포머·DVS·ImageNet 에서의 구조 이득. 재지 않았다.
- 생물학적 근거 (측면 억제·정규화). 서론에서 영감 수준으로만 쓸 수 있다.
- "채널 경쟁 가중은 새롭다". 선행이 있다 (FBS, SASL, Polarization).
- 뉴런 희소성을 헤드라인으로 쓰는 것. UPR 은 뉴런 21% 만 남긴다.

## 3. 기전

### 3.1 식 (코드 기준: `lib_snn/neurons.py:1019-1033, 1132-1182`, `lib_snn/layers.py:2023-2074`)

층 l, 이미지 b, 채널 k, 위치 p, 스텝 t.

```
S_{b,k,p} = Σ_t s_{b,k,p,t}                                   (final_step: t=T 에서 한 번 계산)
c_{b,k}   = Σ_p [ S_{b,k,p} + 1(S_{b,k,p}=0)·clip(V_{b,k,p}/V_th, 0, 1) ]     (vmem)
x_{b,k}   = c_{b,k} / max_j c_{b,j},     w_{b,k} = 1 − x_{b,k}               (stop-gradient)
R_l       = ‖ S_l ⊙ w_l ‖₂               (배치·층 전체에 하나)
L         = L_CE + λ Σ_l R_l,            λ = ρ · L_CE / Σ_l R_l             (stop-gradient)
```

실제 역전파는 이렇다. `wta_rev` 가 정상 L2 기울기 S·w²/R_l 에서 S 를 1 로 바꾼다. 곱셈 S·w 는 custom_gradient 바깥에 있어서 연쇄법칙으로 w 가 한 번 더 곱해진다.

```
∂L/∂S_{b,k,p} = λ · w_{b,k}² / R_l = ρ·L_CE · (1 − x_{b,k})² / (Σ_l R_l · R_l)
→ 막전위로는 × σ'(V)   (R19: asym 서로게이트, |V − V_th| ≤ 0.5 안에서만 0 이 아님)
```

이 식에서 세 가지가 나온다.
- **스파이크 하나에 매기는 단가가 고정이다.** 단가는 채널 순위로만 정해지고, 발화한 뉴런과 창 안의 침묵 뉴런이 같은 단가를 받는다.
- **w 전체의 배율은 의미가 없다.** w → αw 로 바꾸면 R_l, ΣR, λ 가 상쇄되어 단가가 그대로다. 의미가 있는 것은 w 의 모양, 곧 채널 사이 상대값뿐이다. 09-19 의 "R 팽창" 진단과 같은 대수다.
- **이 방법은 forward 손실을 최소화하는 방법이 아니다.** backward 가 forward L2 의 기울기와 다르므로, 논문 Method 에는 실제 backward(w²)를 적는다.

### 3.2 왜 채널을 통째로 끄는가

채널 k 의 모든 위치는 같은 단가 a_k = (λ/R_l)(1 − x_k)² 를 받는다.
- 1등 채널은 a=0 이다.
- 완전히 침묵한 채널은 a 가 최대다.
- inter 3e-3 (n=3) 의 산 채널 x 중앙값은 0.234 다. 그래서 죽은 채널 : 중앙 채널 : 1등 채널의 단가는 약 1 : 0.59 : 0 이다.

conv 채널은 필터와 BN 이동량을 공유한다 (BN 은 추론 때 conv 에 접힌다). 그래서 한 채널에 걸린 단가가 공유 매개변수에 같은 방향으로 쌓인다.

다른 범위와 비교하면 이렇다.

| 범위 | 순위 단위 | 채널 강약 신호 | 1등 면제 대상 |
|---|---|---|---|
| inter | 같은 층 채널의 공간합 | 있음 (채널 전체가 같은 w) | 이미지마다 층의 1등 채널 하나 |
| ours_intra_ch | 같은 채널 안 위치 (w_p = 1 − S_p / max_p S_p) | **없음.** 채널 전체 배율에 불변이라 강한 채널과 약한 채널이 같은 가중 모양을 받는다 | 채널마다 1등 위치. 코드 주석 "no channel can be wiped out" (`neurons.py:971`) |
| ours_layer | 층의 모든 뉴런 | 간접적. 약한 채널의 뉴런도, 강한 채널의 약한 뉴런도 w≈1 | 층의 1등 뉴런 하나 |
| BPSR [Yan 2022] | 없음 (균등) | 없음. 기울기 λ·s 가 발화 사건(s=1)에만 걸린다 | — |
| plain L2 | 없음 (균등) | 없음. 기울기 ∝ S, 침묵 뉴런 0 | — |

측정이 이 구분과 맞는다.
- BPSR 은 분포 모양(CV)을 λ 와 무관하게 보존한다 (E4).
- inter 는 ρ 에 따라 단조로 넓힌다 (E4).
- 상위 채널은 유지하고, 하위 채널의 몫은 작다 (E6·E7).
- ours_layer 는 inter 와 구조 지표가 가장 가깝다 (E9). 순위 단위가 채널에 가장 가까운 팔이라는 위 표와 맞는다.

### 3.3 왜 그것이 구조적 연산 절감인가

가중치 층의 입력 채널 중 죽은 비율을 δ_in, 출력 채널 중 죽은 비율을 δ_out 이라 하자. 지울 수 있는 밀집 MACs 비율은 다음과 같다 (`analysis/prune_measure.py`).

```
δ_in + δ_out − δ_in·δ_out
```

죽은 채널 하나가 두 층(자기 필터, 다음 층의 입력 조각)에서 연산을 줄인다.

반면 채널이 살아 있는 한, 위치 단위 희소(intra)나 뉴런 단위 희소(layer, BPSR)는 밀집 연산에서 아무것도 지우지 못한다. 이벤트 구동 연산(SynOps)에서는 이 구분이 없어서 팔 사이 차이가 0.4% 이하다 (E17). 따라서 inter 의 이점은 **밀집 연산과 가중치 메모리**에 한정된다.

### 3.4 이론이 말하지 않는 것 (반론 반영)

- **"죽음/생존 두 끌개" 는 기각한다.**
  - 채널 공유 매개변수에 걸리는 힘은 "단가 × 서로게이트 창 안 뉴런 수 × 서로게이트 높이" 다.
  - 채널이 깊이 침묵할수록 창 안 뉴런이 0 으로 가므로, 힘도 BPSR 처럼 0 으로 간다.
  - 데이터에서도 inter 고유의 양봉은 없다. 죽은 채널과 겨우 산 채널의 간극은 baseline 에도 있다 (333 vs 17, n=3).
  - 채널 사망은 inter 스파이크 감소의 9.3% ±2.1 (n=19) 뿐이다 (인용). 감소의 대부분은 산 채널 안의 연속적인 감소다.
- **"오목 벌점" 은 비유다.** M = max c 와 R_l 을 고정했을 때 단가를 적분한 꼴일 뿐이다. SCAD·MCP 의 이론적 보장을 빌려올 수 없고, eip-refs 검증 전에는 인용하지 않는다.
- **vmem 의 역할.** 문턱 근처 침묵 채널의 단가를 낮춘다는 것까지는 코드 경로다.
  - 측정된 것: 같은 ρ 에서 −4.3% 덜 줄인다 (n=17/8, 인용).
  - "죽은 채널을 되살린다" 는 측정하지 않았다. 죽은 채널은 654 (n=1) vs 638 ±9 (n=3) 로 구분되지 않는다.

## 5. Method 동기 단락 초안

인용 표기는 [저자 연도] 다. 정확도 우위, 생물학 근거, "새롭다" 는 넣지 않았다. 수치 문장은 실험 절로 보내고, 동기 단락은 설계 논리만 쓴다.

**English draft.**

> Uniform activity penalties such as the squared spike-count penalty of BPSR [Yan 2022] or a plain L2 penalty push every neuron down in proportion to its own activity. Their gradient is nonzero only where a spike occurs, so they shorten firing but leave the relative distribution of activity across channels essentially unchanged. A convolutional channel, however, is the unit that shares one filter and one normalization; a channel that never fires can be removed together with its filter and the corresponding input slice of the next layer, which shrinks dense compute in two layers at once. Uniform penalties give no reason for any particular channel to fall silent. We therefore weight the spike penalty by each channel's rank within its layer: for every image, a channel's spatially summed activity c is divided by the largest channel's activity, and its spikes are penalized with weight w = 1 − c/max c. The most active channel is left unpenalized, and weaker channels pay a higher price per spike. This mirrors rank-dependent and polarizing penalties used for structured pruning in non-spiking networks, which act on normalization scales or gates [Zhuang 2020; Shi 2020; Gao 2019]; here the weighting acts directly on spike counts during training. Structured sparsity of this kind translates into actual speedups on dense hardware [Wen 2016; Liu 2017]. The benefit is specific to dense execution: under event-driven accounting (SynOps), it is not expected to differ from uniform penalties.

**한국어 번역.**

> BPSR 의 스파이크 수 제곱 벌점 [Yan 2022] 이나 plain L2 같은 균등 활동 벌점은 모든 뉴런을 각자의 활동에 비례해 끌어내린다. 기울기는 스파이크가 난 곳에서만 0 이 아니다. 그래서 발화는 짧아지지만, 채널 사이 활동의 상대 분포는 거의 그대로 남는다. 그런데 컨볼루션 채널은 필터 하나와 정규화 하나를 공유하는 단위다. 한 번도 발화하지 않는 채널은 그 필터, 그리고 다음 층의 해당 입력 조각과 함께 지울 수 있다. 그러면 두 층의 밀집 연산이 한꺼번에 준다. 균등 벌점에는 특정 채널이 침묵할 이유가 없다. 그래서 우리는 스파이크 벌점에 층 안 채널 순위로 가중을 건다. 이미지마다 채널의 공간합 활동 c 를 가장 활동적인 채널의 값으로 나누고, 그 채널의 스파이크에 w = 1 − c/max c 의 가중을 매긴다. 가장 활동적인 채널은 벌점을 받지 않고, 약한 채널일수록 스파이크 하나에 더 높은 값을 치른다. 이는 비스파이킹 망의 구조적 가지치기에서 정규화 스케일이나 게이트에 거는 순위 의존·분극 벌점 [Zhuang 2020; Shi 2020; Gao 2019] 과 같은 방향이다. 다만 여기서는 가중이 학습 중 스파이크 수에 직접 걸린다. 이런 구조적 희소성은 밀집 하드웨어에서 실제 가속으로 이어진다 [Wen 2016; Liu 2017]. 이 이점은 밀집 실행에 한정된다. 이벤트 구동 기준(SynOps)에서는 균등 벌점과 차이가 없을 것으로 본다.

인용 상태 (`refs-audit.md`)
- 본문 확인: Gao 2019 = FBS, ICLR. Wen 2016 = SSL. Liu 2017 = Network Slimming.
- 초록 수준: Zhuang 2020 = Polarization, NeurIPS.
- 서지 미확정: Shi 2020 = SASL (arXiv 2003.05891, TCSVT 수락만 확인).
- Yan 2022 = BPSR (Front. Neurosci. 16:760298).
- Method 에 함께 적을 실제 backward(λ·w²/R_l)와 서로게이트 창 조건은 3.1 의 식을 쓴다.

## [LIMITATION]

- **경쟁 범위 효과를 분리하지 못했다.** R19 C10 높은 구간의 정확도 비교는 w² 판 ours_intra_ch / ours_layer 가 거의 없어 가중 지수 효과와 섞여 있다. 0.1%p 대의 정확도 차이는 조건당 n≤4 로 확정할 수 없다.
- **구조 지표의 범위가 좁다.**
  - R19 C10 의 테스트 1만 장 추론 1회와 밀집 MACs 계산뿐이다.
  - 실기 지연·에너지가 없고, C100·QK·DVS·SDT-V3 의 구조 지표가 없다.
  - ours_layer 대비 구조 우위는 모형 설정에 따라 부호가 바뀐다.
- **순위별 분석은 분포 비교다.** 데이터셋 전체 채널 합으로 순위를 매겼는데, 규제가 실제로 쓰는 것은 이미지별 순위다. 같은 채널을 추적한 것도 아니다.
- **동역학은 관측하지 않았다.** 에폭별 채널 기록이 없어 채널 사망 시점, 흡수, 되살아남을 보지 못했다. 3.2~3.4 의 해석은 코드 경로와 학습 끝 시점 분포에 기댄다.
- **스파이크 축이 팔마다 다르다.** npz/s_count 비가 팔마다 1.053~1.112 로 다르고 원인이 풀리지 않았다. 감소율은 축에 따라 1~2%p 달라진다.
- **재계산하지 않은 인용 값이 있다.** 10-05 마지막 에폭 민감도, 채널 사망 몫, 팔 안 r=−0.38, vmem 효과, 세종 학습 시간, SDT-V3 마지막 20에폭 평균은 문서에서 인용했다.
- **교란이 남아 있다.**
  - ours_intra_ch (w²) 3e-3 n=7 은 전부 138 서버의 9월 런이다.
  - 학습 시간은 런마다 돈 시각이 달라 서버 부하가 섞여 있다.
  - 1-softmax·Suetake 는 저구간 n=1~3 이라 이 비교에 넣지 않았다.
- **문헌 쪽 한계.**
  - 외부 논문 수치는 대부분 n 이 적혀 있지 않다.
  - SASL 서지는 미확정이고, Polarization 은 초록 수준만 확인했다.
  - SNN 스파이크 손실에 채널 간 상대 가중을 건 선행 연구를 "못 찾았다" 는 것은 없다는 뜻이 아니다.
