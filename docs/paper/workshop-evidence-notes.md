## 범위와 상태

2026-09-16 작성. [워크숍 초안](workshop-draft-ko.md)은 사용자의 요청에 따라 별도로 작성한 국문 검토본이다. 기존 원고, 방법 용어 규약, 실험 설정, 큐는 변경하지 않는다. 4쪽에 맞춘 LaTeX 조판이나 독립 검증자 검토를 완료한 파일이 아니다.

성능 차이가 작은 상황을 숨기지 않고, 현재 실행된 규칙을 설명하는 예비 연구로 구성했다. 이것만으로 채택 가능성이나 충분한 새로움을 보장하지 않는다. 특히 구현 오류의 발견 자체를 연구 기여로 과장하지 않는다.

## w²에 관한 정확한 해석

가중치 w를 상수로 두고 R=||w⊙q||₂, R>0일 때 현재 함수 합성은 g₂=λw²/R이다. 통상적인 λR의 도함수는 λw²q/R이다. 따라서 w²를 발견한 것과 사용자 정의 backward가 실제 목적함수의 도함수라는 주장은 서로 다른 문제다.

선형 경로 g₁=λw/R은 같은 입력에서 같은 forward를 사용한다. 같은 q,w,λ에서의 비율 g₂/g₁=w는 직접 도출되지만, 두 학습의 전체 궤적에 그대로 적용할 수 없다. 같은 ρ도 같은 기울기 예산을 뜻하지 않는다. 현재 ours 대 plain L2는 시간 적용 방식·제어기·사용자 정의 backward도 함께 달라 인과적으로 w²만 분리하지 못한다.

기존 런을 유지한다면 w² 구현의 결과로 정확히 기술해야 한다. w¹을 최종 방법으로 택한다면 w¹의 실제 결과로 표를 갱신해야 한다. 어느 쪽도 이 초안에서 결정하거나 실행하지 않았다.

코드 기본값은 β=1, 가중치 배율=1, 추가 제곱 off, 평균 정규화 off, denominator floor=0이다. 런별 설정이 이를 덮어썼는지 확인해야 식의 적용 범위를 확정할 수 있다. R=0 분기에서는 반환 기울기를 0으로 선택하지만, 내부 rsqrt(0)의 수치적 안전성까지 실행 검증한 것은 아니다.

## 제출 전 우선순위

1. **기존 결과의 정체 확정:** 저장된 런 설정·코드 버전과 w² 경로 대조. w¹/w² 중 어느 방법을 제출할지 정하고, 선택한 경로의 수식과 결과를 일치시킨다. w²만 보고하는 예비 연구도 가능하지만 지수의 장점은 주장할 수 없다.
2. **측정과 평가 확정:** 계수기/npz 불일치 원인, 집계 대상 층, 모드, 입력 집합, 체크포인트 규칙을 통일한다. 동일 경로 비율도 방법별 편향 여부를 확인해야 한다.
3. **분석 집합 확정:** 상위 4개 선별과 전체 유효 런 집계 중 기존 합의·최신 기록이 어떻게 연결되는지 정리한다. 제외된 런과 미완주 런을 공개하고, 선별에 따른 민감도 분석을 고려한다. 최고 val_acc 선택에서 validation/test 구분도 확인한다.
4. **기여 확보:** 성능 우위가 없으면 반복 가능한 내부 활동 관찰 또는 통제된 w¹/w² 비교가 실제로 설명을 더하는지 검증한다. 차이가 있다는 이유만으로 유용하다고 해석하지 않는다.
5. **문헌 비교 범위:** 최소 비교는 baseline/plain L2/ours. BPSR 전체 재현과 sparsity 항만의 이식을 구분한다. 추가 실험 없이 문헌 우위를 주장하지 않는다.

위 항목들은 실험 실행 지시가 아니다. 학습 코드 변경·실행기 기동·큐 수정은 하지 않았다. 본문 분량은 내용 방향 확인 후 해당 워크숍 양식으로 조판하면서 맞춘다.
