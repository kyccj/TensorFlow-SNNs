### 헤드라인 주장 (사용자 확정, 2026-09-14)
> 스파이크 수를 50% 가까이 줄여도 정확도가 유지된다. 불필요한 뉴런들이 발화하고 있고,
> 제안법은 필수적인 뉴런만 남겨 효율적인 SNN 동작을 가능하게 한다.
> Speck 실험으로 실제 뉴로모픽 하드웨어에서도 검증하였다.

이 문장은 세 개의 독립된 주장으로 쪼개진다. 각각의 증거 상태가 다르다 — §2 참조.

- **C1** 무손실 스파이크 ~50% 감소
- **C2** 감소분이 "불필요한 뉴런을 끈 것"이며, 같은 예산에서 제안법이 뉴런을 더 적게 쓴다
- **C3** 실기(Speck) 검증

## 2. 주장별 증거 대장

등급: **A** = 지금 쓸 수 있음 / **B** = 표본 보강이면 쓸 수 있음 / **C** = 실험이 없음

### A등급 — 지금 쓸 수 있는 것

**A1. 무손실로 스파이크 51.5% 감소 (R19-C10)**
| | n | val_acc | spikes |
|---|---:|---:|---:|
| baseline (규제 없음) | 5 | 96.654 ± 0.065 | 486,656 |
| 제안법 ρ=3e-3 | 4 | **96.650 ± 0.168** | **235,802 (−51.5%)** |

차이 **−0.004%p**. baseline sd 0.065 의 1/16 이다.
**무손실선 = baseline 평균 − 2sd = 96.524.** 제안법 96.650 이 그 위에 있다. 이 선을
판정 기준으로 못 박고, "무손실" 이라는 말을 쓸 때마다 이 선을 함께 적는다.

**주의 — baseline 5런은 다섯 개의 서로 다른 디렉토리에 흩어져 있다.** `'_paper/*'` 글롭만
쓰면 2런만 잡히고 평균이 96.665 @ 481,331 로 어긋난다. 정본 목록:

```
_paper/r19c10-base---s11          96.74  488,900
_paper/r19c10-base---s12          96.59  473,761
_baseline_more/base_r19_c10_run3  96.64  499,190
_baseline_no_reg_r19_c10          96.60  486,852
_baseline_trajectory              96.70  484,578
```
`_paper/r19c10-base---s13` 은 307에폭이라 배제 규칙에 걸린다.
`_paper_bad_seeded/` 의 s1~s3 은 `run_seed` 고정본이라 쓰지 않는다
(95.46 / 95.54 / 96.22, 평균 95.740 ± 0.418 — tf.data 가 매 에폭 같은 증강 순서를 재생한다.
커밋 bb3633f 참조).

**A2. 같은 스파이크 예산에서 활성 뉴런 13.1% 적게 사용** — `ln(활성뉴런) ~ ln(스파이크) + 방법` 회귀,
계수 0.869, **t = −21.5, n = 21**. 최근접 쌍:

| | spikes | active neurons |
|---|---:|---:|
| plain L2 | 193,083 | 155,669 |
| 제안법 | 193,129 | **131,641 (−15.4%)** |

**A3. 뉴런당 발화 강도 순서** — 규제 없음 1.621 > **제안법 1.479** > 1−softmax 1.370 > plain L2 1.284.
제안법 vs plain L2 **t = 10.5, p = 8.4e-7**. 해석: 제안법은 뉴런 수를 줄여 스파이크를 줄이고,
L2 는 전체를 약하게 만들어 줄인다.

**A4. 집중은 초·중반층에서만 일어난다** — conv2_block1 지니 계수
규제없음 0.695 → plain L2 0.758 → **제안법 0.894**, 상위 10% 점유 0.424 → 0.491 → **0.805**.
**conv3_block2 이후는 세 방법이 겹친다.** "전 층에서 WTA" 라고 쓰면 틀린다.

**A5. `1−` 반전은 방법의 작동 조건** — 같은 ρ=4e-3 에서 반전을 빼면 착지점이 192K → **437,011**
(규제 없음 481K 와 거의 같음). 침묵 뉴런이 r=0 이 되어 손실에서 빠지므로 규제가 걸리지 않는다.
σ 로 잴 필요 없는 크기 차이(2.3배).

**A6. vmem 항의 정확도 기여** — 곡선 대비 **−0.222 (3.5σ), n=4**. 네 요소 중 유일하게 확정.

**A7. 학습이 더 싸다** — 695 vs 712 ms/step (final_step 으로 규제 호출이 T=4회 → 1회).
**3%p 라 작다. 부수적 관찰로만 쓴다.**

**A8. 가중치 설계 19종이 같은 정확도–스파이크 곡선에 떨어진다** — 논문의 전제이자 A2 의 대비 배경.
"곡선 위 같은 자리가 같은 상태를 뜻하지 않는다" 가 여기서 나온다.

### B등급 — 표본 보강이면 쓸 수 있는 것

**B1. 어블레이션 3팔** — `−final_step` (n=2, SE 0.188), `−loss-ratio` (n=2), `−1−반전` (n=2).
2σ 까지 각 2~3런, 합계 8런 ≈ 1.7일.

**B2. CIFAR-100 일반성** — 현재 조건당 n=1. baseline n=3 (80.720), l2 5e-7 n=1 (80.660),
제안법 3e-3 n=1 (80.370 @ −52.6%). **착지점이 달라 곡선을 못 그린다.** 조건당 n≥3 필요.

### C등급 — 실험 자체가 없는 것 (헤드라인이 여기에 걸려 있다)

**C1. 전체 테스트셋 기준 영구 침묵 뉴런 측정**
현재 `dead_neuron_ratio` 는 **배치 100장 기준**이다. 방법 간 비율 비교에는 유효하지만
"영구히 죽은 뉴런" 으로 읽으면 안 된다. 사용자의 헤드라인("불필요한 뉴런을 끈다")을
구조적 프루닝 이득으로 주장하려면 테스트셋 10,000장 재측정이 필요하다.
도구는 있다 — `extract_neuron_spikes.py`, GPU 1장 반나절.

**C2. Speck 실측** — 이 레포에 Speck/sinabs 코드가 없다 (다른 머신).
기존 Speck 성과는 5층 SumPool CNN 계열이고 **ResNet-19 / 제안법으로는 한 번도 안 돌렸다.**
헤드라인 세 번째 문장 전체가 이 실험에 걸려 있다.

**C3. `l2 + loss-ratio` 대조군** — loss-ratio 는 plain L2 에도 그대로 붙는다.
이 대조군이 없으면 "λ 자동화" 를 제안법 고유 기여로 못 쓴다. 4런.

**C4. Spikformer / CIFAR10-DVS 를 제안법으로 재실행** — 현존 sweep 은 wta_rev 시절 것이다.

**C5. SDT-V3 173M** — 다른 서버. 이식은 완료(`sdtv3-spike-reg-port`), 실행 미착수.

## 4. 선점 판정 (2026-09-14 확인 완료)

### Activity Pruning, Tong Bu 외, NeurIPS 2025 — **부분 선점**
OpenReview 본문은 CAPTCHA 로 막혀 미확인. **Semantic Scholar 초록 전문 + GitHub 저장소
소스코드**로 확인했다 (`github.com/putshua/Activity-Pruning-SNN`).

| 확인 항목 | 결과 |
|---|---|
| 학습 중 규제인가 | **그렇다.** `utils/utils.py:406 regularize_spike()` 가 층별 스파이크 수를 손실에 더한다. 이름만 Pruning 이고 사후 prune+retrain 이 아니다 |
| 막전위를 쓰는가 | **쓴다.** `Surrogate.forward` 가 역치 부근 발화량에 비례해 역치를 밀어 올린다 (autograd 밖 `thresh += v*eta`) |
| 세기 계수를 자동으로 정하는가 | **아니다.** `eta`/`eta2` 를 설정 파일에 손으로 박는다 |
| 하드웨어 실측 | 저장소에 배포 코드·전력 측정 없음. `SOPMonitor` 는 SynOps 시뮬 계산. **본문 미확인이므로 "실측 없음" 을 단정하지 말고 "코드·초록 범위에서 확인되지 않음" 으로 쓴다** |

**결정적 인용거리** — 같은 방법인데 데이터셋만 바뀌자 계수가 반대 방향으로 움직인다:

| 설정 파일 | `eta` | `eta2` |
|---|---|---|
| `cifar10.yaml` (ResNet20, T=8) | 1e-3 | 1e-4 |
| `imagenet100.yaml` (sew_resnet18, T=4) | 1e-4 | 1e-2 |

`eta2` 100배, `eta` 10배, 서로 반대 방향. **"raw λ 는 조합마다 재튜닝해야 한다" 는 우리 전제를
NeurIPS 2025 논문이 스스로 증명한 셈이다.** 이 표를 그대로 인용한다.

#### 선점되는 주장 / 안 되는 주장

| 우리 주장 | 선점? |
|---|---|
| 스파이크 감소는 거의 전부 뉴런 침묵이다 (활동 가지치기) | **선점됨.** 제목과 전체 프레이밍이 그것 |
| 기존 활동 규제에 구조적 한계가 있다 | **선점됨.** 초록에 명시 |
| 가중 방식 19종이 같은 곡선에 수렴한다 | 선점 안 됨 |
| 살아남은 뉴런이 방법과 무관하게 T=4 중 2.3~2.5회 발화 | 선점 안 됨 |
| 같은 예산에서 활성 뉴런 13% 적게 사용 | 선점 안 됨 |
| λ = ρ·L_task/R 무차원 제어 | 선점 안 됨 |

**→ 사용자가 정한 헤드라인 두 번째 문장("불필요한 뉴런들이 발화하고 있고, 필수적인 뉴런만
남긴다")이 선점된 쪽에 정확히 걸린다.** 이 문장은 신규 기여가 아니라 **선행 관측의 재확인 +
정량화**로 위치시켜야 한다. 신규성은 "같은 곡선 위 같은 자리라도 뉴런 사용은 다르다"(A2·A3)와
"λ 를 손으로 안 정한다"(C3 해결 시)에 둔다.

### Sorbaro 외 2020, Frontiers in Neuroscience 14:662 — **λ 자동화의 최근접 선행**
원문 PDF 확인 완료.

손실: `L = C(a_out, t) + α·|S0 − Σ_ℓ s_ℓ|`, `s_ℓ = Σ_i a_{i,ℓ} · fan-out_ℓ`

계수 선택 (원문 156~158행 축자):
> "we will always choose α = 1/S0², in order to keep the SynOp loss term normalized
> independently of S0 ... we found it easier to set a direct target for the power budget"

즉 α 를 스윕하지 않는 대신 **절대 SynOps 목표 S0 를 스윕한다** (원문 381행: "We trained 30
models with lower and lower target SynOps"). `1/S0²` 은 **학습 전에 확정되는 정적 상수**로
학습 중 L_task·R 의 크기에 반응하지 않는다.

| | Sorbaro 2020 | 본 연구 |
|---|---|---|
| 정규화 기준 | 절대 목표 S0 (사전 지식 필요) | 학습 중 실제 L_task 와 R |
| 갱신 | 없음 (정적) | 매 에폭 재해결 |
| 학습 방식 | quantization-aware ANN → SNN 변환 | STBP 직접 학습, T=4 |
| 데이터 | MNIST-DVS(3층), CIFAR-10(All-ConvNet 9층 1.9M) | CIFAR-10/100, ResNet-19 |
| 하드웨어 | **sinabs 시뮬 전용** | Speck 실측 (예정) |

학습 방식이 ANN→SNN 변환이라는 점이 가장 확실한 차별점이다.

## 6. 보고 형식 규약 (사용자 지시)

- 표 열 순서: **train loss → train acc → val loss → val acc → spikes**
- 반복 런은 개별 행을 모두 보이고 **그룹 바로 아래 줄에 평균**
- 그래프는 실제 정확도·실제 스파이크 수로 그린다 (정규화·상대값 금지)
- `1-maxnorm` 과 `maxnorm` 을 명칭에서 구분한다

## 7. 반전 이력 — 다시 꺼내지 말 것

같은 항목을 여러 번 뒤집었다. **최신 값만 유효하다.** 과거 값을 문서 어딘가에서 보더라도
아래 오른쪽 열을 따른다.

| 항목 | 경로 | 최종 |
|---|---|---|
| prop ρ=3e-3 정확도 | 96.65(n=1) → 96.705(n=2) → 96.727(n=3) → **96.650(n=4)** | baseline 초과 아님, "동일" |
| prop − l2 오프셋 | +0.094(n=16) → +0.074(n=17) → +0.060/+0.071 | **포기** |
| p<0.05 필요 런 수 | "7런" → "31런" → **"≈48~60런, 13일"** | 포기 |
| `abl_novmem` 기여 | −0.303(n=1) → −0.165(n=2) → **−0.222(n=4), 3.5σ** | **정확도** 축 기여 (집중 아님) |
| vmem 정체성 | "WTA 개선" → **"반-WTA(분산), 약자 구제"** | Gini 1-m 0.633 > vmem 0.594 > 1-s 0.579 |
| 시드 고정 | 도입 → **폐기** | 증강 다양성이 죽어 96.65 → 95.72, sd 8배 |
| baseline n | n=5(혼합) → "n=2뿐, 위기" → **n=5 유효** | 정본 목록은 A1 |
| 완주 판정 | `에폭≥300` 버그(302에폭 통과) → **설정된 310과 비교** | `collect_paper.py:planned_epochs()` |

**특히 주의** — "정확도 우위" 와 "필요 런 수" 는 n 이 늘 때마다 값이 흔들렸다. 새 데이터가
들어와 수치가 좋아 보여도 **재개하지 않는다.** 포기는 2026-09-14 에 내린 결정이다.
