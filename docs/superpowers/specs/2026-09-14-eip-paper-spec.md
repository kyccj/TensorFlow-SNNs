### 헤드라인 주장 (사용자 확정, 2026-09-14)
> 스파이크 수를 50% 가까이 줄여도 정확도가 유지된다. 불필요한 뉴런들이 발화하고 있고,
> 제안법은 필수적인 뉴런만 남겨 효율적인 SNN 동작을 가능하게 한다.
> Speck 실험으로 실제 뉴로모픽 하드웨어에서도 검증하였다.

이 문장은 세 개의 독립된 주장으로 쪼개진다. 각각의 증거 상태가 다르다 — §2 참조.

- **C1** 무손실 스파이크 ~50% 감소
- **C2** 감소분이 "불필요한 뉴런을 끈 것"이며, 같은 예산에서 제안법이 뉴런을 더 적게 쓴다
- **C3** 실기(Speck) 검증

## 2. 주장별 증거 대장

등급: **A** = 지금 쓸 수 있음 / **B** = 표본 보강이면 쓸 수 있음 / **C** = 실험이 없음

### A등급 — 지금 쓸 수 있는 것

**A1. 무손실로 스파이크 51.5% 감소 (R19-C10)**
| | n | val_acc | spikes |
|---|---:|---:|---:|
| baseline (규제 없음) | 5 | 96.654 ± 0.065 | 486,656 |
| 제안법 ρ=3e-3 | 4 | **96.650 ± 0.168** | **235,802 (−51.5%)** |

차이 **−0.004%p**. baseline sd 0.065 의 1/16 이다.
**무손실선 = baseline 평균 − 2sd = 96.524.** 제안법 96.650 이 그 위에 있다. 이 선을
판정 기준으로 못 박고, "무손실" 이라는 말을 쓸 때마다 이 선을 함께 적는다.

**주의 — baseline 5런은 다섯 개의 서로 다른 디렉토리에 흩어져 있다.** `'_paper/*'` 글롭만
쓰면 2런만 잡히고 평균이 96.665 @ 481,331 로 어긋난다. 정본 목록:

```
_paper/r19c10-base---s11          96.74  488,900
_paper/r19c10-base---s12          96.59  473,761
_baseline_more/base_r19_c10_run3  96.64  499,190
_baseline_no_reg_r19_c10          96.60  486,852
_baseline_trajectory              96.70  484,578
```
`_paper/r19c10-base---s13` 은 307에폭이라 배제 규칙에 걸린다.
`_paper_bad_seeded/` 의 s1~s3 은 `run_seed` 고정본이라 쓰지 않는다
(95.46 / 95.54 / 96.22, 평균 95.740 ± 0.418 — tf.data 가 매 에폭 같은 증강 순서를 재생한다.
커밋 bb3633f 참조).

**A2. 같은 스파이크 예산에서 활성 뉴런 13.1% 적게 사용** — `ln(활성뉴런) ~ ln(스파이크) + 방법` 회귀,
계수 0.869, **t = −21.5, n = 21**. 최근접 쌍:

| | spikes | active neurons |
|---|---:|---:|
| plain L2 | 193,083 | 155,669 |
| 제안법 | 193,129 | **131,641 (−15.4%)** |

**A3. 뉴런당 발화 강도 순서** — 규제 없음 1.621 > **제안법 1.479** > 1−softmax 1.370 > plain L2 1.284.
제안법 vs plain L2 **t = 10.5, p = 8.4e-7**. 해석: 제안법은 뉴런 수를 줄여 스파이크를 줄이고,
L2 는 전체를 약하게 만들어 줄인다.

**A4. 집중은 초·중반층에서만 일어난다** — conv2_block1 지니 계수
규제없음 0.695 → plain L2 0.758 → **제안법 0.894**, 상위 10% 점유 0.424 → 0.491 → **0.805**.
**conv3_block2 이후는 세 방법이 겹친다.** "전 층에서 WTA" 라고 쓰면 틀린다.

**A5. `1−` 반전은 방법의 작동 조건** — 같은 ρ=4e-3 에서 반전을 빼면 착지점이 192K → **437,011**
(규제 없음 481K 와 거의 같음). 침묵 뉴런이 r=0 이 되어 손실에서 빠지므로 규제가 걸리지 않는다.
σ 로 잴 필요 없는 크기 차이(2.3배).

**A6. vmem 항의 정확도 기여** — 곡선 대비 **−0.222 (3.5σ), n=4**. 네 요소 중 유일하게 확정.

**A7. 학습 비용 — 비교군 중 가장 싸다** (310에폭 평균, 런 내 sd 25~30ms = 4%)

| 조건 | ms/step | s/에폭 | 총 시간 | baseline 대비 |
|---|---:|---:|---:|---:|
| baseline (규제 없음) | 631 | 316 | 27.2h | — |
| `1−` 반전 제거 | 675 | 338 | 29.1h | +7.0% |
| **제안법** | **695** | 348 | 30.0h | **+10.0%** |
| plain L2 | 712 | 357 | 30.7h | +12.8% |
| 1−softmax | 759 | 380 | 32.7h | +20.2% |
| final_step 제거 (매 시점) | 841 | 421 | 36.2h | +33.2% |

정확한 서술은 **"규제를 켜면 10% 느려지는데, 이는 모든 비교군보다 적다"** 이다.
"제안법이 plain L2 보다 싸다"(695 vs 712, 2.4%) 만 쓰면 baseline 대비 비용을 숨기는 것이 된다.
final_step 이 t=T 에 한 번만 도는 덕이며, 매 시점 호출(841)과 비교하면 기여가 명확하다.

**A8. 가중치 설계 19종이 같은 정확도–스파이크 곡선에 떨어진다** — 논문의 전제이자 A2 의 대비 배경.
"곡선 위 같은 자리가 같은 상태를 뜻하지 않는다" 가 여기서 나온다.

**A9. 어블레이션 착지점은 요소마다 다르다** — 같은 ρ=4e-3 에서 제안법 192K, vmem 제거 148K,
final_step 제거 159K, `1−` 반전 제거 437K. 요소를 빼면 `R` 이 변해 세기가 자동으로 달라지며
**그 자체가 결과다** (스펙 §12-4 A tier).

### B등급 — 표본 보강이면 쓸 수 있는 것

**B0. 중반 구간 스파이크 감소 폭 18.7~20.3%** — "제안법은 고정 λ보다 ep51–200 구간에서
스파이크를 18.7~20.3% 더 줄이면서 정확도를 잃지 않는다" (§9-C 가 유일하게 승인한 문장).
**비교 대상인 `abl_nolr` 이 λ=3e-7 n=1, λ=5e-7 n=1 뿐이다.** 이 수치는 A 등급이 아니며
G2(어블레이션 표본 보강)에 걸린다. 게이트 없이 본문에 쓰지 않는다.


**B1. 어블레이션 3팔** — `−final_step` (n=2, SE 0.188), `−loss-ratio` (n=2), `−1−반전` (n=2).
2σ 까지 각 2~3런, 합계 8런 ≈ 1.7일.

**B2. CIFAR-100 일반성** — 현재 조건당 n=1. baseline n=3 (80.720), l2 5e-7 n=1 (80.660),
제안법 3e-3 n=1 (80.370 @ −52.6%). **착지점이 달라 곡선을 못 그린다.** 조건당 n≥3 필요.

### C등급 — 실험 자체가 없는 것 (헤드라인이 여기에 걸려 있다)

**C1. 전체 테스트셋 기준 영구 침묵 뉴런 측정**
현재 `dead_neuron_ratio` 는 **배치 100장 기준**이다. 방법 간 비율 비교에는 유효하지만
"영구히 죽은 뉴런" 으로 읽으면 안 된다. 사용자의 헤드라인("불필요한 뉴런을 끈다")을
구조적 프루닝 이득으로 주장하려면 테스트셋 10,000장 재측정이 필요하다.
도구는 있다 — `extract_neuron_spikes.py`, GPU 1장 반나절.

**C2. Speck 실측** — 이 레포에 Speck/sinabs 코드가 없다 (다른 머신).
기존 Speck 성과는 5층 SumPool CNN 계열이고 **ResNet-19 / 제안법으로는 한 번도 안 돌렸다.**
헤드라인 세 번째 문장 전체가 이 실험에 걸려 있다.

**C3. `l2 + loss-ratio` 대조군** — loss-ratio 는 plain L2 에도 그대로 붙는다.
이 대조군이 없으면 "λ 자동화" 를 제안법 고유 기여로 못 쓴다. 4런.

**C4. Spikformer / CIFAR10-DVS 를 제안법으로 재실행** — 현존 sweep 은 wta_rev 시절 것이다.

**C5. SDT-V3 173M** — 다른 서버. 이식은 완료(`sdtv3-spike-reg-port`), 실행 미착수.

## 4. 선점 판정 (2026-09-14 확인 완료)

### Activity Pruning, Tong Bu 외, NeurIPS 2025 — **부분 선점**
OpenReview 본문은 CAPTCHA 로 막혀 미확인. **Semantic Scholar 초록 전문 + GitHub 저장소
소스코드**로 확인했다 (`github.com/putshua/Activity-Pruning-SNN`).

| 확인 항목 | 결과 |
|---|---|
| 학습 중 규제인가 | **그렇다.** `utils/utils.py:406 regularize_spike()` 가 층별 스파이크 수를 손실에 더한다. 이름만 Pruning 이고 사후 prune+retrain 이 아니다 |
| 막전위를 쓰는가 | **쓴다.** `Surrogate.forward` 가 역치 부근 발화량에 비례해 역치를 밀어 올린다 (autograd 밖 `thresh += v*eta`) |
| 세기 계수를 자동으로 정하는가 | **아니다.** `eta`/`eta2` 를 설정 파일에 손으로 박는다 |
| 하드웨어 실측 | 저장소에 배포 코드·전력 측정 없음. `SOPMonitor` 는 SynOps 시뮬 계산. **본문 미확인이므로 "실측 없음" 을 단정하지 말고 "코드·초록 범위에서 확인되지 않음" 으로 쓴다** |

**결정적 인용거리** — 같은 방법인데 데이터셋만 바뀌자 계수가 반대 방향으로 움직인다:

| 설정 파일 | `eta` | `eta2` |
|---|---|---|
| `cifar10.yaml` (ResNet20, T=8) | 1e-3 | 1e-4 |
| `imagenet100.yaml` (sew_resnet18, T=4) | 1e-4 | 1e-2 |

`eta2` 100배, `eta` 10배, 서로 반대 방향. **"raw λ 는 조합마다 재튜닝해야 한다" 는 우리 전제를
NeurIPS 2025 논문이 스스로 증명한 셈이다.** 이 표를 그대로 인용한다.

#### 선점되는 주장 / 안 되는 주장

| 우리 주장 | 선점? |
|---|---|
| 스파이크 감소는 거의 전부 뉴런 침묵이다 (활동 가지치기) | **선점됨.** 제목과 전체 프레이밍이 그것 |
| 기존 활동 규제에 구조적 한계가 있다 | **선점됨.** 초록에 명시 |
| 가중 방식 19종이 같은 곡선에 수렴한다 | 선점 안 됨 |
| 살아남은 뉴런이 방법과 무관하게 T=4 중 2.3~2.5회 발화 | 선점 안 됨 |
| 같은 예산에서 활성 뉴런 13% 적게 사용 | 선점 안 됨 |
| λ = ρ·L_task/R 무차원 제어 | 선점 안 됨 |

**→ 사용자가 정한 헤드라인 두 번째 문장("불필요한 뉴런들이 발화하고 있고, 필수적인 뉴런만
남긴다")이 선점된 쪽에 정확히 걸린다.** 이 문장은 신규 기여가 아니라 **선행 관측의 재확인 +
정량화**로 위치시켜야 한다. 신규성은 "같은 곡선 위 같은 자리라도 뉴런 사용은 다르다"(A2·A3)와
"λ 를 손으로 안 정한다"(C3 해결 시)에 둔다.

### Sorbaro 외 2020, Frontiers in Neuroscience 14:662 — **λ 자동화의 최근접 선행**
원문 PDF 확인 완료.

손실: `L = C(a_out, t) + α·|S0 − Σ_ℓ s_ℓ|`, `s_ℓ = Σ_i a_{i,ℓ} · fan-out_ℓ`

계수 선택 (원문 156~158행 축자):
> "we will always choose α = 1/S0², in order to keep the SynOp loss term normalized
> independently of S0 ... we found it easier to set a direct target for the power budget"

즉 α 를 스윕하지 않는 대신 **절대 SynOps 목표 S0 를 스윕한다** (원문 381행: "We trained 30
models with lower and lower target SynOps"). `1/S0²` 은 **학습 전에 확정되는 정적 상수**로
학습 중 L_task·R 의 크기에 반응하지 않는다.

| | Sorbaro 2020 | 본 연구 |
|---|---|---|
| 정규화 기준 | 절대 목표 S0 (사전 지식 필요) | 학습 중 실제 L_task 와 R |
| 갱신 | 없음 (정적) | 매 에폭 재해결 |
| 학습 방식 | quantization-aware ANN → SNN 변환 | STBP 직접 학습, T=4 |
| 데이터 | MNIST-DVS(3층), CIFAR-10(All-ConvNet 9층 1.9M) | CIFAR-10/100, ResNet-19 |
| 하드웨어 | **sinabs 시뮬 전용** | Speck 실측 (예정) |

학습 방식이 ANN→SNN 변환이라는 점이 가장 확실한 차별점이다.

## 6. 보고 형식 규약 (사용자 지시)

- 표 열 순서: **train loss → train acc → val loss → val acc → spikes**
- 반복 런은 개별 행을 모두 보이고 **그룹 바로 아래 줄에 평균**
- 그래프는 실제 정확도·실제 스파이크 수로 그린다 (정규화·상대값 금지)
- `1-maxnorm` 과 `maxnorm` 을 명칭에서 구분한다

## 7. 반전 이력 — 다시 꺼내지 말 것

같은 항목을 여러 번 뒤집었다. **최신 값만 유효하다.** 과거 값을 문서 어딘가에서 보더라도

## 9. 고지 의무 — 논문에 반드시 쓸 것

이전 세션(09-03~09-14)이 반복해서 짚은 항목들이다. 빼면 리뷰어가 잡는다.

**A. `wta_rev` 는 진짜 도함수가 아니다** (09-10, 09-14 두 번 강조)
`x_i = c_i·r_i = c_i(1 − c_i/M)` 는 포물선이라 진짜 기울기 `∂x/∂c = 1 − 2c/M` 이
`c = M/2` 에서 **부호가 뒤집힌다** (활동량 높은 뉴런을 오히려 키운다). 구현은 `c` 인자를
떼고 `r` 만 써서 단조 갱신 규칙으로 바꾼 것이다.
**"설계된 갱신 규칙이지 손실의 도함수가 아니다" 를 명시한다.** 대리 기울기와 같은 성격이지만
리뷰어가 반드시 확인할 자리다. (Method 절 소관이지만 §4·§5 서술이 이를 전제하면 안 된다.)

**B. λ 가 ep201 에서 44% 급락하는 원인이 미확인이다** (09-14)
4.75e-7 → 2.68e-7. cutmix 종료(`conf.mix_off_iter = 500*200`) 때문으로 보이지만
**LR 스케줄의 특정 지점과 겹치는지 확인하지 않았다.** 겹친다면 "loss-ratio 가 스케줄에
간접 종속된다" 는 뜻이고, **같은 이유로 `lr-linked` 방법을 이미 기각한 적이 있다.**
→ **F6(λ 궤적 그림)과 CONTRIB-2 를 쓰기 전에 확인해야 한다.** 확인 전에는 "스케줄과
무관하다" 를 주장하지 않는다.

**C. loss-ratio 의 궤적 효과와 강도 효과가 섞여 있다** (09-14)
비교군 고정 λ=3e-7 은 제안법 시간평균(4.00e-7)보다 낮다. "궤적 때문" 인지 "평균 강도 차이"
인지 구분할 수 없다. **착지점 맞추기와 평균 λ 맞추기를 동시에 만족시킬 수 없다.**
격리하려면 λ≈3.2e-7(착지 맞춤) 4런 + λ=4.0e-7(평균 맞춤) 4런 = 8런 / 1.7일.
**지금 말할 수 있는 것은 이것뿐이다:** "제안법은 고정 λ보다 중반 구간(ep51–200)에서
스파이크를 18.7~20.3% 더 줄이면서 정확도를 잃지 않는다."

**D. SynOps 축은 논문에서 뺀다** (09-13) — **T5 계획에 영향**
스파이크당 SynOps 가 제안법 1,505 vs plain L2 1,488 = **+1.1% — 이 표본 규모로는 잴 수 없다**
(§10 규약: "차이가 없다" 로 쓰지 않는다).
층별 스파이크 분포가 거의 같아 구분되지 않는다. **SynOps × pJ 에너지 표로는 우위를
주장할 수 없다.** 정확한 서술은 **"같은 SynOps 에서 뉴런을 적게 쓴다"** 이다.
T5 를 넣더라도 baseline 대비 총량 감소를 보이는 용도이지 비교군 대비 우위 근거가 아니다.

**E. 대리 기울기가 두 코드베이스에서 다르다** (09-07)
TF 는 `asym` (무조건 ON, ResNet bias 0.8 / VGG16·Spikformer 0.6), QKFormer 는
SpikingJelly `Sigmoid()`. asym 이식·검증은 끝났으나(TF 대비 최대 절대차 0.00e+00)
기본값이 꺼져 있다. 켜면 조건이 일치하지만 기존 QKFormer 자산 15점을 못 쓴다.
**결정 보류 상태.** 어느 쪽이든 명시한다. `asym` 은 우리 기여가 아니라 저장소 기존 설정이며
전 팔에 동일 적용되어 비교는 공정하다는 점, `surro_grad_alpha` 값도 함께 적는다.

**F. QKFormer 포팅 버그를 정직하게 기술한다** (09-03)
`tools/wta_rev.py` 의 `cumsum(dim=0)` 이 T 를 가정하는데 `stage3.0/1.ssa.proj_lif` 2층이
`[T·B, C, N]` 으로 들어와 배치까지 누적됐다. 그 2층이 2.75배 강하게 규제됐고 전체
목적함수로는 −5.87% 차이였다. 훅에서 되접는 방식으로 수정했다.
초안된 문구를 그대로 쓴다: "포팅에 축 오인이 있어 2/35층이 2.75배 강하게 규제됐고,
전체 목적함수로는 5.9% 차이였다. 수정 후 재측정했다."

**G. 스파이크 프로토콜을 eval 로 통일한다** (09-03)
같은 QKFormer 모델이 train 426,590 vs eval 603,245 = **1.41배**다. TF 의 `s_count` 와
같은 프로토콜이 되도록 **논문 표는 전부 eval 기준**으로 쓴다. 학습 모드는 S30/S1 선별에만.

**H. "이미지당 조용한 뉴런" 과 "전 데이터셋에서 한 번도 안 쏜 뉴런" 을 구분한다**
현재 측정은 전자(배치 100장)다. 후자를 말하려면 G5 가 필요하다. 두 개념을 섞어 쓰면
프루닝 이득을 과장하게 된다.

**I. 재현성 부록에 적을 인프라 사고** (09-14)
루트 정리 중 `ls -A` 가 `.git`·`.omc`·`__pycache__` 를 함께 옮김(전부 복구, `git fsck` 통과).

## 10. 서술 수위 규약

이전 세션이 여러 번 스스로 단속한 규칙들이다. 문장을 쓸 때마다 적용한다.

| 쓰지 말 것 | 쓸 것 | 근거 |
|---|---|---|
| "명확히 더 좋다" | **"작지만 일관된 우위"** — 또는 아예 쓰지 않는다 | 오프셋 0.094 가 런 간 sd 0.109 보다 작다. 회귀로 모아야만 보인다 |
| "차이가 없다" | **"이 규모로는 잴 수 없다"** + 필요 n 을 함께 적는다 | 부정 결과를 방어 가능한 형태로 |
| 방법에 순서를 매김 | **"세 방법이 같은 곡선 위에 있다"** | 실제로 측정된 것. 순서를 주장하면 반박당한다 |
| "WTA 가 일어난다" | **"활동이 집중된다"** (측정 가능한 언어) + 초·중반층 한정 | 억제상관 +0.61~0.69, 균일 대조군 +0.642 와 구별 안 됨 |
| "무손실로 스파이크를 30% 더 줄인다" | **쓰지 않는다** | 근거인 오프셋 c 가 +0.094(n=16) → +0.074(n=17) 로 약화. 현재 주장 불가 |

**이 규약은 이 스펙 자신에게도 적용된다.** 스펙 본문에서 금지된 표현을 쓰면 개요·본문이
그대로 복사한다 — 실제로 §9-D 가 "차이 없음" 으로 적혀 있다가 개요에 그대로 옮겨졌다 (09-14 수정).

**정직한 서술의 모범 형태** (09-02, 그대로 인용):
> 가중치 설계를 네 가지 축으로 바꿔 봤으나 정확도–스파이크 곡선은 움직이지 않았다.
> 그중 vmem 을 최종 설정으로 쓴다 — 기전적 동기가 있고, 관측된 모든 지표에서 뒤지지 않는다.

## 11. 이미 초안된 문장 — 개요·본문에 재사용

**A. 논문 전체 논지 (최강 후보, 09-14)**
> 가중 설계 19종을 시험했더니 전부 같은 정확도–스파이크 곡선에 떨어졌다. **그런데 곡선 위
> 같은 자리가 같은 상태를 뜻하지 않는다.** 같은 정확도·같은 스파이크에서 plain L2 는 뉴런
> 155,669개를 쓰고 제안법은 131,641개를 쓴다 (−15.4%). 곡선은 두 방법을 구분하지 못하지만
> 뉴런 사용은 구분한다.

19종이 같은 곡선에 모인 것은 약점이 아니라 이 논지의 **전제**다. 정확도 우위를 주장하지
않아도 성립한다. **단서:** "뉴런을 적게 쓰는 게 왜 좋은가" 에 아직 답이 없다 — 기전이지
이득이 아니다. 초록에 과장이 들어가지 않게 한다.

**B. 기전 한 줄 (09-14)**
> 규제를 걸면 뉴런당 발화가 떨어지는데 제안법이 가장 덜 떨어진다. 제안법은 뉴런 수를 줄여
> 스파이크를 줄이고, L2 는 모두를 약하게 만들어 줄인다.

**인용 위계 주의** — plain L2 비교군의 문헌 근거는 `neil2016learning`(ACM SAC 2016) ·
`sorbaro2020optimizing`(Frontiers 2020) · `pellegrini2021low`(IEEE SLT 2021) 셋이 주이고,
`meda2022improving`(arXiv:2201.02538)은 **단독저자 학사 논문이라 보조**다. 이것만 근거로
들면 리뷰어가 지적한다.

**C. 기존 방법의 구조적 한계 (Related Work / Motivation, 09-10)**
> 목표는 하나 — 총 스파이크 수를 줄이는 것. *어떤* 뉴런을 줄일지에 대한 선호가 목적 함수에
> 없다. 결과적으로 L2 는 "간신히 쏜 뉴런을 못 쏘게" 만든다. 강한 뉴런은 건드리지 못하고
> 침묵 뉴런은 손대지 않는다. **의도한 설계가 아니라 구조에서 나온 부작용이다.**

**D. `1−` 반전이 작동 조건인 이유 (09-14)** — `abl_noinv` 는 "정확도가 조금 나빠졌다" 가
아니라 **"빼면 방법이 아예 작동하지 않는다"** 를 보이는 실험이다. 정확도 열이 96.56 으로
멀쩡해 보이는 데 속으면 안 되고, **착지점(437K)과 `sc_rate` 평균(0.04~0.17)을 같이 싣는다.**
세 겹침: ① `sc_rate` 평균이 1/20 로 떨어짐(뉴런 78~97%가 침묵 → 반전 없으면 r=0 으로 이탈)
② `R` 이 2.33배가 되어 λ 가 자동으로 1/3 로 깎임(4.00e-7 → 1.39e-7) ③ 남은 gradient 가
문턱 한참 위 뉴런에 가는데 거기선 대리 기울기가 0. 착지 437,011 = 규제 없음의 90%.
**"켜져 있지만 작동하지 않는다."**

**E. 설계 공간을 닫았다는 논증 (08-31)** — 리뷰어가 "다른 가중치를 써보지 그랬냐" 고 물으면
**"양 끝을 다 했다"** 고 답한다. WTA 방향(집중)과 그 반대 방향(분산)을 다 만들었는데 둘 다
균일 가중과 같은 곡선이다. **"분포를 의도대로 바꿨는데 정확도가 안 바뀐다"** 가 부정 결과를
강하게 만든다 — 구현이 안 됐거나 차등이 안 걸려서가 아니라, 차등이 확실히 걸렸는데도
무관하다는 뜻이므로.

**H. 초록을 쓰기 전 반드시 볼 자기 평가 (09-10)**
> 지금 상태의 정직한 결론은 "기존 방법과 동등한데 조금 싸고 튜닝이 없다" 이다. CVPR 에는 약하다.

강화 경로는 둘뿐이다 — **테스트셋 전체 뉴런 측정 → 프루닝 이득(G5)** 또는 **Speck 실측(G7)**.
정확도 통계를 닫는 경로는 2026-09-14 에 포기했다. 어느 쪽이든 `l2 + loss-ratio` 대조군(G4)은
돌려야 한다.

## 12. 실험 프로토콜 확정

### 12-1. 사전 등록 규칙 — 두 종류를 구분한다

**선별 규칙** (어떤 런을 표에 쓰는가. 제안법·비교군에 대칭 적용):
1. 310에폭 미완주 → 배제. `collect_paper.py` 가 `에폭 ≥ 300` 으로 판정하던 버그가 있었고
   302에폭 런이 완주로 통과했다. `Epoch n/N` 의 N 을 읽도록 고쳤다. 이 버그로 `abl_novmem`
   을 96.220 으로 잘못 보고할 뻔했다.
2. `S30/S1 < 0.19` → 배제 (초기 붕괴 지표). **이 규칙이 ρ 의 상한을 약 1e-2 로 정한다** —
   ρ=1.2e-2 는 예상 S30/S1 0.188 로 배제 위험이다.
3. 그래도 5개가 남으면 val_acc 상위 4개.

**판정 규칙** (결과를 무엇이라 부르는가):
4. **무손실선 = baseline 평균 − 2sd.** R19-C10 은 **96.524**, VGG16-C10 라인은 94.78.
5. **±1 SE 안이면 판정 보류.** prop ρ=4e-3 은 +1.25 SE 로 "보류의 바로 바깥" 이었다.

R19-C10 baseline 은 후보 8런 중 규칙으로 3런을 배제하고 **5런을 썼다**. 부록 T7 에 그대로 적는다.

### 12-2. 시드를 쓰지 않는다 — 중대한 반전

`run_seed` 를 09-03 에 도입했다가 **09-04 에 전면 폐기**했다. 전역 시드를 박으면 `tf.data`
난수 연산이 에폭마다 같은 시퀀스를 재생해 증강 다양성이 사라진다:
baseline **96.65 → 95.72 (−0.93%p)**, 런 간 **sd 0.050 → 0.429 (8배)**, train/val 격차도
−1.12 → +0.73 으로 뒤집혔다. 게다가 시드를 고정해도 GPU 비결정성으로 재현되지 않는다
(같은 시드 2회에 val_acc 37.35% vs 41.31%).
**결과적으로 s1~s5 는 태그일 뿐이고, 조건당 목표 반복은 n=5 다.** 논문에 이대로 쓴다.

### 12-3. 통계 — 한 점 맞대결이 아니라 공통기울기 회귀 (ANCOVA)

```
acc = a + b·ln(spikes) + c·[제안법]
```
- 정확도 축: n=16 에서 `acc = 93.174 + 0.274·ln(spikes) (+0.094 제안법)`, 잔차 sd 0.109,
  t=1.63 → n=17 에서 +0.074 (t=1.19) → 최종 +0.060~0.071. **주장하지 않는다.**
- 3방법 동시: prop +0.094 / **sm +0.006** — 1−softmax 는 plain L2 와 사실상 같은 곡선이다.
- 활성 뉴런 축: `ln(활성뉴런) ~ ln(스파이크) + 방법` → 0.868배 = **−13.2%, SE 0.0073,
  t=−19.4 (n=19)**. 다른 집계에서 t=−21.5 (n=21). **이 축을 쓴다.**

**표기 주의** — prop ρ=3e-3 의 "± 0.168" 은 **sd** 이고, 다른 기록의 "0.084" 는 **SE** 다
(sd/√4). 표마다 어느 쪽인지 명시한다.

### 12-4. 어블레이션 스파이크 맞추기 — 설계 확정, 실행 미승인

**"맞춘 표만 내면 안 되고, 두 표를 같이 내야 한다."**
- **(A) 같은 ρ 행** — "이 요소를 빼면 방법이 어떻게 달라지나". 요소를 빼면 `R` 이 변해
  λ 가 자동으로 바뀌고 gradient 모양도 바뀌는데 **그 자체가 결과**다.
- **(B) 맞춘 스파이크 행 (192K)** — "같은 희소성에서 이 요소가 정확도에 기여하나".

맞출 값 (prop 3점에서 `ln(spikes) = c − 0.594·ln(ρ)`):

| 팔 | 현재 | 목표 | 근거 |
|---|---|---|---|
| − vmem | ρ=4e-3 → 148K | **ρ ≈ 2.6e-3** | prop 기울기 차용 |
| − final_step | ρ=4e-3 → 159K | **ρ ≈ 2.9e-3** | 〃 |
| − loss-ratio | λ=3e-7→201K, 5e-7→152K | **λ ≈ 3.2e-7** | 두 점 사이 보간 (차용 아님) |
| − `1−` 반전 | — | **맞추지 않는다** | 착지점 437K 자체가 증거다 |

총 12런 / 6장 / 약 2.6일. 정찰은 불필요하고 **30에폭(3.5시간)에서 `S30/S1` 로 조기 판정**
가능하다 (prop 10런에서 r=0.978, 착지점 1.6% 오차). **승인 대기.**

### 12-5. `within_channel` 은 어블레이션에서 뺀다 (09-09 결정)

"`1−` 반전이나 vmem 과 달리 **우리가 새로 만든 것이 아니라 고른 것**" 이라서다.
대신 본문에 **설계 선택으로 한 문단**을 쓰고, 코드 주석의 VGG16 관찰을 근거로 든다 —
층 전체 max 를 쓰면 약한 채널이 통째로 지워지고, 과거 VGG16 에서 은닉층 17개가 0% 발화로
죽었다. 리뷰어가 물을 가능성에 대비해 GPU 여유가 나면 n=2 정도 가볍게 확인해 둔다.

### 12-6. 재현성 공백 — `SOURCES` 4개가 git 밖에 있다
