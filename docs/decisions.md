**2026-09-15 — "정확도를 맞추고 스파이크를 비교" 로 재구성해도 이득 없음.**

## 보류

**2026-09-15 — `s_count` 와 뉴런별 npz 총합이 11% 불일치** (188,208 vs 209,080/이미지).

**2026-09-14 — loss-ratio 의 기여는 판단 보류.** n=1 로 결론 냈다가 두 번째 점에서
뒤집힌 전례가 있다. 대조군(`plain L2 + loss-ratio`)이 없으면 "λ 튜닝 불필요" 주장에
증거가 없다. 아직 큐에 없음.

n=22, 오프셋 `+0.064 ± 0.050%p`, t=1.28, 95%CI [−0.034, +0.162].
plain L2 스윕 4점이 더 들어와야 기울기 추정이 안정된다.

## 경쟁 논문

**2026-09-15 — ICLR 2024 (Shi/Ding/Hao/Yu, "Towards Energy Efficient SNNs: An
Unstructured Pruning Framework")가 정면 경쟁자.**
CIFAR-10 에서 −0.21% 손실에 뉴런 21%, −2.19% 에 뉴런 8.23%.
→ **뉴런 희소성으로는 이길 수 없다.** 우리가 설 자리는 "규제 항 하나로, 마스크·재학습·
추가 파라미터 없이". 그리고 `ours_layer` 가 채널을 죽이면 **구조적** 프루닝 각도
(비구조적은 전용 하드웨어 필요, 구조적은 아무 장치에서나 먹음).

**2026-09-15 — BPSR (Yan et al. 2022) 식(4)은 우리 plain L2 와 다르다.**
제곱 L2 vs 제곱근. BPSR 기울기는 λ 상수, 우리 쪽은 λ/√N 으로 **층별 30배, 학습 중 2배**
변한다. λ 재조정으로 흡수되지 않는다. → 별도 비교군으로 구현·스윕 중.

## w¹ vs w² (2026-09-18)

**2026-09-18 — `ours_w1`(w¹ 기울기) 4점 완주. 같은 스파이크에서 w² 나 plain L2 와 구별 안 됨.**
ANCOVA 오프셋: w² 대조 −0.107 ±0.202, L2 대조 +0.006 ±0.158, 합침 −0.049 ±0.158 (전부 p≥0.28).
곡률을 넣으면 +0.022 ±0.146. 직접 쌍 5개 전부 0.5σ 미만.
→ w¹ 은 곡선을 올린 게 아니라 **같은 ρ 눈금에서 곡선을 더 멀리 끌고 간 것** (5e-3 에서
107K/95.96 완주; w² 는 같은 ρ 에서 214에폭 사망). 가중 모양 변형이 크기만 바꾼다는
다섯 번째 확인. Method 절은 실제로 돌린 w² 를 쓰고 "w¹ 도 같은 곡선" 한 줄.
각 ρ n=1 — 0.16%p 미만 차이는 검출 불가. 배제 적용 시 유효점 2개라 엄밀히는 판단 보류.

**2026-09-18 — 파레토 곡선은 log-linear 가 아니다.** 2차항 t=−3.26 (p=0.003): 고스파이크
평평, 저스파이크 가파름. 기존 log-linear ANCOVA 결론(BPSR·plain L2·ours 비교)은
곡률 넣고 재검토 필요. 아직 안 했음.

**2026-09-18 — 배제 규칙 S30/S1≥0.19 는 사실상 "eval 스파이크 ≥ 약 163K" 예산 하한이다.**
`S30/S1 = −2.449 + 0.220·ln(spikes)`, 잔차 SD 0.0095, n=36, 그룹 더미 무의미(w¹ +0.018).
방법을 가리지 않고 저스파이크 구간을 통째로 잘라낸다. 붕괴 런 탐지라는 원래 목적과
다르게 작동하고 있음. 규칙을 바꿀지는 별도 결정 — 바꾸면 사전 등록 위반이므로
바꾸더라도 두 결과를 나란히 보고한다.

## ours_ch 와 R 팽창 (2026-09-19)

**2026-09-19 — `ours_ch`(채널 합 경쟁) 실패. 원인은 "1등 채널 면제"가 아니라 `R` 팽창이다.**
30에폭 S30/S1: ours(wc) 0.27 / ours_ch(β=1) 0.376 / β=0.7 **0.390** / β=0.4 0.363.
β 를 내려도 안 되고 β=0.7 은 더 나빠졌다 — 진단이 틀렸다.

40에폭 실측: reg_R = 12,309(wc) / 24,002(β=1) / **29,735(β=0.7)**,
adp_lambda = 3.52e-7 / 1.78e-7 / **1.42e-7**.

기전: `channel` 묶음은 대부분 채널이 ch≪ch_max 라 w≈1 로 거의 균일 → R=‖spike·w‖ 팽창
→ loss-ratio 가 λ=ρL/R 로 λ 를 줄임. 그런데 실제 기울기는
  λ·w²/R = ρL·w²/**R²**
라 R 의 **제곱**에 반비례한다. λ 를 1/R 로 줄이는 보상으로는 못 따라간다.
β 를 내리면 w 가 1 에 더 가까워져 R 이 더 커진다 — 고치려던 방향이 거꾸로다.

**일반 교훈: loss-ratio 아래에서 가중을 평평하게 만드는 변형은 자기파괴적이다.**
제어기는 R 로 정규화하는데 기울기는 R² 로 나뉜다. "가중 모양 변형이 크기만 바꾼다"는
기존 관측의 **기전**이 이것이다. 곡선을 옮기려면 R 을 키우지 않으면서 모양을 바꿔야 한다
(예: mean(w) 를 고정하는 `reg_spike_shape_mean1`, 또는 R 정의 자체를 바꾸기).

**2026-09-19 — `ours_ch` 3점 완주로 확정.** 2e-3 382,188/96.77, 3e-3 347,822/96.64,
4e-3 312,597/96.75 (전부 유효, 각 n=1). ρ 를 2배 올려도 스파이크가 18% 만 준다
(ours 는 34%). 정확도는 나쁘지 않지만 그 대역은 plain L2 5e-8(381K, 96.77)과 같은 지점 —
곡선 위다. R 팽창 기전(위 항목)으로 설명된다. **팔 종료.**

**2026-09-19 — baseline n=5 확정: 96.73 / 486,445.** s11/s12/s13(138) + s14/s15(23).
23 두 런이 96.87 / 96.64 로 갈려 **서버 효과는 보이지 않는다** (23 평균 96.76 vs 138 96.71,
시드 산포 안). plain L2 4.5e-7 에서 23 이 −0.195 였던 것과 부호가 반대라 계통 차로 못 읽는다.

## SynOps 축 (2026-09-20)

**2026-09-20 — SynOps 축으로 바꿔도 결론이 같다. x축은 스파이크로 유지한다.**
ResNet19 fan-out: 32×32 = 1,105~1,233 / 16×16 = 2,116 / 8×8 = 3,872 (해상도가 낮을수록 비싸다).
`lib_snn/neurons.py:1225` 의 `reg_spike_layer_cost='synops'` 상수표는 **VGG16 전용**이라
ResNet 층 이름은 전부 `.get(name, 1.0)` 으로 1.0 에 떨어진다 — 지금까지 무효였다.

- ours 는 **싼 층(32×32)을 더 줄이고 비싼 층(conv3)을 덜 줄인다**. SynOps 축에서 불리.
  conv2 SynOps 비중 plain L2 32.4% → ours 27.9%, conv3 40.3% → 44.4%.
- 같은 예산 @200k 에서 SynOps/스파이크: plain L2 1,432.9 기준 **ours +2.09 ± 0.17%**
  (n=15 vs 15, 시드 SD 0.5% → 12σ). 1-softmax +1.92%, ours_layer +1.89%. **실재하는 차이다.**
- 그러나 축을 바꾸면 전부 불리해진다: 무손실 감축 −60.0% → **−54.1%**,
  ours vs plain L2 오프셋 +0.080 ± 0.040 (p=0.053) → **+0.074 ± 0.040 (p=0.074)**,
  규제 6종 한 곡선 F 1.55 → **1.43** (더 붙는다).
- 이유: 비용 차 2.09% = ln 0.021 × 기울기 0.425 = **등가 정확도 0.009%p**, 시드 SD 의 1/13.

→ **주 축은 스파이크. SynOps 는 "축을 바꿔도 같은 곡선"이라는 강건성 표 하나.**

**따라 나오는 다음 실험 후보 — 층 비용 가중 규제.** `reg_spike_layer_cost` 를 ResNet19
fan-out 으로 확장하면 규제가 비싼 층을 우선 줄인다. 지금 6종이 전부 싼 층부터 비우므로,
이건 분포 **모양**이 아니라 **겨냥 대상**을 바꾸는 첫 팔이다. SynOps 축에서 곡선을 옮길
유일한 후보. (미착수)

한계: npz/`s_count` 불일치가 방법마다 다르다 (baseline 1.053, plain L2 1.107, ours 1.111)
→ npz 기반 절대 감소율은 못 쓴다. fan-out 규약(BN 흡수·항등 무비용·GAP 접기)에 따라
절대 cost 는 최대 8% 움직이나 방법 간 차이는 ±0.13%p 안에서 불변.

**2026-09-20 — `- 1- inversion` 등스파이크 판정 가능해짐. 기존 인상이 틀렸다.**
ρ 를 4e-3 → 2e-2 / 4e-2 / 8e-2 로 올리니 441K → 264K(96.83) → 164K(96.27) → 101K(96.69, 배제).
스파이크 맞춘 쌍(각 n=1): ours 5e-3 162,846/96.42 vs `- 1-` 4e-2 163,844/96.27 (−0.15);
ours 2e-3 290,020/96.64 vs `- 1-` 2e-2 263,742/96.83 (+0.19). **부호가 갈린다.**
→ "1− 역전이 없으면 스파이크를 못 줄인다"는 인상은 **틀렸다.** ρ 만 올리면 같은 곡선 위로 온다.
역전의 역할은 **ρ 눈금을 맞추는 것**이지 곡선을 올리는 것이 아니다.
이로써 어블레이션 4종(vmem / final_step / loss-ratio / 1− inversion)이 전부 등스파이크
판정 가능해졌고, **넷 다 "같은 곡선" 쪽**이다.

## 다음 방법 후보 — 세 축 (2026-09-20 검토, 미착수)

**왜 지금까지 다 실패했나 — 한 식으로.**
  g_i = (ρL/R)·(w_i²/R_ℓ)·h(v_i),   R_ℓ = ‖s_ℓ·w_ℓ‖  (층별)
- (a) `w` 의 **스케일은 무의미**하다. w→c·w 면 R→cR, λ→λ/c, w²→c²w² 로 정확히 상쇄.
  `shape_mean1` 류는 no-op. (앞서 "R 팽창" 으로 설명한 것은 **틀렸다** — 스케일이 아니라
  발화/침묵 뉴런 간 w **대비**가 분모 Σs²w² 를 정하는 것이 실제 기전이다.)
- (b) `R` 이 **층별**이라 층 간 우선순위가 식에 없다. λ 만 전역. → 층 비율 불변(2.6→2.5).
- (c) `w` 가 **표본·타임스텝 하나**의 함수. 표본마다 승자가 바뀌어 압력이 흩어진다.
  → 활성 뉴런 −6.3% 에 그친 이유.
**10개 변형이 전부 `w` 의 모양만 바꿨다.** (a) 때문에 무효이고 (b)·(c) 는 미착수다.

**A. 층 비용 가중** — `g_i → c_ℓ·g_i`, `c_ℓ = fanout_ℓ / 평균`. 0.55~1.93 (3.5배 폭).
목적함수가 스파이크 수 → SynOps 로 바뀐다. 지금 6종은 전부 싼 층부터 비운다
(ours: conv2 32.4→27.9%, conv3 40.3→44.4%) — 정반대 방향.
판정: 정확도–SynOps 평면에서 기존 곡선 **위**. 총 스파이크는 늘 것이고 그건 예상된 결과.
**선행 조건: 논문 x축을 SynOps 로 할지 결정.** 축을 바꾸면 다른 수치가 전부 나빠진다.
비용: `neurons.py` 상수표(VGG16 자리) + 3~4런.

**B. 시간 축 (조기 종료)** — `‖Σ_t γ^t s_t·w‖`, γ>1 이면 뒤 스텝이 비싸 정보가 앞으로 몰린다.
**지연×정확도는 아무도 안 본 축이고 정확도–스파이크 곡선과 직교한다.**
같은 스파이크·같은 정확도인데 T=2 에서 답이 나오면 순수 이득.
**선행 측정이 공짜**: 기존 체크포인트를 T=1,2,3 으로 평가 → 지금도 방법마다 시간 분포가
다른지. 추론 몇 분. 다르면 축이 살아 있다는 신호.
위험: γ 크면 뒤 스텝이 죽어 실질 T 가 줄고 정확도가 빠진다. γ 스윕 필요.

**C. 표본 간 누적 가중** — `r_i ← (1−α)r_i + α·1[발화]` (stop_gradient), `w = 1 − r/max(r)`.
데이터셋 전체에서 꾸준히 약한 뉴런에만 **압력이 누적**된다. 활성 뉴런 수를 직접 겨냥하는
유일한 길. 판정: 같은 스파이크에서 활성 뉴런이 ours(1,006,582)보다 유의하게 적고 96.5 유지.
위험: **되돌아올 길이 없는 래칫.** 초반에 우연히 약했던 뉴런이 영구히 죽는다.
과거 `adaptive v2/v3`·`early-reg` 실패와 닮았다 — **그 실패 원인 확인이 선행**.

권장 순서: **B 측정(추론 몇 분) → A(축 결정 후) → C(과거 실패 검토 후)**.

## `- 1- inversion` 은 단일 요소 어블레이션이 아니다 (2026-09-20)

**2026-09-20 — 코드 확인 (`lib_snn/neurons.py:938-944`).** `maxnorm_plain` 분기는
`reg_spike_maxnorm_group` 을 **안 읽고**(`reduce_axis` = 층 전체), vmem readiness 도
**안 쓴다**(`self.spike_count` 직접, `scp` 아님). config 에 `vmem_gain=1.0` 이 켜져 있어도 무시된다.
→ 지금 표의 `- 1- inversion` 은 실제로 **"− 역전 − within_channel − vmem"** 세 요소 동시 제거다.
**논문 어블레이션 표에 "1− 역전의 효과"로 쓰면 안 된다.**
분리하려면 `maxnorm_plain` 에 within_channel 묶음 + vmem 을 붙인 팔 1~2런이 가장 싸다.
