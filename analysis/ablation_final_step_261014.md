## 정의

- **final_step (켜짐, 제안법)**: 규제 블록이 t=T 에서 한 번만 돈다. 벌점 = λ·Σ_l ‖(Σ_t S_t)⊙w_l‖₂, w = 1 − c/max c (c = 채널 공간합, t=T 의 누적 발화 + 침묵 뉴런의 막전위 준비도). backward (wta_rev) 는 모든 뉴런·모든 t 에 λ·w²/R_l 을 준다 (R_l = 그 층의 노름).
- **`- final_step` (꺼짐)**: 규제 블록이 매 스텝 돈다. 벌점 = λ·Σ_l Σ_t ‖S_t⊙w_{l,t}‖₂, w_{l,t} 는 t 까지의 누적 발화 (+ t 의 준비도) 로 매 스텝 다시 계산. 스텝 t 의 뉴런은 λ·w_t²/R_{l,t} 를 받는다 (R_{l,t} = 그 스텝만의 노름).
- **R**: loss-ratio 가 쓰는 원값 벌점. 켜짐 R = Σ_l ‖(ΣS)⊙w‖, 꺼짐 R = Σ_l Σ_t ‖S_t⊙w_t‖ (sc_loss_snap 이 스텝마다 누적, neurons.py:1213-1218). **λ_{e+1} = ρ·L_e/R_e** (L = 규제 뺀 과제 손실).
- **ρ 배율**: `- final_step` 이 ρ 에서 착지한 스파이크를 ours 가 내려면 필요한 ρ 의 비 (ln s = a + b·ln ρ + c·[nofinal] + e·[23] 에서 exp(c/b), Fieller 구간).
- **기울기 배율 K**: 같은 스파이크·같은 w 에서 λ 한 단위가 뉴런에 주는 기울기의 비 (꺼짐/켜짐) = E[R_{l,f}/R_{l,t}]. 같은 압력이면 λ_f/λ_n = K 여야 한다.
- **같은 스파이크 차 (ANCOVA)**: y = a + b·ln(spikes) + c·[nofinal] + e·[서버 23], ours_inter_ch 200~420K 완주·비배제. c 가 오프셋. 정확도 축은 nofinal_vs_inter_261014 와 같은 모형.
- **이미지당 침묵 %** (학습 모드): 한 이미지에서 T 동안 한 번도 안 쏜 뉴런 비율 (배치 평균, 뉴런 수 가중). **지니·상위 10%**: 층 안 뉴런 스파이크 집중도 (층 스파이크 가중). **죽은 채널** (npz): 테스트 1만 장 합이 0 인 채널.

### 3b. 기울기 배율 K — 스텝별 노름이 압력을 얼마나 키우나

wta_rev backward 는 뉴런 (발화 여부 무관) 에 λ·w²/(그 노름) 을 준다. 켜짐은 모든 t 가 같은 R_{l,f} 로 나뉘고, 꺼짐은 스텝 t 가 R_{l,t} 로 나뉜다. w_t ≈ w (발화 뉴런의 평균 w² 가 스텝마다 같다) 라고 두면 R_{l,t} ∝ √(그 스텝 스파이크 수) 이므로 R_{l,t} = R_{l,n}·√p_t / Σ_s √p_s (p_t = 층의 스텝 몫, npz_t). 그러면 K_l = (R_{l,f}/R_{l,n})·(Σ√p)² (스파이크 가중 평균) 또는 (R_{l,f}/R_{l,n})·(Σ√p)·mean_t(1/√p_t) (스텝 균등 — 비발화 뉴런까지 기울기를 받는 wta_rev 에 더 가깝다). R_{l,n} = `- final_step` 3런 평균 (reg_detail), R_{l,f} = ours 200~420K 층별 ln R ~ ln s 직선의 같은 스파이크 값, p_t = `- final_step` s1 npz_t (n=1, 테스트셋 eval).

- 해석 (검증 안 됨): 착지점은 모든 뉴런에 고르게 주는 기울기가 아니라 **그 스텝에 발화하는 (문턱 근처) 뉴런이 받는 기울기** 로 정해지는 것으로 보인다. 대리 기울기가 문턱 근처에서만 크다는 것과 맞는 해석이다. 이 추정의 입력 (스텝 몫 p_t 는 npz_t, R 비는 reg_detail) 은 착지 스파이크와 독립이라, 일치는 순환 논리가 아니다.
- R_{l,f}/R_{l,n} (층 스파이크 가중) = 0.751 — 같은 스파이크에서 스텝별 노름의 합이 T 합의 노름보다 1.33 배 크다 (삼각부등식 Σ_t‖x_t‖ ≥ ‖Σ_t x_t‖ 의 실제 크기).

## [LIMITATION]

1. `- final_step` 은 **한 ρ (2.2e-3, 약 −42% 스파이크), n=3**. 다른 스파이크 수준 (특히 −30% 구간) 은 진행 중인 6런 (각 n=1~2) 이 완주해야 곡선으로 볼 수 있다. 10-14 사전 등록 규칙 (d 의 95% 하한 > 0 일 때만 final_step 제거) 은 그 런들로 판정한다 — 이 문서는 판정하지 않는다.
2. 같은 스파이크 오프셋 CI [−0.08, +0.17]%p 안의 차이는 이 설계로 볼 수 없다. 조건당 n≤4 규칙 아래서는 하한이 0.17%p 근처다.
3. 기울기 배율 K 는 w_t ≈ w 와 R_{l,t} ∝ √(스텝 스파이크 수) 를 가정한 추정이다. 스텝별 R_{l,t}·w_t 는 로그에 없고, 스텝 몫은 eval (테스트셋) 의 n=1 이다. 실측 λ 비가 스파이크 가중 추정과 맞는다는 것은 일치이지 증명이 아니다.
4. 학습 모드 지표는 마지막 에폭 배치 평균, 정확도·스파이크는 best 에폭 eval 이다. 지표 16개를 보정 없이 검정했다.
5. npz 채널 구조·시간축은 `- final_step` s1 하나 (n=1) 이고, 이미지 합산이라 이미지별 부분 순위를 재지 못한다.
6. 학습 시간 짝 비교의 켜짐 쪽은 ours_inter_ch 가 아니라 같은 시각의 다른 어블레이션 팔 (final_step 켜짐) 이다. 서버·GPU 부하가 시점마다 달라 팔 전체 중앙값 비는 거칠다.
7. intra 교차 확인은 다른 방법 (채널 안 경쟁) 이고, `abl_nofinal` 은 ρ 3개 n=4 (같은 ρ 반복 2런은 4e-3 뿐). ours_layer_w1 판은 런이 없다.
8. spikes 는 s_count 원값이다. s_count 와 npz 총합의 불일치 (09-15 보류) 는 두 팔에 같은 정의를 쓰므로 비율 비교에는 영향이 작다고 보지만 해소되지 않았다.
