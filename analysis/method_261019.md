**정의**
- 정확도 = best val acc, 스파이크 = 그 에폭의 s_count (원장). 예외: SDTv3 는 공식 체크포인트 파인튜닝이라 best 가 에폭 1 근처에 생기므로 **마지막 에폭** 값 (대조 런 마지막 에폭과 비교). QK 는 fp32 model_best 를 테스트 셋에서 재측정한 값.
- **s_count 는 학습 배치 통계다 (2판 정정).** 그 에폭의 학습 패스 (증강된 학습 50,000장, 학습 모드 순전파) 에서 센 이미지당 스파이크다 — `lib_snn/proc.py` 의 `postproc_batch_train_snn → spike_count_batch_end`, 에폭 끝에 `train_ds_num` 으로 나눔; 테스트 배치는 `mode=='inference'` 일 때만 센다. reg_detail.csv 의 같은 에폭 층 합 (n_in 포함) 은 s_count 와 같다 (137런, 불일치 0). 그래서 CSV 지표도 학습 패스 통계다.
- **테스트 셋 npz 와의 비가 팔마다 다르다:** npz/s_count = baseline 1.0535 (n=3, s11~s13, 138), ours_inter_ch 1.081 (n=20), BPSR 1.082 (n=13), plain L2 1.086 (n=11). 그래서 **baseline 대비 % 는 측정 축에 따라 1.5~2%p 달라진다** (R19 C10 표에 두 축을 함께 적었다). 규제 팔끼리의 비교 (inter 대 BPSR·plain L2) 는 비가 같아 영향이 없다. 09-15 결정 "불일치 해소 전 절대 스파이크 수를 논문에 쓰지 않는다" 는 그대로 유효하다 (학습 패스 대 테스트 셋이라는 차이가 불일치를 전부 설명하는지는 확인하지 않았다).
- **R19 의 val 셋은 테스트 셋이다.** best 는 310 에폭 중 테스트 셋에서 고른 최고값이라 절대 정확도가 낙관적이다 (예: inter 3e-3 best 96.72, 마지막 10에폭 평균 96.53, n=4). 팔끼리 비교는 마지막 10에폭 민감도로 확인했다.
- 유효 런 = 완주 (R19 310, VGG 200 에폭), S30/S1 ≥ 0.19 (원장 배제 규칙), 시드 < 900. 미완주·배제 런은 표 끝 부록에 사유와 함께 남겼다.
- 같은 스파이크 비교 = `acc = a + b·ln(spikes) + c·[팔] + d·[서버 23]` (ANCOVA). c = inter − 상대 팔. 같은 정확도 스파이크 비 = exp(−c/b) (inter/상대, 1 보다 작으면 inter 가 적게 씀), 95% 구간은 팔 안 재표본 부트스트랩 10,000회.
- 최소 검출 차 = (t₀.₉₇₅ + t₀.₈₀) × SE. 양측 5%, 검정력 80% 로 잡을 수 있는 가장 작은 차이.
- 비열등 (baseline 대비) = Δacc 의 90% 구간 하한이 −마진 보다 큼 (한쪽 5%). 마진은 아직 사용자 결정 전이라 ±0.15·±0.2 를 둘 다 적는다. **두 마진은 자료를 본 뒤 함께 적은 것이고 미리 정한 값이 아니다.** n=1 묶음은 합동 시드 SD 로 구간을 그렸지만 판정에 쓰지 않는다.
- **합동 SD 판정 (2판 추가):** n≤4 묶음은 그룹 안 SD 가 우연히 작으면 Welch 구간이 좁아진다. 그래서 같은 차를 합동 시드 SD (아래) 로 다시 판정해 함께 적는다. 둘이 다르면 "경계" 로 읽는다.
- 다중비교: 표 안의 p 는 따로 적지 않으면 보정 전이다. 여러 검정을 한 묶음으로 본 곳은 Holm 보정값을 함께 적었다.
- 시드 SD (정확도, 합동): R19 C10 0.110 (자유도 22), C100 0.168 (13), VGGSNN 첫 프레임 0.492 (18), QK C10 0.149 (8), QK C100 0.129 (9).

## 0. 결론

**한 줄:** ours_inter_ch 는 R19 C10 에서 스파이크 −30% (s_count; 테스트 셋 npz 로는 −27%) 까지 baseline 과 비열등이다 — **±0.2 마진이면 best·마지막 10에폭·마지막 에폭 세 기준 모두 성립하고, ±0.15 마진은 경계 위다.** 같은 스파이크에서 BPSR·plain L2 보다 정확도가 높다는 근거도, 같은 정확도에서 스파이크가 적다는 근거도 없다 (R19 C10·C100, 각 n=4 대표점과 곡선 전체). 구조 차이 (같은 스파이크에서 이미지당 활성 뉴런이 적고 채널을 더 끈다) 는 재현되지만 **보조 근거 (B 등급)** 다 — maxnorm 계열 공통 성질이고, 크기가 09-15 에 기각한 크기와 같으며, 뉴런 희소성으로는 Shi 2024 (UPR) 와 거리가 멀다.

1. **baseline 을 지키는 범위 (Q1)**
   - R19 C10: ρ 3e-3 (n=4) **−30.1% (s_count, 학습 패스, baseline n=6) / -27.4% (테스트 npz, baseline n=3)** 에서 Δacc -0.008 %p. 90% 구간: Welch [-0.148, +0.131] (하한이 −0.15 와 0.002 차), 합동 SD [-0.130, +0.113], 마지막 10에폭 -0.024 [-0.132, +0.085], 마지막 에폭 -0.060 [-0.169, +0.049]. → **±0.2 는 네 판정 모두 성립, ±0.15 는 마지막 에폭에서 못 넘는다 (경계).**
   - −38~−43% (ρ 4e-3·4.5e-3 각 n=3, 5e-3 n=1) 은 판정 불가. **손실이 시작되는 점은 −47~−51% 이고 서버가 섞여 있다:** ρ 5.5e-3 (n=3, −47.1%, 3런 모두 138) 은 Welch -0.128 [-0.217, -0.040] p=0.029 로 손실이지만 그룹 SD 가 0.035 로 합동 SD 의 1/3 이라, 합동 SD 로는 [-0.261, +0.005] p=0.11 로 손실이 확인되지 않는다. ρ 6e-3 (n=3, −51.0%, 3런 모두 23) 은 두 판정 모두 손실 (합동 SD p=0.003).
   - R19 C100: ρ 2e-3 (n=4) **−21.5%** (s_count, npz 없음) 에서 +0.001, Welch [-0.180, +0.181] (그룹 SD 0.024), 합동 SD [-0.191, +0.193] → ±0.2 비열등 (두 판정 모두). ρ 3e-3 (n=3, −30.8%) 은 -0.273, Welch [-0.495, -0.052] p=0.053, 합동 SD [-0.484, -0.063] p=0.039 로 손실.
   - VGGSNN 첫 프레임: ρ 1e-3~1e-2 (각 n=4, −19~−75%) 모두 baseline 82.31 ±0.54 (n=4) 과 **차가 검출되지 않는다** (Δ -0.58~+0.18, 모두 p≥0.14, 최소 검출 차 1.1~1.3%p). **다만 점추정과 추세는 손실 쪽이다:** 규제 20런 평균이 baseline 보다 -0.30, 24런 (ρ 2e-2 n=1 제외) 의 정확도–ln 스파이크 기울기 0.36 ±0.23 (p=0.12) 는 −75% 에서 약 -0.5%p 를 가리킨다 (2e-2 포함 n=25 면 p=0.020). 무손실로 읽으면 안 된다.
   - QK C10: ρ 1.2e-2 (n=4) −29.2% 에서 -0.058 [-0.25, +0.13] (90% 하한 -0.249: ±0.2 마진은 못 넘고 ±0.25 면 겨우 비열등). ρ 2e-2 (n=1) −44.0% 에서 -0.02 이지만 n=1 → 판단 불가.
   - QK C100: ρ 6e-3 (n=4) **−10.6% 에서 이미 -0.30 [-0.49, -0.10], p=0.025** → 무손실 구간을 찾지 못했다.
   - SDTv3 (ImageNet, 각 n=1, 마지막 에폭): ρ 0.1 −6.3% 에서 +0.02, ρ 0.2 −11.5% 에서 -0.19, ρ 0.3 −15.9% 에서 -0.27. ImageNet 시드 SD 를 재지 않아 판단 불가. KD 4런은 진행 중 (10-20~22 완주 예정).

2. **plain L2·BPSR 대비 같은 스파이크 정확도 (Q2) — 차이 검출 안 됨**
   - 표1 점 (R19 C10, 각 n=4): ours_inter_ch 96.72 @ 342,075, BPSR 96.70 @ 322,503, plain L2 96.58 @ 324,888. **BPSR 이 inter 보다 스파이크 5.7% 적은 점에서 정확도 차가 검출되지 않는다** (inter − BPSR +0.02 [-0.17, +0.21], 최소 검출 차 0.25; 기울기로 스파이크 차를 보정하면 +0.001 ±0.076). 동등성 검정은 하지 않았으므로 "같다" 가 아니라 "구분되지 않는다" 다. plain L2 대비 보정 차는 +0.12 ±0.09.
   - baseline (n=6) 대비로는 BPSR 1e-10 (n=4) 도 -34.1% (s_count) / -31.7% (npz) 에서 -0.028, Welch 하한 -0.1494, 합동 SD 하한 -0.1499, 마지막 에폭 하한 -0.194 → **inter 와 마찬가지로 ±0.15 경계 위, ±0.2 는 성립.** "−30% 에서 무손실" 은 inter 만의 결과가 아니다. plain L2 1e-7 (n=4, -33.6% / -31.4%) 은 -0.146, Welch [-0.294, +0.002] 이지만 합동 SD 로는 [-0.267, -0.024] 로 손실 쪽이다.
   - ANCOVA, 300~420K (n=27: inter 12, plain L2 8, BPSR 7): inter − BPSR +0.021 [-0.072, +0.114] p=0.64, inter − plain L2 +0.080 [-0.009, +0.170] p=0.077. 180~420K (n=63): -0.026 [-0.093, +0.041] / +0.005 [-0.054, +0.065].
   - 같은 정확도 스파이크 비 (180~420K, 기울기 0.334 ±0.050 로 잘 잡히는 구간): inter/BPSR **1.08 [0.91, 1.24]**, inter/plain L2 0.98 [0.79, 1.17]. 300~420K 는 기울기가 0 과 구분되지 않아 (0.18 ±0.18) 비가 정의되지 않는다 (구간 [0.12, 1.53]).
   - 최소 검출 차: 300~420K 에서 0.13%p, 180~420K 에서 0.10%p. BPSR 대비 우위가 있다 해도 95% 상한이 +0.11 (300~420K) / +0.04%p (180~420K) 라, 그보다 큰 우위는 이 자료로 **배제**된다.
   - C100 (290~420K, n=25): inter − plain L2 +0.02 [-0.13, +0.17], inter − BPSR +0.01 [-0.18, +0.21].
   - QK C10 (plain L2 만, ρ 마다 n=1): 662K 에서 +0.08 [-0.22, +0.39]. 524K 에서 inter ρ 2e-2 (n=1) 가 plain L2 보간보다 +0.60 높지만 n=1 대 n=1 이고, 학습 로그 최고값 기준이면 +0.24 로 줄어든다 → 판단 불가.
   - **사용자 요구 ("BPSR 대비 같은 정확도면 스파이크 적게 / 같은 스파이크면 정확도 높게") 는 지금 자료로 보일 수 없다.** 자료가 가리키는 것은 차이가 검출되지 않는다는 것이다 (180~420K 의 95% 구간이 ±0.1%p 안, 같은 정확도 스파이크 비 0.9~1.25 안 — 선형·공통 기울기 가정, 동등성 검정은 하지 않음).

3. **구조 (Q3) — 차이는 재현되지만 보조 근거 (B 등급, 2판에서 내림)**
   - 표1 점 npz (테스트 1만 장, inter 4 / BPSR 4 / plain L2 4 런, baseline 3): 죽은 채널 (/4,736) inter 652.5 vs BPSR 587.0 vs plain L2 596.8 (baseline 534.0); 지울 수 있는 밀집 MACs (시나리오 a) 24.5 / 19.8 / 20.6% (baseline 17.5). 단 inter 쪽 npz 스파이크가 6% 많은 점끼리이고, n=4 Welch 24개 검정이라 죽은 채널 (p_Holm 0.11 / 0.17)·MACs a (0.09 / 0.11)·활성 뉴런 (0.26 / 0.09) 은 보정 뒤 유의하지 않다. 주 근거는 아래 같은 스파이크 ANCOVA 다.
   - 같은 스파이크 (npz, 300~420K, n=25: inter 12, plain L2 6, BPSR 7): 죽은 채널 BPSR 대비 +56.5 [+34.4, +78.6] (채널의 1.19%p), MACs (a) +4.04 [+2.70, +5.39]%p, 이미지당 활성 뉴런 -5.9% [-7.0, -4.8].
   - 활성 뉴런 감소는 스파이크 수준에 따라 다르다 (팔마다 기울기를 따로 둔 모형, CSV 지표, BPSR 대비): C10 400K -3.9%, **342K -6.7% [-7.4, -6.0]**, 310K -8.4% (n=27); C100 **354K -6.0% [-7.8, -4.2]** (n=25, C100 BPSR 은 n=4 이고 293~342K 에만 있어 342K 위는 외삽). 스파이크를 줄일수록 차가 커진다. 공통 기울기 모형의 숫자 하나 (C10 -5.8%, C100 -7.2%) 는 기울기 차가 유의해 (기울기 차 C10 p<0.001, C100 p<0.001) 구간 평균일 뿐이다. CSV 와 npz 의 활성 뉴런 비는 팔마다 다르지만 (baseline 0.974 n=3, 규제 팔 0.949~0.954), 같은 구간의 팔 대비는 CSV -5.8% (n=27) 와 npz -5.9% (n=25) 로 맞는다.
   - **위치 (2판 추가):** 표1 점에서 inter 는 채널의 86.2% 가 살아 있고 (BPSR 87.6%), 테스트 1만 장에서 한 번도 안 쏜 뉴런은 20.0% (BPSR 16.5%, baseline 13.1%), 이미지당 활성 뉴런은 전체의 16.2% (BPSR 16.7%) 다 (각 n=4). Shi 2024 (ICLR, UPR) 는 CIFAR-10 −0.21% 손실에 뉴런 21% 만 남긴다 (09-15 인용) — **뉴런 희소성으로 비교할 위치가 아니다** (09-15 결정 그대로).
   - **등급을 내린 이유:** (1) 활성 뉴런 감소는 maxnorm 계열 공통 성질이다 (10-14 E8: ours_layer·ours_intra_ch 대비 −1.0~−1.2%). (2) 죽은 채널 +56.5/4,736 (1.19%p) 는 09-15 에 "구조적으로 쓸 수 없다" 고 기각한 크기 (+50개, 1.06%p) 와 같다. (3) 10-10 사용자 결정에서 구조 지표는 보조 근거다. (4) 이벤트 구동 하드웨어의 효율 이득이 아니다 (같은 스파이크면 SynOps 차 0.4% 이하, 10-09) — 밀집 연산·가중치 메모리에서만 의미가 있고 실측이 없다.
   - 단계 배분: BPSR 대비 inter 는 conv1 몫이 +1.2%p (C10) / +1.0%p (C100) 크다 — conv1 을 덜 줄인다. plain L2 와는 차이 +0.2 / -0.0%p.

4. **구성요소 (요약, R19 C10, 342K 근처 각 n=4)**
   - `- vmem` 은 같은 스파이크에서 inter 곡선보다 낮은 쪽이다: inter − (- vmem) +0.098 [+0.010, +0.185] p=0.029 (n=27/9), 마지막 10에폭 기준 +0.098. **그러나 구성요소 4팔 검정을 Holm 으로 보정하면 p=0.12 로 유의하지 않다.** 서버별로는 138 +0.17, 23 +0.01 이지만 팔×서버 상호작용 p=0.095 이고 23 의 - vmem 은 n=3 이라, "138 에서만 보인다" 도 "서버와 무관하다" 도 판정할 수 없다. BPSR·plain L2 를 함께 넣은 4팔 모형 (180~420K) 에서 - vmem − BPSR -0.112 [-0.202, -0.021] (p=0.016), - vmem − plain L2 -0.086 [-0.171, -0.001] (p=0.047) 로 균등 규제보다 낮은 쪽이다 → vmem 의 몫은 "inter 를 균등 규제보다 낫게" 가 아니라 "inter 가 균등 규제보다 떨어지지 않게" 로 읽힌다 (이것도 보정 전 p).
   - `- 1- inversion` (n=5; 대표 4런은 모두 ρ 4.5e-3·138 서버) 은 정확도 차가 검출되지 않는다 (-0.012 [-0.111, +0.088]; "그대로" 가 아니라 "차가 검출되지 않음"). 구조는 달라진다: **층 안 뉴런 지니 상승은 사라지고 균등 규제보다도 낮아진다** (대표점 지니 inter 3e-3 0.551, BPSR 1e-10 0.503, plain L2 1e-7 0.498, - 1- inversion 4.5e-3 0.457, 각 n=4; 같은 스파이크 4팔 모형 - 1- inversion − BPSR -0.044 [-0.056, -0.031], 300~420K). **활성 뉴런 감소는 사라지지 않는다.** 1− 반전이 설명하는 몫은 inter − BPSR 차의 약 62~71% 이고, - 1- inversion − BPSR 이 300~420K -1.74% [-3.42, -0.04] (n=4), 180~420K -3.48% [-5.52, -1.39] (n=5) 로 남는다 (같은 모형의 inter − BPSR 은 -5.8% / -8.9%). 138 서버만 보면 300~420K -1.67% [-3.79, +0.49] 로 0 을 포함한다.
   - `- final_step`·`- loss-ratio` 는 정확도 차 검출 안 됨 (+0.066, +0.034; 최소 검출 차 0.14~0.16%p; Holm p 0.53, 1.00).

5. **10-14 대비:** BPSR 대비 정확도 오프셋은 +0.050 (p=0.27) → +0.02 (p=0.64) 로 약해졌고, 표1 점에서는 BPSR 이 스파이크 5.7% 적은 점에서 정확도 차가 검출되지 않는다. 구조 차이 (활성 뉴런·죽은 채널) 는 n=4 표1 점·C100 으로 재현됐지만 2판에서 보조 근거로 내렸다. 자세한 대조는 5절.

## 3. 구조 — 스파이크 감소가 어디에 어떻게 나뉘는가 (Q3)

**지표 정의** (`struct_compare_261007` 과 같음)
- 죽은 채널: 테스트 1만 장 전체에서 공간 모든 위치가 한 번도 안 쏜 채널 (/4,736 = conv 4,480 + fc1 256). "완전 침묵 채널" 과 같은 말.
- MACs 제거 %: 죽은 채널을 물리 제거할 때 줄어드는 밀집 MACs 비율. 시나리오 a = 잔차 합류점 (`_out_n`) 채널은 지우지 않음 (논문 보고용), b = 모두 지움.
- 이미지당 활성 뉴런: 이미지 한 장에서 T 스텝 동안 한 번이라도 쏜 뉴런 수 (전체 1,442,048). ln 으로 회귀하고 % 로 환산.
- 채널 지니 (층 스파이크 가중): 층 안 채널별 총 스파이크의 지니. 0 = 고르게, 1 = 한 채널에 몰림. 뉴런 지니: 전체 뉴런의 총 스파이크 지니.
- 스텝/활성쌍: 뉴런이 어떤 이미지에서 쐈을 때 T=4 중 평균 몇 스텝 쐈나.
- 단계 몫: 전체 스파이크 중 conv1 (1층)·conv2 (6층, 32×32)·conv3 (6층, 16×16)·conv4 (4층, 8×8) 의 비율 (%).
- CSV 지표 (모든 런, reg_neuron_detail.csv · reg_detail.csv 의 best 에폭 행): 활성 뉴런 = Σ층 뉴런 수 × (1 − 표본별 0 스파이크 비율), 층 안 뉴런 지니 (층 스파이크 가중), 단계 몫. **2판 정정: 이 CSV 는 "학습 중 평가 기록" 이 아니라 그 에폭 학습 배치에서 누적한 통계다** (s_count 와 같은 경로, 정의 절).
- npz 지표는 테스트 1만 장을 추론 모드로 한 번 돌린 값이다. CSV 와 npz 는 데이터 (증강된 학습 셋 대 테스트 셋) 와 모드가 다르다.

### 3.4 해석

- 같은 스파이크에서 inter 는 **더 적은 뉴런이 더 몰아서** 쏜다 (활성 뉴런 342K 에서 BPSR 대비 -6.7%, 층 안 지니 +0.05). BPSR·plain L2 는 발화하는 뉴런의 스텝을 고르게 깎는다 (10-09 의 스텝/활성쌍 결과와 같은 방향). 이 모양 차이는 C10 과 C100 에서 비슷한 크기다 (C100 354K -6.0%).
- **이 모양 차이의 대부분은 inter 고유가 아니다.** 활성 뉴런 감소는 maxnorm 계열 (ours_intra_ch·ours_layer) 공통이고 inter 와 그 둘의 차는 −1.0~−1.2% 뿐이다 (10-14 E8, 인용). 구성요소로는 1− 반전이 inter − BPSR 차의 약 60~70% 를 설명한다 (4절).
- 채널 단위로 보면 그 차이의 일부가 "채널 전체가 꺼짐" 으로 나타난다 (죽은 채널·MACs). 다만 채널 사망은 inter 스파이크 감소의 약 9% 뿐이고 (10-14 인용, n=19), 대부분은 산 채널 안의 연속적인 감소다. 크기도 채널의 1.2%p 로 09-15 에 기각한 크기 (1.06%p) 와 같다.
- 단계 배분은 BPSR 과 1~2%p 안에서만 다르다 (inter 가 conv1 을 덜, conv2·conv3 를 조금 더 줄임; npz 표1 점 conv1 몫 inter 17.3% vs BPSR 15.4%, baseline 17.9%). plain L2 와는 300~420K 에서 차이가 없다. 층 배분은 주장의 근거가 될 만큼 크지 않다.
- **정확도와는 연결되지 않는다.** 같은 스파이크에서 정확도 차가 검출되지 않는데 구조만 다르므로, 구조 차이는 "같은 정확도·같은 스파이크에서 다른 해를 찾는다" 로만 쓸 수 있다. 10-14 에 적은 팔 안 상관 (죽은 채널이 많을수록 정확도가 낮음, r=−0.38, 인용) 도 그대로다.
- **이벤트 구동 하드웨어의 효율 이득이 아니다** (같은 스파이크면 SynOps 차 0.4% 이하, 10-09 인용). 밀집 연산·가중치 메모리에서만 의미가 있고, 채널을 실제로 지운 뒤의 정확도·지연은 재지 않았다.

### 5.2 주장 계층 (10-19)

**A. 강함 — 경계 문구와 함께 쓸 수 있다**

1. **R19 C10 에서 −30% 까지 baseline 과 비열등 (±0.2 마진).** ρ 3e-3 (n=4), 스파이크 -30.1% (s_count, 학습 패스) / -27.4% (테스트 npz, baseline n=3). Δ -0.008; 90% 하한 Welch -0.148, 합동 SD -0.130, 마지막 10에폭 -0.132, 마지막 에폭 -0.169. 함께 적을 것: **±0.15 는 경계** (마지막 에폭에서 못 넘음), 마진은 사후에 적은 값, BPSR 1e-10 (n=4) 도 -34.1% / -31.7% 에서 같은 경계로 비열등, plain L2 1e-7 (n=4) 은 합동 SD·마지막 에폭 기준 손실 쪽. "유일" 은 쓰지 않는다. 절대 정확도는 best (테스트 셋 선택) 라 낙관적이다.
2. **R19 C100 에서 −21.5% 까지 비열등** (ρ 2e-3, n=4, ±0.2 마진, Welch·합동 SD 둘 다; s_count 축, npz 없음). −31% (ρ 3e-3, n=3) 에서는 -0.273 손실 (합동 SD p=0.039).

**B. 단서가 붙어야 쓸 수 있다 (부록·보조 문장)**

3. *(1판 A3 에서 내림)* **같은 스파이크에서 이미지당 활성 뉴런이 균등 규제보다 적다** — 342K 에서 BPSR 대비 -6.7% (C10, n=27), 354K 에서 -6.0% (C100, n=25); 스파이크를 줄일수록 커진다. 함께 적을 것: maxnorm 계열 공통 성질 (ours_layer·ours_intra_ch 대비 −1.0~−1.2%, 10-14 E8); 1− 반전이 그 차의 약 60~70% 를 설명; Shi 2024 (UPR) 는 −0.21% 손실에 뉴런 21% 만 남기는데 inter 는 한 번도 안 쏜 뉴런이 약 20% — 뉴런 희소성으로 경쟁할 위치가 아니다; 이벤트 구동 하드웨어 이득 아님; 10-10 결정대로 보조 근거.
4. *(1판 A4 에서 내림)* **R19 C10 에서 같은 스파이크에 채널을 더 끈다** (죽은 채널 BPSR 대비 +56.5 = 채널의 1.19%p, MACs a +4.04%p, npz n=25). 함께 적을 것: 09-15 에 같은 크기 (+50개, 1.06%p) 를 "구조적으로 쓸 수 없다" 고 기각한 이력; inter 도 채널의 86% 가 살아 있음; 표1 n=4 Welch 는 Holm 뒤 비유의; baseline 도 MACs a 17.5% 를 이미 지울 수 있음; SynOps 이득 없음; 실제로 지운 뒤의 정확도·지연 측정 없음; C100·QK·DVS 는 재지 않음.
5. *(1판 A5 에서 내림)* **스파이크 감소 방향은 R19·QK·VGGSNN·SDTv3·Speck 칩에서 같다.** 함께 적을 것: 벌점을 걸면 스파이크가 주는 것은 어느 방법에서나 기대되는 결과라 기여 주장이 아니다; 칩 전력 −35% (10-15 인용) 는 **학습 n=1 런 하나를 반복 측정**한 값이다; 무손실 폭은 과제가 어려울수록 준다 (C10 −30% → C100 −21% → QK C100 −10% 에서 이미 손실).
6. **BPSR·plain L2 와 같은 스파이크에서 정확도 차가 검출되지 않는다.** 180~420K 에서 BPSR 대비 -0.026 [-0.093, +0.041], plain L2 대비 +0.005 [-0.054, +0.065] (n=63; 선형·공통 기울기·best 기준). 동등성 검정은 하지 않았다. "정확도를 잃지 않고 구조가 다르다" 의 앞부분으로만 쓴다.
7. VGGSNN 첫 프레임: −75% (ρ 1e-2, n=4) 까지 baseline 과 **차가 검출되지 않는다.** 함께 적을 것: 검출 한계 ~1.2%p (시드 SD 0.49); 점추정·추세는 손실 쪽 (−75% 에서 약 -0.5%p, 규제 20런 평균 -0.30); 첫 프레임 입력은 정적 입력 (메모리 dvs-input-protocol). 무손실로 쓰지 않는다.
8. QK C10: −29% (ρ 1.2e-2, n=4) 에서 Δ -0.06 [-0.25, +0.13] — ±0.25 마진이면 비열등. QK 스파이크는 테스트 셋 재측정 축.
9. `- vmem` 은 같은 스파이크에서 정확도가 낮은 쪽이다 (+0.098, n=27/9, 보정 전 p=0.029). 함께 적을 것: **구성요소 4팔 Holm 보정 뒤 p=0.12 로 유의하지 않음**; 서버 차이는 판정 불가 (23 의 - vmem n=3, 상호작용 p=0.095); 효과 방향은 BPSR·plain L2 보다 낮아지는 쪽 → "vmem 이 inter 를 균등 규제보다 떨어지지 않게 한다" 로만 쓴다. "필수 요소" 로 쓰지 않는다.
10. `- 1- inversion`: 정확도 차 검출 안 됨 (n=5, 4런은 한 ρ·138). 1− 반전을 빼면 지니 상승은 사라지고 균등 규제보다도 낮아진다; 활성 뉴런 감소는 줄지만 BPSR 대비 -1.7~-3.5% 가 남는다.
11. 학습 비용이 다른 경쟁 범위 팔과 같다 (10-14 E20, 인용).

**C. 쓰면 안 되는 문장**

- BPSR 보다 같은 스파이크에서 정확도가 높다 / 같은 정확도에서 스파이크가 적다. "BPSR 대비 −17%" 류의 수치. (표1 점에서는 오히려 BPSR 이 스파이크 5.7% 적은 점에서 정확도 차가 검출되지 않는다.)
- inter 와 BPSR 이 같은 스파이크에서 "정확도가 같다" (동등성 검정을 하지 않았다 — "차가 검출되지 않는다" 로 쓴다).
- 구조 지표 (활성 뉴런 −6%, 죽은 채널 +56) 를 헤드라인·기여로 쓰는 것. 뉴런 희소성으로 Shi 2024 와 겨루는 문장.
- "1− 반전을 빼면 활성 뉴런 감소가 사라진다", "지니가 baseline 수준으로 돌아간다" (1판 문구, 틀림).
- "vmem 이 필수", "vmem 이 inter 를 균등 규제보다 낫게 만든다", "vmem 효과는 138 서버에서만 보인다" (판정 불가).
- 절대 스파이크 수와 "baseline 대비 −30%" 를 축 표기 없이 쓰는 것 (s_count 는 학습 패스 통계, 09-15 보류 유효).
- plain L2 보다 정확도가 높다 (300~420K +0.08 p=0.077 은 결과를 보고 고른 구간·넓히면 0).
- QK C10 저스파이크 (−44%) 에서 plain L2 보다 낫다 (n=1 대 n=1, 측정 기준에 따라 +0.60 → +0.24).
- QK C100 무손실. QK C100 은 −10.6% 에서 −0.30%p (n=4).
- VGGSNN 에서 inter 가 정확도를 올린다 (ρ 1e-3 +0.18, 시드 SD 0.5 안).
- SDTv3 무손실 범위 (n=1, 시드 SD 미측정).
- 구조 차이가 정확도 이점의 원인이다. 이벤트 구동 하드웨어에서 같은 스파이크로 더 적은 에너지.
- 10-14 C 항목 (−30% 유일 무손실, intra·layer 보다 나은 경쟁 범위, 생물학 근거, "채널 경쟁 가중은 새롭다") 은 그대로 유효.

## [LIMITATION]

- **정확도 우위에 대한 검정력이 없다.** 같은 스파이크 정확도 차의 최소 검출 차가 0.09~0.13%p (R19 C10), 0.21~0.31%p (C100), 0.4~0.5%p (QK) 다. 이보다 작은 우위·열위는 "없다" 가 아니라 "보이지 않는다" 다. 반대로 BPSR 대비 +0.11%p 보다 큰 우위는 이 자료로 배제된다. 동등성 검정은 하지 않았다.
- **비열등 판정은 경계 위에 있다.** R19 C10 ±0.15 하한과의 여유가 inter 0.0023, BPSR 0.0006 (Welch) 뿐이고, 마진은 자료를 본 뒤 적은 값이다. 반복 상한 n=4 안에서는 여유를 늘릴 수 없다.
- **스파이크 측정 축.** R19·VGGSNN 의 s_count 와 CSV 지표는 학습 배치 통계다. 테스트 셋 npz 와의 비가 baseline 1.053, 규제 팔 1.07~1.09 로 달라 baseline 대비 % 가 축마다 1.5~2%p 다르다. npz 축 baseline 은 138 서버 3런뿐이다. 학습 패스 대 테스트 셋 차이가 09-15 의 11% 불일치를 전부 설명하는지는 확인하지 않았다.
- **절대 정확도는 테스트 셋에서 고른 best 다.** R19 의 val 셋 = 테스트 셋. 표1 점과 baseline 의 마지막 10에폭 평균은 best 보다 0.14~0.19%p 낮다.
- **300~420K 는 사후에 고른 구간이다.** 주 구간의 p 는 탐색적이다. 넓은 구간 (180~420K) 은 곡선 모양 (직선 가정) 에 기댄다 — 2차항을 넣어도 결론은 같았다.
- **같은 정확도 스파이크 비는 기울기에 기댄다.** 300~420K 처럼 기울기가 0 과 구분되지 않는 구간에서는 비가 정의되지 않는다 (구간이 0~2.7 로 퍼짐).
- **구조 지표는 팔마다 기울기가 다르다.** 공통 기울기 숫자는 구간 평균이고, 스파이크 수준을 정해 읽어야 한다. C100 의 BPSR 은 293~342K 에만 있어 그 위는 외삽이다.
- **구조 지표의 범위.** 죽은 채널·MACs 는 R19 C10 npz (테스트 1만 장 1회 추론) 뿐이다. C100 은 CSV 지표 (활성 뉴런·지니·단계 몫) 만 있고, QK·DVS·SDT 는 구조를 재지 않았다. MACs 는 밀집 계산값이고 실측이 없다. Shi 2024 수치는 09-15 기록 인용이며 원문을 다시 확인하지 않았다.
- **다중비교.** 구성요소 4팔과 표1 npz 24개는 Holm 보정을 적었지만, 구간·지표를 여럿 본 나머지 표의 p 는 보정 전이다.
- **서버 교란.** 서버 항을 넣었지만 팔마다 서버 비율이 다르다. R19 C10 곡선 끝 (ρ 5.5e-3 은 138 만, 6e-3 은 23 만), - 1- inversion (4/5 런이 138), - vmem (23 은 n=3) 에서 서버와 처리가 겹친다.
- **QK 비교의 측정 잡음.** fp32 재측정값이 학습 로그 최고값보다 런마다 0.00~0.46 낮아, n=1 끼리의 비교는 판단할 수 없다. plain L2 는 ρ 마다 시드 하나다.
- **VGGSNN·SDTv3 의 해상도.** VGGSNN 은 시드 SD 0.5%p 로 n=4 가 1%p 를 겨우 가르고, 점추정·추세는 손실 쪽이다. SDTv3 는 n=1 이고 ImageNet 시드 SD 를 재지 않았다. KD 런은 진행 중이다.
- **진행 중인 런.** R19 C10 inter 6런, plain L2 2런 (사용자 중단 뒤 재투입) 은 평균에서 뺐다. 끝나면 −38~−43% 구간 판정이 바뀔 수 있다.
- **인용 값.** SynOps (10-09), 채널 사망 몫 9% (10-05), 팔 안 상관 r=−0.38, maxnorm 계열 비교 (10-14 E8), 학습 비용 (10-14), Speck 칩 측정 (10-15), Shi 2024 (09-15) 는 다시 계산하지 않았다.
- **이 분석은 경쟁 범위 (intra·layer) 비교를 갱신하지 않았다.** 새 자료가 BPSR·plain L2 쪽에만 들어왔다.
