## 정의

- **ECE (expected calibration error)**: 신뢰도 (softmax 최대확률) 와 정확도의 평균 차이. 최대확률을 [0,1] 15개 등간격 구간으로 나눠 구간별 |평균 신뢰도 − 정확도| 를 표본 비율로 가중 합. 단위 %p. **과신 몫/소신 몫** = 신뢰도 > 정확도 인 구간 / < 인 구간의 기여 (합 = ECE).
- **gap** = 최대확률 평균 − 정확도. 음수 = 소신 (자신 없게 맞춤).
- **NLL** = −log p(정답), label smoothing 없이. **LS 손실** = 학습과 같은 label smoothing 0.1 교차엔트로피 — 원장 val loss 와 대조용.
- **최적 온도 T\***: logits/T\* 로 테스트 NLL 이 최소가 되는 T\*. T\*<1 이면 소신 (날카롭게 해야 맞음), >1 이면 과신. 테스트셋으로 맞춘 기술 통계일 뿐이다.
- **logits**: 출력층 (`predictions_n`) 막전위의 마지막 스텝 값 (`snn_out_proc=last_ts`). `logits_t[:,k]` 는 k+1 스텝까지 적분된 막전위 — 출력층이 적분기라 **누적값**이다 (`logits == logits_t[:,3]` 확인, 9런 최대 차 0). 그래서 "T'=k 정확도" = k 스텝에서 멈췄을 때의 정확도.
  - **2026-10-20 정정:** 위 문장의 "그래서 … k 스텝에서 멈췄을 때의 정확도" 는 틀렸다. 출력층이 적분기인 것은 맞지만, 앞 층의 BN 이 T 스텝 입력의 시간 평균 한 장에 걸려 (`lib_snn/model.py` f_temporal_reduction) 스텝 k 까지의 막전위에 스텝 k+1~4 의 정보가 이미 들어 있다. "T'=k 정확도" 는 '4스텝을 다 돈 뒤 스텝 k 에서 읽은' 판독값이다 (`analysis/early_exit_261020.md` 0절).
- **누적 스파이크 %**: 스파이킹 18층 (`n_in`, `predictions_n` 제외) 의 1~k 스텝 스파이크 / 4스텝 전체.
- **최초 발화 몫**: (뉴런, 이미지) 쌍 중 스텝 k 에 처음 쏜 쌍의 비율. 미발화 = 4스텝 동안 한 번도 안 쏜 쌍. 평균 최초 발화 스텝 = 쏜 쌍만의 평균 (1~4).
- **McNemar**: 같은 1만 장에서 a 만 맞춘 수 vs b 만 맞춘 수의 정확 이항 검정. **두 모델 (런) 사이의 차이**를 묻는 검정이지 방법 사이의 차이가 아니다 — 방법 비교의 단위는 시드 (n=3).
- 스파이크: 원장 = 평가 모드·베스트 에폭 원장값, npz = 이 추출의 18층 합/이미지. 둘은 정의가 달라 npz 쪽이 4~6% 크다 (0절).

## 3. 스텝별 정확도 × 누적 스파이크 — T'=k 에서 멈추면

> **2026-10-20 정정:** 이 절은 `logits_t[:, k−1]` 과 1~k 스텝 누적 스파이크를 'k 스텝에서 추론을 멈춘' 값으로 읽었다. R19 의 BN 이 T 스텝 입력의 시간 평균에 걸려 conv2 부터 스텝 k 의 계산에 스텝 k+1~4 의 발화가 섞이므로, 아래 표는 4스텝을 다 돈 뒤 일찍 읽은 판독이고 실제로 멈춘 망의 값이 아니다. 같은 baseline 체크포인트 (s11~s13) 를 실제로 다시 돌린 값 (CPU, 테스트 앞 1000장, n=3; [ ] 는 체크포인트×이미지 이원 부트스트랩 95%): T'=3 은 BN 이동통계를 T=4 값으로 두면 자기 T=4 대비 −3.37%p [−4.90, −1.90], BN 이동통계만 T'=3 에서 다시 잡으면 −0.17%p [−1.23, +0.90] (스파이크 −39.0 ±0.3%). T'=2 는 BN 고정이면 우연 수준 (200장, s11·s12), BN 을 다시 잡아도 63.0 ±3.7% (−33.8%p) 다. 그래서 아래의 "T'=2 에서 멈추면 스파이크를 약 73% 덜 쓰고 정확도는 0.13%p 이내로 떨어진다" 는 성립하지 않는다. ## [LIMITATION]

- **모든 팔 n=3, 한 ρ/λ 점.** inter ρ 1.5e-3, BPSR λ 3e-11 한 쌍만 있다. 스파이크는 원장 기준 inter 가 BPSR 보다 약 1.6% 적어 완전히 같은 점은 아니다. 다른 스파이크 구간 (300K 대 등) 의 보정·클래스·일치도는 npz_t 가 없어 모른다.
- Welch t 는 자유도 약 2~4 라 검정력이 낮다. 여기서 "차이 없음" 은 "시드 SD 수준보다 큰 차이는 없다" 는 뜻이지 동등성 증명이 아니다. 정확도 시드 SD 0.10~0.13%p 보다 작은 효과는 이 설계로 보이지 않는다.
- 클래스 10개·혼동 90칸·층 18개 검정은 다중비교 보정을 하지 않았다. 개별 p<0.05 를 발견으로 읽지 않는다.
- 보정은 label smoothing 0.1 학습 모델의 것이다. 소신 방향은 LS 의 결과이고, LS 없이 학습했을 때 규제가 보정을 어떻게 바꾸는지는 이 자료로 말할 수 없다. 최적 온도는 테스트셋에 맞춘 값이다.
- 스텝별 정확도는 T=4 로 학습한 망을 짧게 추론한 것이다. 처음부터 T=2 로 학습한 망과의 비교가 아니다.
  - **2026-10-20 정정:** '짧게 추론한 것' 도 아니다. 4스텝을 다 돈 뒤 일찍 읽은 판독이다 (3절 정정 참고).
- 최초 발화 차이를 final_step 등 특정 요소에 돌릴 수 없다 (`- final_step` npz 없음). inter 와 BPSR 은 가중 방식 전체가 다르다.
- 테스트 1만 장 1회 추론 (결정적) 이다. 데이터 증강·다른 데이터셋 (C100, DVS) 으로 일반화되는지는 모른다.
