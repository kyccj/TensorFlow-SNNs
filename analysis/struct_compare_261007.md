# 경쟁 범위와 희소성의 구조: 채널 단위 vs 뉴런 단위 (R19-C10, 26-10-07)

생성: `analysis/struct_compare_261007.py` → `.json`, 이 문서. 원장 2026-10-06 16:14 집계 (310 에폭 완주·S30/S1≥0.19·seed<900), npz = 테스트 1만 장 1회 추론, 스파이킹 18층 (n_in·predictions_n 제외). **C100: npz 없음. Suetake: npz 없음** (C10 유효 런 n=2, 추출 안 됨).

## 정의 (분석 전에 고정)

- **죽은 채널**: 테스트 1만 장 전체에서 공간 모든 위치가 한 번도 안 쏜 채널 (/4,736 = conv 4,480 + fc1 256).
- **MACs 제거 %**: 죽은 채널을 물리 제거했을 때 줄어드는 밀집 MACs 비율, 모든 스파이킹 층 (`prune_measure.py` 시나리오 b, `inter_deep_261005.py` 와 같은 셈). 제거해도 정확도 변화 0.00 (inter_deep F1, 실측 28런).
- **이미지당 활성 뉴런**: 이미지 한 장에서 T 스텝 동안 한 번이라도 쏜 뉴런 수의 평균 = Σ(뉴런이 쏜 표본 수)/1만. 스펙 A2 의 활성 뉴런 (Σ N·(1−dead_neuron_ratio), 표본별 0 스파이크 비율) 과 같은 정의이고, 측정이 학습 모드 CSV 대신 테스트 모드 npz 다. 전체 뉴런 1,442,048 개 (모든 런 같음: True).
- **산 채널 안 활성 %** (보조): 위 활성 뉴런을, 죽지 않은 채널(fc1 은 죽지 않은 뉴런) 에 속한 뉴런 수로 나눈 값. 채널 사망과 분리한 뉴런 단위 희소성. **판정에 쓰지 않는 보조 지표**다 (요청 지표가 아님).
- 모형: `y = a_팔 + b·ln(스파이크)` 공통 기울기 ANCOVA. 활성 뉴런은 스펙 A2 와 같이 ln(y) → 결과를 % 로 환산. 스파이크 x 는 npz 테스트 스파이크 (지표와 같은 측정); 원장 스파이크를 x 로 쓴 결과는 민감도 절. 기울기가 팔마다 다를 수 있어 기울기를 따로 둔 모형의 367K (npz 축, 원장 약 340K) 대비도 낸다 — 두 팔 모두 그 스파이크를 덮을 때만.
- **판정 규칙**: 대상 팔 vs 나머지 팔 합동 대비의 95% CI 가 유리한 방향으로 0 을 벗어나고, 개별 팔 대비의 점추정 부호가 전부 같은 방향이면 성립. 구간: **1차 = 원장 스파이크 320~420K** (주장 범위), 2차 = 유효 npz 전 런. baseline 은 회귀에서 빼고 기준 행으로만.

## 0. 결론

1. **(a) 성립.** 1차 구간 (n=31: inter 9) 에서 같은 스파이크일 때 ours_inter_ch 는 나머지 팔 합동보다 죽은 채널 +27.8 [+12.9, +42.7] p<0.001 개, MACs 제거 +1.83 [+0.80, +2.87] p=0.001 %p 더 많다. 개별 네 팔 모두 같은 부호. 단 ours_layer (w¹) 와는 공통 기울기 모형에서 구분되지 않는다 (죽은 채널 +13.7 [-0.4, +27.8] p=0.056 (Holm 0.056), MACs +0.77 [-0.08, +1.61] p=0.073 (Holm 0.073)); 기울기를 따로 둔 367K 대비는 MACs +1.25 [+0.11, +2.39] p=0.033. 2차 전체 (n=78) 에서는 여섯 팔 전부와 Holm 후 유의.
2. **(b) 불성립.** 1차 구간에서 ours_intra_ch (w¹) 의 이미지당 활성 뉴런은 나머지 팔 합동 대비 -1.6 [-4.2, +1.1] p=0.223 % (음수 = intra 가 적음) 로 0 을 포함한다. plain L2 (-5.7 [-6.9, -4.5] p<0.001 (Holm 0.000) %)·BPSR (-4.3 [-5.6, -3.0] p<0.001 (Holm 0.000) %) 보다는 적지만, ours_inter_ch 보다는 오히려 +0.6 [-0.5, +1.8] p=0.256 (Holm 0.512) % (양수 = intra 가 많음) 이고 ours_layer (w¹) 와 같다. 기울기를 따로 둔 367K 에서는 intra 가 inter 보다 +1.1 [+0.2, +2.0] p=0.014 % 많다. 원래 제안법 w² (2차 전체만, n=9) 도 inter 와 -0.2 [-2.1, +1.8] p=0.877 (Holm 0.877) % 로 같다.
3. **이미지당 활성 뉴런이 가르는 것은 경쟁 범위가 아니라 'maxnorm 가중 계열 (inter·intra·layer) vs plain L2·BPSR' 이다.** 세 경쟁 범위 팔은 서로 1% 안이고, 셋 다 plain L2 보다 5~7%, BPSR 보다 4~7% 적다 (1차, 공통 기울기·367K 두 방식). ours_inter_ch 를 대상으로 두면 inter 도 나머지 합동보다 -2.6 [-4.4, -0.7] p=0.010 % 적다 — 즉 inter 는 채널 지표와 뉴런 지표 **둘 다** 앞서거나 같다.
4. **스펙 A2 (−13.1%) 는 npz 테스트 모드로 재현된다:** ours_intra_ch (w²) vs plain L2 만 넣으면 -12.9 [-14.6, -11.3] p<0.001 (Holm 0.000) % (n=18: 각 9). 그러나 같은 정의로 inter 를 넣으면 w² 와 차이가 없으므로 (2번) **A2 는 intra 고유 성질이 아니다.**
5. 보조 지표 (판정 외): **산 채널 안 활성 %** 는 intra (w¹) 가 가장 낮다. 1차 나머지 합동 대비 -0.44 [-0.74, -0.15] p=0.005 %p, 개별 네 팔 전부 같은 부호, Holm 후 전부 p<0.05 (inter -0.26 [-0.45, -0.06] p=0.012 (Holm 0.013)). 즉 '살아남은 채널 안에서 덜 쏜다' 는 intra 쪽 분리는 보인다. 다만 이 지표는 미리 정한 판정 지표가 아니고, 분모가 채널 사망에 따라 바뀌어 inter 쪽은 기계적으로 높아진다 (약한 채널이 빠지면 남은 채널의 활성 비율이 오른다). plain L2·BPSR 은 intra 보다 채널을 덜 죽였는데도 이 값이 더 높으므로 (+0.8%p) 기계적 효과만은 아니다. 논문 근거로 쓰려면 이 지표를 사전 등록하고 별도 런 집합으로 확인해야 한다.
6. **요지 문장 판정:** "경쟁 범위가 희소성의 구조를 고른다" 는 이 결과로 **쓸 수 없다.** 쓸 수 있는 것은 한쪽 — "채널끼리 경쟁(inter) 은 같은 스파이크에서 채널을 더 죽여 MACs 를 나머지 팔 합동보다 1.8%p (1차, n=31) 더 줄이고, 이미지당 활성 뉴런은 다른 경쟁 범위 팔보다 많지 않다" 이다.

- 죽은 채널은 테스트셋 판정이다 (학습셋 판정과 28/28 런에서 같았음, inter_deep F1). MACs 는 타임스텝 1회분 밀집 연산 기준이고 스파이크 희소성에 따른 실제 연산량이 아니다.
- npz 스파이크 총합과 `s_count` 의 불일치(결정 기록 09-15) 는 해소되지 않았다. 두 축 모두로 계산해 결론이 같음만 확인했다.
- 보조 지표(산 채널 안 활성 %) 의 intra 우위는 사후에 판정 근거로 승격하면 안 된다. 미리 정한 판정 지표는 이미지당 활성 뉴런이다.
