## 정의

- **c**: 채널 공간합 = Σ_위치 scp. scp = T 합 스파이크 (한 번이라도 쏜 위치) 또는 막전위/문턱 clip(0,1) (한 번도 안 쏜 위치, vmem). 이미지마다 따로. **max c**: 같은 층·같은 이미지의 채널 중 최대 (neurons.py:1019-1033). fc1 (2D) 은 채널 묶음 없이 층 전체 max.
- **w** (`reg_detail.csv` 의 `sc_rate_mean`, 위치·채널·배치 평균): ours = 1 − c/max c (1등 채널 0, 침묵 채널 ≈1), `- 1- inversion` = c/max c (1등 채널 1, 침묵 채널 ≈0; neurons.py:1047-1062). 18층 평균은 뉴런 수 가중. **두 팔의 w 를 그대로 비교하면 정의가 뒤집힌 것까지 섞인다.**
- **m = mean(c/max c)** (이 문서에서 새로 씀): 두 팔에서 같은 양 — ours 는 1 − w, `- 1- inversion` 은 w. 1등 채널 대비 평균 채널의 비율; 클수록 채널이 고르다. **채널 CV** = std(c/max c) / m. std 는 `reg_neuron_detail.csv` 의 `sc_rate_std` (std(1−x) = std(x) 라 두 팔 같은 양; 이미지마다 층 안 뉴런 위 표준편차 → 배치 평균, neurons.py:1229-1232). 층별 CV 를 뉴런 수 가중.
- **뉴런 지니·상위 10% 몫** (`reg_neuron_detail.csv`, neurons.py:1449-1462): 배치 (100장) 평균 뉴런별 T 합 스파이크의 층 안 집중도 → 층 스파이크 가중 평균. 뉴런 단위 (채널 단위 아님). **이미지당 침묵 %** = 이미지 하나에서 한 번도 안 쏜 뉴런 비율의 배치 평균 (뉴런 수 가중).
- **학습 모드 지표**: 마지막 에폭 (310) 학습 배치 평균, 증강 포함. 원장 spikes (평가 모드, best 에폭) 와 다른 자료다.
- **같은 스파이크 Δ (기전)**: ours 런 (원장 spikes 180~330K, 10-10 과 같은 대역) 으로 `지표 = a + b·ln(spikes)` 적합 → `- 1- inversion` 의 spikes 에서 예측. **z** = (값 − 예측) / 새 런 하나의 예측 SE (곡선 SE + 잔차 SD). 잔차 SD 는 ours 시드 산포를 담는다; `- 1- inversion` 자신의 시드 산포는 n=1 이라 모른다. x 를 학습 모드 스파이크로 바꾼 값도 함께 적었다.
- **벌점 기울기** (layers.py:2024-2053, decisions 09-20): 스파이크 하나가 받는 기울기 = λ·w_i²/R_ℓ (× surrogate). 쏜 뉴런이든 안 쏜 뉴런이든 w² 만큼 받는다 (wta_rev). R_ℓ = ‖S_ℓ ⊙ w_ℓ‖₂, R = Σ_ℓ R_ℓ, loss-ratio: λ_{e+1} = ρ·L_e/R_e.
- **ρ 배율**: `- 1- inversion` 과 같은 스파이크를 내는 ours ρ 에 대한 `- 1- inversion` ρ 의 비. ours ρ 별 평균 ln 스파이크를 ln-ln 구간 선형으로 이은 곡선 위에서 역산 (주 결과). 구간 = 이웃 두 ρ 평균 SE + noinv 한 런의 시드 산포 (ours 합동 ln SD) 를 국소 기울기로 옮김, t(df=합동 자유도).
- **npz 지표** (테스트 1만 장 1회 추론, 평가 모드, best 가중치): **죽은 채널** = 테스트셋 합 0 인 채널 (conv 는 공간합, fc1 은 뉴런 하나; 18층 4,736). **이미지당 활성 뉴런** = Σ 뉴런이 쏜 이미지 수 / 1만. **채널 지니·상위 10%** = 층 안 채널 합의 집중도를 층 스파이크로 가중. **제거 시 MACs 감소** = 죽은 채널을 지웠을 때 conv MAC 감소율.

## [LIMITATION]

1. `- 1- inversion` 완주 런은 **n=1** (ρ 1e-2 s1, sejong). 정확도 차는 어느 방향으로도 말할 수 없다. 기전 지표·ρ 배율의 z 는 ours 시드 산포 기준이라 noinv 의 산포가 더 크면 과대평가된다. 중단 런 (2.4e-2 s1, 195 에폭) 으로는 방향만 재확인했고, 이 런도 s1·sejong 이다.
2. 서버: 두 noinv 런 모두 23. 정확도 ANCOVA 의 서버 항은 0 에 가깝지만 (e=-0.001), 기전 지표의 서버 효과는 따로 재지 않았다.
3. 학습 모드 지표는 증강이 걸린 학습 배치 평균이다. 평가 모드 (npz) 로 같은 결론인지는 측정 1 이 필요하다. m·채널 CV 는 vmem readiness 가 c 에 섞인 값이라 순수 스파이크 채널 분포가 아니다.
4. "1등 채널을 누르면 과제 손실이 버텨 같은 압력에 덜 줄어든다" 는 해석이다. 채널별 과제 기울기·벌점 기울기를 재지 않았다.
5. ρ 배율은 ours ρ 별 평균을 ln-ln 구간 선형으로 이은 곡선 위의 값이다. 이웃 ρ 사이 곡률은 무시했고, 1e-2 의 같은 ρ 비교는 n=1 인 8e-3·1.2e-2 사이 보간, 2.4e-2 의 같은 ρ 비교는 외삽이다.
6. intra 교차 확인 (`abl_noinv`) 은 반전·within_channel·vmem 세 요소를 함께 뺀 팔이고, 비교 구간의 abl 런은 전부 23, prop 런은 대부분 138 이다. 반전 단독의 intra 증거는 없다 (`abl_noinv_wc` 0런).
7. best 에폭 기준은 310 에폭 최대값이라 시드 잡음을 위로 끌어올린다 (두 팔 공통). spikes 는 s_count 원값 — s_count 와 npz 총합의 불일치 (09-15 보류) 는 해소되지 않았다.
8. 학습 시간은 같은 서버의 다른 작업 부하에 좌우된다. `- 1- inversion` 은 n=2 (한 런은 195 에폭 중단) 이고 같은 시각 겹친 ours 런은 1개뿐이다.
