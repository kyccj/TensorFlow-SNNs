# ours_inter_ch vs BPSR — 정확도·스파이크 수 밖의 구조적 차이 (R19-C10, 26-10-09)

생성: `analysis/inter_vs_bpsr_261009.py` → `.json`, 이 문서. 원장 2026-10-09 22:50 집계 (310 에폭 완주·S30/S1≥0.19·seed<900), npz = 테스트 1만 장 1회 추론, 스파이킹 18층 (n_in·predictions_n 제외), T=4. ours_inter_ch 의 런 키는 `ours_ch`.

## 요약

1. **inter 가 앞서는 축 = 채널 단위 구조 희소성과 이미지당 활성 뉴런.** 같은 스파이크 (원장 300~420K, inter n=11 / BPSR n=6) 에서 죽은 채널 +49.8 [+28.3, +71.2] p=0.0002 개 (/4,736), 그 채널을 지웠을 때 MACs 감소 +3.44 [+2.11, +4.76] p=6.9e-05 %p, 이미지당 활성 뉴런 -5.7 [-6.9, -4.4] p=1.9e-07 %. 스파이크가 거의 같은 짝 (inter 1.5e-3 vs BPSR 3e-11, 원장 405K vs 412K, 각 n=3) 에서도 부호가 같다 (활성 뉴런 p<0.01, 죽은 채널·MACs 는 p=0.14·0.08 로 짝만으로는 유의하지 않음).
2. **줄이는 방식이 다르다 (우열이 아니라 모양).** BPSR 은 발화하는 뉴런의 스텝 수를 고르게 깎고, inter 는 뉴런·채널을 통째로 끈다: 발화한 (뉴런, 이미지) 쌍당 발화 스텝 수 (최대 4) 가 inter 쪽이 +0.089 [+0.070, +0.109] p=1.2e-07 많고 (baseline 1.64 → 짝에서 inter 1.60, BPSR 1.54; conv1·conv2 에서 +0.12~0.13, conv4·fc1 에서는 차이 없음), 전체 뉴런 지니 +0.056 [+0.044, +0.068] p=9.9e-08, 상위 10% 뉴런의 스파이크 몫 +6.3 [+4.9, +7.7] p=1.3e-07 %p, 채널 지니 +0.052 [+0.041, +0.063] p=8.6e-08 로 스파이크가 더 소수에 몰린다. 그 몫의 상당 부분은 이미지 절반 이상에서 쏘는 뉴런이 나른다 (3절).
3. **차이 없는 축.** SynOps (fan-out 가중 시냅스 연산) 는 baseline 대비 감소율 차 -0.38 [-0.63, -0.13] p=0.0051 %p 로 통계적으로는 0 이 아니지만 0.4%p 이하라 실질 차이 없음 (전 구간 n=19/12 에서는 p=0.67). 층(단계)별 스파이크 배분은 1.3%p 안 (inter 가 conv1 을 덜, conv3 를 더 줄임). val loss +0.0008 [-0.0023, +0.0039] p=0.59, val acc +0.042 [-0.039, +0.123] p=0.29 %p, train−val 차 (정확도·loss) 모두 CI 가 0 을 포함.
4. **BPSR 이 앞서는 축 = 시드 재현성.** 같은 ρ 시드 간 SD (n≥3 묶음 합동): 정확도 inter 0.112%p (자유도 17) vs BPSR 0.058%p (자유도 8), F 검정 p=0.065; 착지 스파이크 변동계수 2.17% vs 1.10%, p=0.057 (1차 구간만: 2.85% vs 0.66%, p=0.012, 자유도 9/4). 정확도 SD 는 경계선이고 BPSR 자유도가 8 이라 **아직 판단 불가**; 스파이크 착지는 BPSR 이 더 일정하다.
5. **잴 수 없었던 축.** 타임스텝별 스파이크 분포·첫 스파이크 시각·보정 오차(ECE)·클래스별 정확도는 지금 npz (뉴런별 총합만 저장) 와 원장에 없다. 새 추론이 필요하다 (끝의 [LIMITATION]).

## 정의

- **같은 스파이크 비교 (ANCOVA)**: 두 팔만 넣고 `y = a + b·ln(npz 테스트 스파이크) + c·[inter]`. c = 같은 스파이크에서 inter − BPSR. 1차 = 원장 스파이크 300~420K (inter n=11, BPSR n=6, npz 있는 런), 2차 = 두 팔 유효 npz 전 런 (n=19/12, 147~437K). 기울기가 팔마다 다를 수 있어 (표의 "기울기 차 p") 기울기를 따로 둔 모형의 1차 구간 중앙 (npz 389K) 대비도 json `sep` 에 있다 — 전 지표에서 공통 기울기 c 와 소수 셋째 자리까지 같아 표에는 c 만 적었다.
- **짝 비교**: inter 1.5e-3 vs BPSR 3e-11 (원장 405,469 vs 412,033, npz 430,731 vs 437,056, 각 n=3), Welch t. 모형 없이 거의 같은 스파이크끼리. 보조 짝: inter 4e-3 vs BPSR 1e-10 (302K vs 319K, 각 n=3) — 스파이크가 5% 다르므로 json `pair2` 에만.
- **죽은 채널**: 테스트 1만 장에서 공간 모든 위치가 한 번도 안 쏜 채널 (/4,736 = conv 4,480 + fc1 256). **MACs 감소 %**: 그 채널을 물리 제거할 때 줄어드는 밀집 MACs 비율 (`struct_compare_261007` 시나리오 b 와 같은 셈). **이미지당 활성 뉴런**: 이미지 한 장에서 T 스텝 동안 한 번이라도 쏜 뉴런 수 (ln 으로 회귀, % 로 환산).
- **지니**: 0 = 모든 뉴런이 같은 수를 쏨, 1 = 한 뉴런이 전부. 전체 뉴런 지니는 1,442,048 개 뉴런의 총 스파이크로 (침묵 뉴런 포함). **채널 지니**: conv 17층 각각에서 채널별 총 스파이크의 지니, 층 스파이크로 가중 평균. **상위 10% 몫**: 가장 많이 쏜 10% 가 낸 스파이크 비율. **산 채널 안 공간 지니**: 산 채널 안에서 위치별 스파이크의 지니, 채널 스파이크 가중 평균.
- **쏜 이미지 비율**: 한 번이라도 쏜 뉴런마다 (쏜 이미지 수 / 1만), 그 평균. 낮을수록 뉴런이 이미지를 가려서 쏜다 (선택성). **이미지 절반 이상에서 쏘는 뉴런**: 그 비율 ≥ 0.5 인 뉴런 (전체 뉴런 대비 %) 과 그 뉴런들이 낸 스파이크 몫.
- **스텝/활성쌍** = Σ스파이크 / Σ(뉴런이 쏜 이미지 수) — 뉴런이 어떤 이미지에서 발화했을 때 T=4 스텝 중 평균 몇 스텝 쐈나 (1~4). 시간축 분포 자체는 아니고 그 대리.
- **SynOps**: 스파이크 하나가 다음 연산에서 일으키는 곱셈-누산 수 (위치별 경계 포함 정확한 fan-out, `analysis/r19_fanout.py`; BN 접힘·identity shortcut 0·단계 입구 1×1 shortcut 포함·GAP 는 fc1 에 접힘). 이미지당 합.
- 스파이크·정확도는 원장 (베스트 에폭 eval), 분포 지표는 npz (테스트 모드). npz/원장 스파이크 비는 1.05~1.07.

## 3. 분포 모양과 선택성 — 읽는 법

- inter 는 스파이크가 더 소수 뉴런·채널에 몰린다 (지니·상위 10% 몫 모두 BPSR 과 baseline 보다 큼). BPSR 의 지니는 baseline 보다 오히려 낮다 (0.570 vs 0.583) — 발화를 고르게 깎는 방법이라는 해석과 맞다.
- 몰린 몫의 상당 부분은 **이미지 절반 이상에서 쏘는 뉴런** 이 낸다: 그 뉴런들의 스파이크 몫 inter 42.0% vs BPSR 36.4% (각 n=3), baseline 44.6%. 뉴런 수는 둘 다 전체의 약 10% 로 같고 (짝 p=0.21), inter 에서는 그 뉴런들이 더 많이 쏜다. 한편 한 번이라도 쏜 뉴런의 평균 쏜 이미지 비율은 inter 가 약간 낮다 (−0.005~−0.008). → inter 는 '대부분의 뉴런은 더 가려 쏘고, 소수의 상시 발화 뉴런이 더 많이 나르는' 구조다. 이것이 정확도나 일반화에 이득이라는 증거는 없다 (4절: val loss·train−val 차 차이 없음). **선택성이 inter 의 본질이라고 쓸 근거는 약하다** — 차이는 '어느 뉴런이 쏘나' 의 집중이지 이미지별 선택성의 큰 변화가 아니다.
- 산 채널 안 공간 지니는 inter 가 약간 낮다 (−0.007): 살아남은 채널 안에서는 위치별 발화가 더 고르다. 채널 단위로 끄고 남은 채널은 고르게 쓰는 모양과 일치하지만 크기가 작다.

## [LIMITATION]

- **시간축은 재지 못했다.** npz 는 뉴런별로 (샘플×T) 합계와 "쏜 샘플 수" 만 저장한다. 타임스텝별 스파이크 분포, final_step 때문에 inter 가 마지막 스텝에 몰리는지, 첫 스파이크 시각은 이 자료로 답할 수 없다. 여기 "스텝/활성쌍" 은 발화 스텝 수의 평균일 뿐 어느 스텝인지 모른다. 재려면 추출기 (`extract_neuron_spikes.py`) 에 스텝별 카운트와 로짓 저장을 더한 새 추론이 필요하다 (짝 6런 + baseline 3런, 런당 테스트 1만 장 1회). 이번 작업 범위 (읽기·집계) 밖이라 하지 않았다.
- **ECE·클래스별 정확도도 같은 이유로 없다** (로짓 미저장). 원장에 있는 val loss 만 비교했다.
- BPSR 은 1차 구간에 ρ 두 개 (3e-11 412K, 1e-10 319K) 뿐이다. 공통 기울기 ANCOVA 의 BPSR 쪽 기울기는 두 점 묶음으로 정해진다. 그래서 거의 같은 스파이크의 짝 비교 (n=3/3) 를 같이 냈다. 짝은 n=3 이라 죽은 채널·MACs 차는 짝만으로 유의하지 않다 (p=0.14, 0.08).
- 분포 지표 상당수에서 기울기 차가 유의하다 — 차이는 스파이크가 낮을수록 커진다. 1차 c 는 그 구간 평균적 차이다.
- SynOps 는 밀집 위치별 fan-out × 스파이크 수 근사다. 실제 하드웨어의 메모리 접근·채널 프루닝 이득은 측정하지 않았다. "MACs 감소 %" 는 죽은 채널을 지운 밀집 연산 기준 (제거 시 정확도 변화 0.00, 28런 실측, inter_deep F1).
- 지표 수가 많다 (npz 30개 이상). 다중 비교 보정은 따로 하지 않았다. 판정 (우위·다름) 은 1차 CI 가 0 을 벗어나고 짝 비교의 부호가 같은 것만 적었고, 그 행들의 1차 p 는 모두 ≤2e-4 라 Bonferroni (지표 약 35개, 0.05/35 ≈ 1.4e-3) 를 적용해도 남는다. p 가 0.005~0.05 인 지표 (SynOps 감소율, conv3·conv4 몫) 는 판정에 쓰지 않았다.
- 시드 SD 비교는 BPSR 자유도 8 (전 구간), 4 (1차) 로 작다. "BPSR 이 더 재현적" 은 스파이크 CV 에서만 1차 p=0.012 이고 정확도 SD 는 판단 불가.
- 선택성 지표는 "쏜 이미지 비율" 하나로 쟀다. 클래스별 반응 (클래스 선택성) 은 표본별 기록이 없어 못 쟀다.
- R19·CIFAR-10·T=4 한 설정이다. C100 은 BPSR 런이 없고 (결정 10-07: BPSR 비교는 R19 C10 에서만), 다른 모델로 일반화하지 않는다.
