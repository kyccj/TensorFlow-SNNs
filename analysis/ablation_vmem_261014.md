## 정의

- **vmem (막전위 준비도)**: 1-maxnorm 서열을 만들 때, t=T 까지 한 번도 안 쏜 위치에 준비도 r = clip(V/Vth, 0, 1) 를 스파이크 수 대신 넣는다 (쏜 위치는 정수 스파이크 수 그대로, `silent_only`). inter 에서는 채널 공간합 c = Σ_위치 (스파이크 수 또는 r) 로 서열을 매기고 w = 1 − c/max c. 그래서 **문턱 근처 침묵 위치가 많은 채널일수록 c 가 커지고 w 가 작아진다** (`lib_snn/neurons.py` 976–1021).
- **ρ / λ**: loss-ratio 목표 ρ. 매 에폭 λ_{e+1} = ρ·L_task/R. λ 평균 = 310 에폭 평균, λ 마지막 = 310 에폭 값.
- **R** = Σ_층 ‖S_l∘w_l‖₂ (학습 모드, 마지막 에폭 배치 평균). **w 평균** = 18층 뉴런 가중 평균 sc_rate.
- **층 상대 압력 π (새 지표)**: π_g = (R_g / 스파이크_g) / (R / 스파이크_전체). 층 묶음 g 의 스파이크 하나에 걸리는 평균 벌점 기울기를 전체 평균에 대한 비로 나타낸 것 (아래 3c 유도). ln π 차 > 0 이면 그 묶음이 상대적으로 더 눌린다.
- **같은 스파이크 오프셋 d**: `acc = a + b·ln(spikes) + d·[- vmem] (+ e·[서버 23])`, ours_inter_ch 완주·비배제 200~420K n=27 (nofinal_vs_inter_261014 과 같은 곡선·같은 모형).
- 층 묶음: stem = conv1_conv, 블록 안쪽 = 잔차 블록 첫 conv (`*_conv1_n`, 8층), 블록 출력 = `*_out_n` (8층).
- 합동 시드 SD (ours_inter_ch, n≥2 ρ 8개, 자유도 17) = **0.112%p**.

## 요약

1. **같은 스파이크 정확도: `- vmem` 이 −0.096%p [−0.188, −0.005], p=0.040 (ours n=27 · `- vmem` n=8, 선형+서버).** 10-10 의 n=6 (같은 모형으로 다시 계산 −0.065, p=0.18) 에서 새 2런이 더해져 0 을 겨우 벗어났다. 새 2런만 따로 보면 −0.211 [−0.377, −0.046] (n=2, 10-10 이 예측한 방향과 같음, 단 n=2 라 근거로 쓰지 않음). **그러나 민감하다**: 런 하나만 빼도 (2e-3 s3 → p=0.13, 3e-3 s1 → p=0.10) 유의성이 사라지고, 서버별로 138 런 (n=5) −0.162 (p=0.010) / 23 런 (n=3) −0.012 (p=0.85) 로 갈린다 (서버×팔 상호작용 p=0.097). 현재 설계의 검출 한계 (검정력 0.8) 는 0.13%p 로 관측값보다 크다. **판정: 방향은 일관되나 크기 0.1%p 는 확정 불가.**
2. **같은 ρ 에서 vmem 은 스파이크를 덜 줄이게 한다: `- vmem` −4.3% [−7.2, −1.4] (p=0.006, n=17/8).** ρ 눈금으로 환산하면 vmem 을 끄는 것은 ρ 를 **×1.16 [1.05, 1.28]** 키운 것과 같다 (`- final_step` 의 약 ×2 보다 훨씬 작다). 같은 λ 에서는 −6.2% [−8.9, −3.5] (p=1.2e-4). ρ 2e-3 직접 비교 (n=3 대 3) 는 −5.3% [−12.5, +2.5] (p=0.13). intra 에서는 효과가 크다: −21.1% (n=15/7), ρ ×1.42.
3. **기전 — vmem 은 w 를 낮추지만, loss-ratio 아래에서 평균 하락은 상쇄되고 '배분' 만 남는다.** 같은 학습 모드 스파이크에서 `- vmem` 의 w 평균 +0.071 ±0.003 (p=2e-20), R +13.6% [+11.4, +15.8] (n=27/8) — 새 2런이 그대로 복제 (w +0.077·+0.070, R +13.4%·+12.5%). 벌점 기울기 λw²/R_l 은 w 를 일정 배수로 바꾸면 loss-ratio 가 λ 로 정확히 되돌리므로 (척도 불변), 평균 하락 몫은 같은 ρ 에서 λ +7% (`- vmem` 쪽 −6.9%) 로 상쇄된다. 남는 것은 **층 사이 상대 압력**: vmem 을 끄면 블록 안쪽 conv1 층의 π 가 약 4% 높아진다 (ln π 차 +0.039 [+0.016, +0.062], p=0.002; 그 층 스파이크 몫을 통제해도 +0.036, p=5e-5). 출력 층은 −0.015, stem 은 −0.041. 17층에서 층별 압력 변화는 그 층의 침묵 비율과 함께 커진다 (Spearman 0.54, p=0.024). 즉 **vmem 은 침묵이 많은 블록 안쪽 층의 상대 압력을 약 4% 덜어준다.** w 차이는 학습 내내 벌어진다 (에폭 1 +0.016 → 310 +0.077, ρ 2e-3 n=3 대 3).
4. **침묵·저발화 뉴런 보존은 판단 불가 — 10-10 보충 문서 정정.** 보충 문서의 "테스트셋 침묵 뉴런 19.42 ±0.13% vs 20.85%, z=+9.6, p=0.011" 은 inter ρ 3e-3 세 시드의 SD 0.13 을 썼는데, 이 값이 ρ 4개 중 가장 작다 (1.5e-3 0.63, 2e-3 1.34, 4e-3 0.94). 4개 ρ 합동 (스파이크 보정, 자유도 7) 으로 다시 재면 +1.11%p, **z=+1.71, p=0.13** (n=1). 저발화 (발화율 0~1%) 뉴런 비율은 차이 없음 (z=+0.06). 학습 모드 이미지당 침묵도 +0.09%p (p=0.39, n=8). 남는 신호는 블록 안쪽 층 스파이크 −5.8% (z=−2.47, p=0.043, n=1, 지표 13개 중 하나) 로 3번의 압력 배분과 방향이 같다.
5. **학습 시간: vmem 비용 약 +2%.** 에폭당 중앙값 `- vmem` / ours_inter_ch = 336 / 343.5 s (138, n=5/14), 341 / 349 s (23, n=3/14) → −2.2% (두 서버 모두 [−3.4, −0.9] 안). 310 에폭에 약 40분. baseline 315 / 323 s (n=3/3) 대비 ours_inter_ch 는 +9%/+8% 이고 그중 약 2%p 가 vmem 몫이다. 런마다 같은 시각에 돈 것이 아니라 서버 부하 차이가 섞일 수 있다.

**판정 한 줄**: vmem 이 하는 일은 "같은 ρ 에서 스파이크를 4% 덜 줄이는 눈금 이동 (×1.16)" 과 "침묵이 많은 블록 안쪽 층의 상대 압력을 4% 덜어주는 배분 이동" 이고 둘 다 n=8 에서 분명하다. 같은 스파이크 정확도 이득 0.1%p 는 방향이 사전 예측과 맞고 명목 p=0.04 이지만 런 하나에 좌우되고 서버 한쪽에서만 보여 **확정하지 못한다.**

### 3c. 왜 '평균 w 하락' 이 아니라 '배분' 인가

- 벌점 기울기 (wta_rev): 층 l 의 쏜 뉴런 i 는 λ·w_i²/R_l 을 받는다 (`lib_snn/layers.py` l2_norm_wta_rev; 실효 w² 경로). loss-ratio 로 λ = ρL/R.
- 모든 뉴런의 w 를 c 배 하면 λ → λ/c, w² → c²w², R_l → cR_l 이라 기울기가 **그대로** 다 (척도 불변). 그러므로 vmem 의 평균 w 하락 (−0.071, 상대 약 −9%) 과 R 하락 (−12%) 자체는 같은 ρ 에서 λ 상승 (+7%) 으로 상쇄되는 몫이고, 같은 ρ 에서 남는 스파이크 차 (+4.5%) 는 **w 의 모양 (층·채널 사이 상대 가중) 변화에서만** 올 수 있다. 10-10 의 "R 이 14% 작아 같은 λ 에서 벌점이 덜 걸린다" 는 같은 λ 에서는 맞지만 loss-ratio 가 켜진 실제 학습 (같은 ρ) 의 설명으로는 불완전하다.
- 층 l 의 평균 스파이크당 기울기 ≈ ρL·R_l / (R·S̄_l·스파이크_l) (S̄ = 쏜 뉴런의 평균 스파이크 수, 두 팔에서 같다고 근사). 층 공통 인자를 빼면 정의의 π_l 이 남는다.

## 6. 판정

**판정 가능 (n=8, 효과가 시드 산포의 수 배)**
- 같은 ρ 에서 vmem 은 스파이크를 덜 줄이게 한다: −4.3% [−7.2, −1.4] (`- vmem` 쪽), ρ 눈금 ×1.16 [1.05, 1.28].
- 같은 스파이크에서 vmem 은 w 를 0.071 낮추고 R 을 12% 줄인다 (10-10 n=6 → 새 2런이 복제).
- 같은 ρ 에서 vmem 은 λ 를 약 7% 높게, R 을 약 10% 낮게 유지한다 (과제 손실 같음).
- vmem 은 블록 안쪽 conv1 층의 상대 압력 π 를 약 4% 낮추고 stem·출력 층 쪽으로 옮긴다 (`- vmem` − ours 의 ln π_안쪽 +0.039 [+0.016, +0.062], 그 층 스파이크 몫 통제 후에도 유지). 층별 변화는 침묵 비율과 함께 커진다 (Spearman 0.54, 17층).

**판정 불가 (n 부족 또는 결과가 민감)**
- 같은 스파이크 정확도 이득: −0.096%p (p=0.040) 이지만 런 하나 빼면 p 0.10~0.13, 23 서버 n=3 은 효과 없음, 검출 한계 0.13%p 보다 작음.

## [LIMITATION]

1. **`- vmem` 은 ρ 2e-3 만 n=3 이고 나머지 5개 ρ 는 n=1** 이다. 같은 스파이크 정확도는 곡선 ANCOVA 로 8런을 합쳐 본 것이고, ρ 별 개별 판단은 할 수 없다.
2. 같은 스파이크 정확도 p=0.040 은 다중 비교 (inter 변형 11팔) 보정 전 값이고, 하나 빼기·서버 분할에서 흔들린다. 이 문서는 "vmem 이 정확도를 높인다" 를 확정하지 못한다. 95% CI [−0.188, −0.005] (`- vmem` − ours) 는 "vmem 의 이득이 0.19%p 를 넘는다" 와 "vmem 이 손해다" 를 배제하지만, 런 하나를 빼면 CI 상한이 +0.02 로 0 을 넘으므로 뒤쪽 배제는 약하다.
3. π (층 상대 압력) 는 쏜 뉴런의 평균 스파이크 수 S̄ 가 두 팔에서 같다는 근사, 그리고 R_l 이 L2 노름이라 스파이크가 적은 층에서 기계적으로 커지는 성질을 갖는다. 스파이크 몫을 통제해도 남는 것을 확인했지만, 뉴런별 w 를 직접 재지 않았다 (reg_detail 은 층 평균만).
4. 학습 모드 지표 (reg_detail) 는 마지막 에폭의 배치 평균이고, 원장 스파이크 (평가 모드, best 에폭) 나 npz (테스트셋, best 가중치) 와 프로토콜이 다르다. 셋을 섞어 비교하지 않았다.
5. npz 는 `- vmem` 1런뿐이다. 3f 의 '같은 ρ' 기준은 ours 4개 ρ 의 시드 SD 를 합친 것이라 ρ 마다 SD 가 같다는 가정이 들어간다 (실제 0.13~1.34 로 다르다).
6. 막전위는 재지 않았다. "문턱 근처 침묵 위치가 많은 층에서 w 가 더 낮아진다" 는 코드 경로·층별 Δw·침묵 비율의 상관에서 추론한 것이다.
7. 학습 시간은 다른 시각·다른 부하에서 돈 런들의 중앙값 비교다.
8. intra (`abl_novmem`) 는 5/7 런이 prop 곡선 밖 (외삽) 이고 새 런이 없다. `lw1_novmem` 은 완주 런이 없다. R19·CIFAR-10·T=4 만이다.
9. best 에폭 기준은 310 에폭 최대값이라 시드 잡음을 위로 끌어올린다 (두 팔에 같게 작용하나 n 이 달라 기대치가 미세하게 다르다). 사용자 지시로 다른 기준은 주 결과로 쓰지 않았다.
