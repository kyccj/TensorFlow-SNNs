## 요약

1. **vmem — 같은 ρ·같은 λ 에서 더 많이 쏘게 한다 (스파이크 감소를 누그러뜨린다). 정확도 이득은 경향만.** inter 에서 `- vmem` 은 같은 ρ 에서 스파이크 -5.2% ±1.6 (p=0.0027, inter n=17 / `- vmem` n=6), 같은 λ (학습 평균) 에서 -6.9% ±1.5 (p=8.8e-05). 이유: vmem 이 채널 가중 w 를 낮춘다 — 같은 스파이크에서 평균 w `- vmem` +0.070 ±0.004 (p=2.0e-15), 벌점 크기 R +13.6% ±1.1. intra 에서는 효과가 훨씬 크다: ρ 4e-3 에서 192,092 vs 148,802 (각 n=5, `- vmem` -22.5%, p=5.3e-08). 같은 스파이크 정확도는 `- vmem` 이 inter -0.067 ±0.042 (p=0.11, n=6), intra -0.083 ±0.062 (p=0.2, n=15/7) 로 둘 다 낮은 쪽이나 각각은 유의하지 않다.
2. **final_step — 스파이크를 마지막 스텝으로 몰지 않는다. 바꾸는 것은 '같은 ρ 에서 얼마나 줄이나' 다.** `- final_step` (n=1) 은 같은 ρ 에서 스파이크 -22% (z=-8.0), 같은 λ 에서 -25% (z=-10.0) 로 훨씬 세게 줄이고, 같은 스파이크 정확도는 +0.06 ±0.10 로 차이 없다. 시간축 (npz_t): inter (n=3) 의 마지막 스텝 몫은 baseline (n=3) 보다 +0.55%p (p=0.043) 이고, final_step 이 없는 BPSR (n=3) 은 +1.49%p — 스파이크를 줄이면 앞 스텝이 조금 비는 것은 두 방법 공통이고 inter 쪽이 더 작다. `- final_step` npz 가 없어 요소 단독의 시간 효과는 재지 못했다.
3. **loss-ratio — λ 를 학습 내내 움직여 ρ 를 고정한다; 고정 λ 는 실효 ρ 가 2.1e-3 → 3.5e-3 로 1.6배 흔들린다.** inter ρ 3e-3 (n=4) 의 λ 는 5에폭 1.43e-07 → 200에폭 직전 1.9e-07 (+34%) → 혼합 증강 해제(200에폭) 뒤 1.08e-07. 착지 스파이크의 시드 변동은 inter 가 오히려 크다: 같은 ρ 묶음 합동 CV 2.17% (자유도 17) vs 고정 λ 인 BPSR 1.10% (자유도 8), F 검정 p=0.057. `- loss-ratio` 는 n=1 이라 그 팔 자체의 시드 변동은 **판단 불가**. 같은 스파이크 정확도 +0.01 ±0.10.
4. **1−inversion — 분포 모양을 정반대로 만든다 (n=1 이지만 효과가 시드 산포의 20배 이상).** `- 1- inversion` (w = 채널합/최대) 은 같은 스파이크의 inter 대비 평균 w 0.34 vs 0.81, 층 스파이크 가중 지니 -0.153 (z=-27), 상위 10% 몫 -14.5%p (z=-19) — 큰 채널이 눌려 발화가 고르게 퍼진다. 정확도는 +0.05 ±0.10 로 차이 없다. 채널 수(죽은 채널)는 이 팔 npz 가 없어 못 셌다.
5. **BPSR 대비 — 정확도로는 지금도, 현실적인 n 으로도 우위를 못 보인다. 주장은 구조 지표로 둔다.** 같은 스파이크 Δacc (inter − BPSR): 300~420K +0.042 ±0.038 (p=0.29, n=12/6); BPSR 묶음별로는 412K +0.01, 319K +0.01, 237K -0.06 (p=0.073) — 높은 구간에서만 inter 가 앞서는 경향. +0.042 를 80% 검정력으로 보이려면 팔당 약 51런 (잔차 SD 0.076) 이 필요하고, 조건당 n=4 상한에서 보이는 최소 차는 ±0.15%p 다. 반면 같은 스파이크 (300~420K) 에서 죽은 채널 +48.8 ±9.9/4,736 (p=0.00022), 제거 시 MACs +3.38 ±0.61%p, 이미지당 활성 뉴런 -5.4% ±0.6 는 이미 유의하다 (재계산).
6. **스텝별 정확도 (보너스).** T=4 로 학습한 망을 2스텝에서 자르면 (스파이크 약 27%만 씀) 정확도 변화가 inter +0.01 ±0.03 (n=3), baseline -0.13 ±0.14 (n=3), BPSR -0.06 (n=3); 3스텝 (약 61%) 은 모두 −0.1 이내. inter − baseline 차 +0.15 ±0.08 (p=0.2) — n=3 이라 **아직 판단 불가**.

## 정의

- **ρ**: loss-ratio 목표. 매 에폭 끝에 λ = ρ·L/R 로 다음 에폭 λ 를 정한다 (L = 과제 손실, R = 가중 스파이크 벌점의 원값). 그래서 ρ 가 같으면 "벌점/과제 손실" 비가 같다.
- **λ 평균**: `train.log` 의 `adp_lambda` 를 310 에폭 평균한 값. **λ 마지막**: 310 에폭 값.
- **w (채널 가중)**: inter 의 벌점 가중 `sc_rate` = 1 − (채널 공간합)/(층 안 최대 채널 공간합). 1등 채널 0, 침묵 채널 1. vmem 이 켜지면 한 번도 안 쏜 위치는 0 대신 막전위/문턱 (0~1) 을 채널 합에 더한다. `w 평균` = `reg_detail.csv` 의 `sc_rate_mean` 을 뉴런 수로 가중한 18층 평균 (마지막 에폭, 학습 모드).
- **R**: 18층 `sc_loss` 합 = Σ_층 ‖S∘w‖₂ (S = 이미지별 T 합 스파이크, 배치 평균). 같은 스파이크에서 R 이 크면 스파이크 하나에 걸린 가중이 크다.
- **학습 모드 지표** (`reg_detail`/`reg_neuron_detail`, 마지막 에폭 배치 평균): 층 몫 = 단계 스파이크/전체, 침묵 % = 이미지 하나에서 한 번도 안 쏜 뉴런 비율 (뉴런 수 가중), 지니·상위 10% 몫 = 이미지마다 층 안 뉴런 스파이크의 집중도 (층 스파이크 가중 평균). 원장 스파이크 (평가 모드, 베스트 에폭) 와 다른 자료다.
- **같은 스파이크 Δacc**: inter 완주 런 200~420K 직선 `val acc = a + b·ln(spikes)` 예측값과의 차. ± 는 새 런 하나의 예측 SE (곡선 SE + 잔차 SD). ANCOVA = `y = a + b·ln(x) + c·[팔]`, c 가 오프셋.
- **npz_t**: 테스트 1만 장 1회 추론. `__t` = 스텝별 스파이크 합, `__first_t` = (뉴런, 이미지) 쌍의 최초 발화 스텝 히스토그램, `logits_t` = 각 스텝까지 돌린 출력. 스파이킹 18층.
- 단계: conv1 (1층, 32×32), conv2 (6층, 32×32), conv3 (6층, 16×16), conv4 (4층, 8×8), fc1.

## [LIMITATION]

- **어블레이션 팔은 거의 n=1** 이다 (`- vmem` 은 ρ 6개 각 n=1, 나머지 셋은 각 n=1). 착지 스파이크·분포 지표처럼 효과가 시드 산포의 수 배 이상인 것은 방향을 말할 수 있지만, 정확도 효과 (0.1%p 대) 는 말할 수 없다.
- **뉴런 단위 "vmem 이 더 쏘게 하는 뉴런" 은 재지 못했다.** `ch_novmem`·`ch_nofinal`·`ch_noinv`·`ch_nolr` 와 intra `abl_novmem` 의 npz 가 없다. 1d 는 학습 모드 층 집계 대리 지표다. 재려면 `ch_novmem` 3e-3 s1 (138, 가중치 있음) 과 inter 3e-3 s2 를 같은 추출기로 돌려 baseline 발화율 구간별로 비교해야 한다 (각 약 17분, GPU 1장 — 실행은 승인 사항).
- **final_step 단독의 시간 효과는 측정 안 됨.** 2b 는 inter (final_step 있음) vs baseline·BPSR (없음) 비교라 다른 요소와 섞여 있다. BPSR npz_t 는 n=3.
- **"같은 ρ" 는 요소마다 같은 세기가 아니다.** final_step·inversion 을 끄면 R 의 정의 (가중·합산 위치) 가 바뀐다. vmem 은 R 정의가 같아 같은 ρ 비교가 가장 공정하다. λ 는 loss-ratio 가 정하는 내생 변수라 "같은 λ" 비교는 인과가 아니라 대응 관계다.
- 학습 모드 지표 (`reg_detail`, `reg_neuron_detail`) 는 마지막 에폭의 학습 배치 (증강 포함) 평균이고, 원장 스파이크 (평가, 베스트 에폭) 와 다르다. 지니·상위 10% 는 이미지 안 층별 값의 평균이라 npz 의 데이터셋 전체 지니와 정의가 다르다.
- 1d·4a 는 지표를 15~20개 검정했다. 다중 비교 보정은 하지 않았고, 결론은 z 가 매우 큰 것 (4a) 또는 방향만 (1d) 으로 제한했다.
- vmem 의 정확도 사후 합산 (p=0.04) 은 두 경쟁 범위를 결과를 본 뒤 합친 값이다. 논문 근거로 쓰지 않는다.
- BPSR 비교의 대역·국소 창 (±25%) 은 미리 정한 것이 아니다. 검정력 계산은 정규 근사이고 잔차 SD 를 고정값으로 썼다.
- 스텝별 정확도는 inter·baseline 각 n=3, BPSR n=3 이고, 추론 T 를 줄이는 것은 학습 규제와 다른 질문이다.
  - **2026-10-20 정정:** 6절의 스텝별 정확도는 추론 T 를 줄인 값이 아니라 4스텝을 다 돈 뒤 일찍 읽은 판독이다 (6절 정정 참고).
- R19·CIFAR-10·T=4 한 설정이다. C100·다른 모델의 어블레이션은 없다.
