**정의.** 정확도 = 런 전체 best val acc, spikes = 그 에폭의 s_count (샘플당, 원값). **이 문서의 절대 스파이크 수와 감소율은 모두 원장 s_count 축이다** (npz 총합 축으로 바꾸면 baseline 대비 감소율이 1~2%p 작아진다 — 1.7 절). 평균 행은 완주·비배제 런만. Δacc 의 ± 는 차이의 표준오차 SE = sp·√(1/n + 1/n_base), sp 는 설정별 합동 시드 SD (n≥2 조건들의 조건 내 분산을 합친 값 — 조건마다 SD 를 따로 쓰면 n=3 에서 너무 흔들려서). p 는 그 SE 로 계산한 양측 t 검정 (자유도 = 합동 자유도). 최소 검출 차 = 80% 검정력으로 볼 수 있는 가장 작은 차 ((t₀.₉₇₅+t₀.₈₀)·SE).

**정확도 유지 판정 세 가지 — 어느 것도 "손실이 없다" 를 증명하지 않는다.** (1) **시드 범위 기준 (이번 요청의 정의)**: 조건 평균 정확도 ≥ baseline 시드 최저값. n≥3 조건만 판정, n≤2 는 "판단 불가". "마지막 점" = 통과한 조건 중 스파이크를 가장 많이 줄인 것, "연속" = 그보다 덜 줄인 n≥3 조건이 모두 통과한 범위. 이 기준은 느슨하다 — 평균이 baseline 최저 시드와 같으면 통과하므로 baseline 평균보다 시드 SD 1~1.5배 낮아도 통과한다. 그래서 이 문서는 통과한 마지막 점을 "무손실 한계" 라고 부르지 않는다. (2) **검정 기준 (보정 없는 순차 검정, 참고)**: 스파이크를 덜 줄인 조건부터 보며 Δ<0 이고 p<0.05 인 n≥3 조건이 처음 나오기 전까지. 조건 약 10개를 보정 없이 차례로 검정하므로 첫 검출이 위양성일 수 있고, 검출되지 않음은 "같다" 가 아니다. (3) **±0.2%p 동등성 검정 (TOST, 참고)**: Δ 의 90% 구간이 (−0.2, +0.2) 안에 들어가면 통과. 마진 0.2%p 는 합의된 값이 아니다 (10-14 inter 타당성 분석에서 쓴 값).

**같은 스파이크 비교 (ANCOVA).** acc = a + b·ln(spikes) + c·[팔] + d·[서버 23]; c 가 기준 팔 (ours_inter_ch) 대비 같은 스파이크에서의 정확도 차 (c>0 이면 비교 팔이 더 높음). "같은 정확도 스파이크 비" = exp(−c/b) = 같은 정확도를 내는 데 비교 팔이 쓰는 스파이크 / 기준 팔 (1 미만이면 비교 팔이 덜 씀), 95% 구간은 델타법. 여러 팔을 한 번에 비교한 p 는 Holm 보정 값을 같이 적는다.

표 규약: 열 순서 train loss → train acc → val loss → val acc → spikes. 반복 런은 개별값 뒤 **평균 ±SD (n)** 행. ⚠n<4 = 반복 4회 미만. S30/S1 = 30에폭 스파이크 / 1에폭 스파이크 (0.19 미만은 원장 배제 규칙).

## 4. QKFormer (CIFAR-10 / CIFAR-100, 410에폭, 재측정)

val acc·spikes 는 model_best 체크포인트 fp32 재측정값 (spikes_*.json). train loss (과제 손실)·val loss 는 학습 로그 summary.csv 의 model_best 에폭 값 (AMP 학습 중 평가) — **같은 행에서 val loss 는 로그 값, val acc 는 재측정 값이다.** train acc 는 QKFormer 학습 로그에 기록되지 않음 (mixup/cutmix). ## [LIMITATION]

- **이 문서의 수치는 방법의 우위나 새로움을 뒷받침하지 않는다.** R19 C10 에서 −47~−52% 를 시드 범위 안에서 줄이는 것은 plain L2·BPSR 도 같다. 문헌 대비 위치 (eip-critic 이 든 예: 2026 "The Sparsity Ceiling", ICLR 2024 Shi 등) 는 이 문서에서 확인하지 않았다 — refs-audit 소관.
- **시드 범위 기준이 느슨하고 경계점이 취약하다.** 평균이 baseline 최저 시드와 같으면 통과한다 (예: R19 C10 ours_inter_ch 5.5e-3 은 통과하지만 Δ -0.13 ±0.07, p=0.082, n=3, s2 를 빼면 불통과). 검정 기준은 반대로 "검출되지 않음" 을 "같음" 으로 읽게 만들고, 보정 없는 순차 검정이라 위양성도 있다 (plain L2 1e-7). ±0.2%p 동등성 검정 (TOST) 을 참고로 붙였지만 마진은 합의된 값이 아니다. 어느 기준을 논문에 쓸지는 정하지 않았다.
- **시드 범위 마지막 점으로 방법 간 우열을 말할 수 없다.** R19 C10·C100 에서 plain L2·BPSR 의 시드 범위 마지막 점이 ours_inter_ch 와 같거나 더 크고, 같은 스파이크 ANCOVA 는 모두 0 을 포함한다. 그렇다고 "우리 방법이 못하다" 의 근거도 아니다 — 현재 n 으로는 약 0.1~0.2%p (스파이크로는 ±20% 안팎) 보다 작은 차이를 볼 수 없다.
- **스파이크 축 (s_count 대 npz).** 절대 스파이크 수와 감소율은 원장 s_count 축이다. npz 총합은 s_count 보다 런마다 19K~28K 많고 (비 1.05~1.13, 스파이크가 적을수록 큼), 그래서 baseline 대비 감소율이 npz 축에서 1~2%p 작다 (예: ours_inter_ch 3e-3 -30.1% → -28.4%, 5.5e-3 -47.1% → -45.3%, plain L2 2.5e-7 -49.7% → -47.8%, BPSR 3e-10 -51.5% → -49.8%). 불일치 원인은 미해결이다. 같은 s_count 에서 측정한 팔 사이의 비 차는 약 0.3% (95% 구간으로도 0.6% 안쪽) 라 같은 스파이크 비교에는 영향이 없지만, ablation 4팔은 npz 가 없어 확인하지 못했다.
- ANCOVA 는 ln(spikes) 직선 + 서버 항 + 팔 공통 오프셋을 가정한다. - final_step 은 두 ρ 의 오프셋이 달라 (p=0.012) 이 가정이 깨진다. 구간 경계에 따라 포함 런이 바뀌며, C10 200–420K 는 이전 분석과 맞춘 것, C100 220–420K 는 같은 날 정한 것이고 둘 다 사전 등록된 구간이 아니다. ablation 4팔은 Holm 보정을 같이 적었다.
- R19 C10 ours_inter_ch 1.5e-3·2e-3·4e-3 (n=3)·5e-3 (n=1) 은 진행 중인 런이 끝나면 평균이 바뀐다. 이 문서의 n 은 10-19 16:38 고정 사본 기준.
- VGGSNN DVS 는 시드 SD 가 커서 n=4 대 4 로도 약 1%p 보다 작은 차이를 볼 수 없고, 시드 범위 판정은 이미지 1장 미만 차로 갈린다. 첫 프레임 입력은 시간 정보를 쓰지 않는 정적 입력이다.
- QKFormer 정확도는 fp32 재측정값이고 학습 로그 최고값과 전체 범위 -0.47~+0.04%p 다르다 (n=28 런, 양 끝 모두 baseline 런; 조건별 평균은 4절). 재측정 차이의 원인은 확인되지 않았다. baseline s44 (23) 는 재측정이 없어 뺐다. QK val loss 는 재측정이 아니라 학습 중 평가 값이다. QK C100 6e-3 의 판정은 측정 축 (재측정/로그) 과 검정 방식에 따라 달라진다.
- SDTv3·Speck 은 조건당 학습 1회다. 칩 측정 반복 (r1/r2) 은 측정 잡음만 줄이고 학습 시드 편차는 반영하지 않는다. Speck baseline 쪽은 서로 다른 체크포인트 둘을 합쳤다. Speck 수치는 decisions.md 에서 옮긴 것이고 153 서버의 원본 측정 파일은 이 분석에서 다시 읽지 않았다. SDTv3 대조 런의 "공식 출발점 대비" 차는 평가 경로가 다른 두 값의 비교다.
- 정확도는 val=test 에서 고른 best 에폭이라 모든 팔이 위로 부풀려진다 (이전 분석에서 R19 C10 약 0.15~0.18%p, 팔 간 같음).
- R19 train loss 는 Keras 로그의 loss (규제항 포함 여부는 이 문서에서 확인하지 않음), QK·SDT train loss 는 과제 손실이다. 설정 간 train loss 를 비교하지 말 것.
