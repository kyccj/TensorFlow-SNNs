## 요약

1. **같은 스파이크 정확도 — 판단 불가 (n=1).** `- loss-ratio` 96.70% @ 342,306 vs `ours_inter_ch` 곡선 (n=27): 오프셋 d = **+0.006%p** [95% CI -0.215, +0.228], p=0.953 (선형+서버, nofinal 분석과 같은 모형). 같은 착지의 `ours_inter_ch` 3e-3 (n=4, 342,075) 대비 -0.020%p [-0.28, +0.24]. 교차 확인 두 쌍도 0 근처 — intra (끈 팔 n=3) -0.050%p [-0.21, +0.12], plain L2 (켠 팔 n=5 − 끈 팔) -0.028%p [-0.17, +0.12]. 어느 쌍에서도 약 ±0.2%p 보다 큰 효과는 없고, 그보다 작은 효과는 볼 수 없다. baseline (n=6) 대비 -0.028%p [-0.28, +0.23] · 스파이크 -30.0%.
2. **λ 를 과제 손실에 묶는다.** loss-ratio 아래 λ 는 혼합 증강 구간에 오르고 (에폭 5→199 +43%, 범위 +25~+91%, n=28) 해제 때 -38% 떨어진다 (n=28, 범위 -38~-36%). 떨어지는 이유는 L 이 -40% (R 은 -2%). 고정 λ 는 같은 L 하락을 그대로 받아 **실효 ρ 가 2.16e-3 → 3.51e-3 (×1.63)** 로 오른다 (intra 고정 λ 3런 ×1.77/1.72/1.66).
3. **같은 착지, 다른 경로.** `- loss-ratio` 는 `ours_inter_ch` ρ ≈ 2.78e-3 (95% [2.25, 3.41]e-3) 와 같은 곳에 착지한다. 그러나 혼합 증강 구간에는 실효 ρ 가 낮아 같은 착지의 `ours_inter_ch` 3e-3 (n=4) 보다 스파이크가 많고 (에폭 100 +6.0%, 199 +10.0%, z=+4.9), 해제 뒤 따라잡아 309 에서 +0.9% (z=+0.4). 해제 반응 -21.8% vs `ours_inter_ch` -16.9% (n=28; 착지 보정 차 -0.081 ln, p=7.3e-05 — n=1 이라 기준 팔 잔차 SD 를 가정). 같은 방향이 교차 쌍에서 n 을 갖고 보인다: intra 고정 λ -30.5% (n=3) vs -16.2% (n=15), 차 -0.183 ln (p=2.2e-12); plain L2 고정 λ (n=22) − loss-ratio (n=5) -0.084 ln (p=6.1e-09). 규제 없는 baseline 도 해제 뒤 -9.7% (n=6) 줄어든다.
4. **착지는 해제 뒤 λ 에 시간 비율보다 큰 무게를 둔다.** ln λ_혼합 = (1−α)·ln λ_해제전 + α·ln λ_해제뒤 로 놓고 고정 λ 와 loss-ratio 의 착지가 맞는 α: inter **0.60** (n=1), intra **0.70** (n=3, 런별 0.73/0.64/0.73), plain L2 **0.67** (n=5, 부트스트랩 95% [0.38, 0.86]). 해제 뒤 구간의 시간 비율은 0.36 — 착지 무게는 그 1.7~2.0배 (런별 α 대 0.36: intra p=0.007, plain L2 p=0.033). loss-ratio 는 무거운 구간에서 λ 를 38% 내리므로, 같은 평균 λ 라면 고정 λ 보다 덜 줄인다.
5. **ρ 눈금이 데이터셋 사이에 옮겨진다 (C10 → C100, 같은 R19).** 같은 손잡이에서 각 데이터셋 baseline 대비 스파이크 비의 C100 차 (ln): loss-ratio 방법 `ours_inter_ch` **-0.002** [-0.025, +0.021] (n=10/9), `ours_intra_ch` +0.025 [-0.020, +0.070] (n=9/3); 고정 λ 방법 `plain L2` **+0.358** [+0.330, +0.385] (n=16/8), BPSR +0.335 [+0.303, +0.366] (n=6/7). 예: ρ 3e-3 → C10 -30.1% (n=4) / C100 -30.8% (n=3); plain L2 λ 2.5e-7 → C10 -49.7% (n=5) / C100 -30.0% (n=1). 기전: C100 의 과제 손실 L 이 1.9~2.2배라 loss-ratio 가 λ 를 2.1~2.4배로 올린다 (2d 표). 단 이것은 벌점 모양이 다른 방법 사이의 비교이고, 같은 ρ 의 정확도 손실은 데이터셋마다 다르다 (ρ 3e-3: C10 -0.01, C100 -0.27%p).
6. **착지 시드 변동 — loss-ratio 가 줄이지 않는다.** 같은 손잡이 묶음 ln 스파이크 잔차 SD: `ours_inter_ch` 2.24% (자유도 16), `ours_intra_ch` 2.17% (11) vs 고정 λ `plain L2` 1.75% (15), BPSR 0.98% (7); baseline 1.87% (4). loss-ratio 합동 / 고정 λ 합동 SD 비 1.43 (F=2.04, p=0.092); BPSR 만 따로 보면 p=0.035, plain L2 와는 p=0.349. 되먹임 부호가 이 방향과 맞다: 같은 ρ 에서 더 쏘는 시드는 R 이 커서 λ 가 작다 (묶음 안 d ln λ_해제뒤 / d ln S = -0.37 ±0.15, p=0.024, n=25) → 선형 근사로 시드 차이를 ×1.11 [1.02, 1.23] 키운다. `- loss-ratio` 자체의 시드 변동은 n=1 이라 **판단 불가**.
7. **같은 스파이크에서 분포.** inter: 지표 17개 모두 `ours_inter_ch` 곡선 시드 산포 안 (|z| 최대 2.4, n=1; 지표 수를 생각하면 기대 범위). intra: 고정 λ 3런이 같은 스파이크에서 지니 -0.019 ±0.003, 상위 10% 몫 -1.49 ±0.21%p (p=7.2e-06, 4.3e-06) — 발화가 덜 몰린다. inter 의 같은 지표도 같은 방향 (z=-2.2, -1.6), plain L2 는 차이 없음 (+0.003, p=0.316). 원인은 확인하지 않았다 (가설: 감소가 해제 뒤로 몰리는 경로 차이). 채널 단위 (죽은 채널·활성 뉴런) 는 npz 가 없어 못 쟀다.
8. **학습 시간 차이 없음**: 에폭당 중앙값 `- loss-ratio` 348s vs `ours_inter_ch` (23) 349s (n=14), 차 -0.6s [-3.9, +2.8]. 제어기는 에폭 끝 스칼라 한 번이다.

**판정**: loss-ratio 가 바꾸는 것은 **λ 의 시간·데이터셋 배분** 이다. (i) λ 를 과제 손실에 묶어, 혼합 증강 해제처럼 L 이 바뀔 때 벌점/과제 손실 비를 일정하게 둔다 — 고정 λ 는 해제 뒤 실효 ρ 가 ×1.63~1.77 로 오르고 스파이크가 그때 몰아서 준다. (ii) 같은 이유로 ρ 가 C10·C100 사이에서 같은 스파이크 감소를 주는 눈금이 된다 (고정 λ 방법은 같은 λ 에서 C100 이 ln 0.33~0.36 덜 줄인다). 정확도 (n=1, 교차 쌍 포함 ±0.2%p 안 판단 불가), 착지 재현성 (줄이지 않음, 되먹임은 오히려 키우는 부호) 에는 이득이 보이지 않는다. 논문에 쓸 수 있는 것: "loss-ratio 는 정확도 기여가 아니라 세기 눈금의 이식성 (같은 모델, 다른 데이터셋) 과 학습 중 L 변화에 대한 자동 보정을 준다" — 단 데이터셋 이식성은 다른 벌점 방법과의 비교 (같은 벌점의 고정 λ C100 런 없음) 라는 단서를 단다. "정확도를 올린다", "착지를 안정시킨다" 는 쓸 수 없다.

### 2c. 착지를 정하는 구간의 무게 α

### 3f. loss-ratio 되먹임의 부호

같은 ρ 묶음 안에서 시드별 ln λ 를 ln 착지 스파이크에 회귀 (묶음 고정효과).

| 팔 | 묶음 수 | n | d ln λ_해제뒤 / d ln S | 95% CI | p | d ln λ_마지막10 / d ln S | d ln R_마지막 / d ln S |
|---|---|---|---|---|---|---|---|
| ours_inter_ch | 8 | 25 | **-0.37** ±0.15 | [-0.68, -0.06] | 0.024 | -0.57 ±0.19 (p=0.009) | +0.60 ±0.23 |
| ours_intra_ch | 3 | 14 | **-0.14** ±0.19 | [-0.57, +0.29] | 0.478 | -0.30 ±0.13 (p=0.035) | +0.52 ±0.04 |

- 음의 기울기 = 같은 ρ 에서 더 쏘는 시드일수록 R 이 커서 λ = ρL/R 가 작아진다 → 그 시드는 덜 눌려 더 쏜 채로 남는다 (시드 차이를 키우는 고리). 고정 λ 에는 이 고리가 없다.
- 크기 (선형 근사): 고정 λ 에서 시드 섭동 ε 가 ln S 를 ε 만큼 옮긴다면 loss-ratio 아래서는 ε / (1 + k·s) (k = −d ln S / d ln λ, s = 위 기울기). `ours_inter_ch`: k = 0.280 (국소 ln S ~ ln λ_해제뒤), s = -0.37 → **×1.11** (s 의 95% 끝에서 ×1.02~×1.23). `ours_intra_ch`: s 가 유의하지 않음 (p=0.478), ×1.07.
- 예측 배율 ×1.11 는 관측 SD 비 (loss-ratio 합동 / 고정 λ 합동 1.43, p=0.092) 와 방향이 같고 크기는 작다. 요소 단독의 효과는 `- loss-ratio` 반복 런으로만 확인된다.

## 5. 판정 가능 / 불가 / 필요한 측정

**판정 가능**

- loss-ratio 는 λ 를 L 에 묶는다: 혼합 증강 구간 +43% (n=28, 전 런 같은 방향), 해제 때 -38% (원인 L -40%). 실현 비는 ρ 의 ±0.1% 안.
- 고정 λ 의 실효 ρ 는 해제 뒤 ×1.63 (inter n=1), ×1.77/1.72/1.66 (intra n=3). 정의상 L 하락에서 나오므로 n 이 작아도 결정적이다.
- 고정 λ 는 해제 뒤에 더 줄인다: plain L2 쌍 (n=22/5) p=6.1e-09, intra (n=3/15) p=2.2e-12, inter (n=1) 같은 방향.
- 착지는 해제 뒤 λ 에 시간 비율 (0.36) 보다 큰 무게 (α 0.60~0.70) 를 둔다: intra p=0.007 (n=3), plain L2 p=0.033 (n=5).
- 같은 ρ 는 C10·C100 에서 같은 스파이크 감소를 준다 (inter c=-0.002, 95% ±0.023); 같은 λ 는 아니다 (plain L2 c=+0.36, BPSR +0.33). 단 방법 간 비교.
- 학습 비용 차이 없음 (inter 차 -0.6s).

**판정 불가**

- 같은 스파이크 정확도: `- loss-ratio` n=1, 95% 구간 [-0.21, +0.23]%p. "기여한다/안 한다" 둘 다 말할 수 없다. n=3 이 돼도 최소 검출 차 0.21%p, n=4 0.19%p — 0.1%p 대 차이는 조건당 n=4 상한으로 못 본다.
- `- loss-ratio` 자체의 착지 시드 변동 (요소 단독 재현성): n=1. 3e·3f 는 벌점 모양이 다른 방법 사이 비교와 되먹임 부호로 본 간접 근거다.
- 같은 스파이크 분포 차 (지니·상위 10%) 가 inter 에서도 있는지: n=1 (z −2.2·−1.6). intra 에서만 유의.
- 채널 단위 구조 (죽은 채널·활성 뉴런): npz 없음.
- 같은 벌점에서 λ 제어만 바꿨을 때의 데이터셋 이식성: C100 고정 λ inter 런 없음.

## [LIMITATION]

1. 주 비교 팔 `- loss-ratio` 는 **n=1** 이다. 정확도·시드 변동·구조 지표 모두 이 런 하나가 `ours_inter_ch` 시드 산포 안에 드는지만 말한다. "loss-ratio 를 빼도 같다" 는 결론이 아니다 — 95% 구간 밖의 큰 차이만 배제된다. n=1 의 p (3d inter 행 등) 는 그 런의 시드 산포를 기준 팔과 같다고 가정한다.
2. 교차 확인 팔은 손잡이당 n=1 이다 (`abl_nolr` 3개, `l2_lr` 5개). 여러 손잡이를 묶어 n 을 만든 것이라 "손잡이에 따라 효과가 다르다" 는 가능성 (plain L2 α 가 ρ 와 함께 커짐) 을 배제하지 못한다. 모두 138 서버다.
3. 데이터셋 이식성 (2d) 과 착지 시드 변동 (3e·3f) 은 벌점 모양이 다른 방법 사이의 비교다. loss-ratio 단독 효과는 λ ∝ L 기전 (로그로 확인) 과 되먹임 부호로 뒷받침할 뿐, 같은 벌점에서 λ 제어만 바꾼 C100 런·반복 런이 없어 직접 검증하지 않았다. 되먹임 배율은 선형 근사다. C100 값은 이 스크립트가 로그에서 다시 읽은 best 에폭 값 (원장과 일치) 이다.
4. "같은 λ" 비교의 λ 는 loss-ratio 가 정하는 내생 변수다. ln S ~ ln λ 직선은 ρ 를 바꿔 얻은 대응 관계이지 λ 를 직접 조작한 인과가 아니다 (2b·2c 의 inter·intra). plain L2 쌍만 고정 λ 를 직접 조작한 용량-반응선이다. α 의 2구간 혼합 모형은 단순화이고 구간 안 λ 변화는 평균으로 뭉갰다.
5. 혼합 증강 해제와 학습률 cosine 감쇠 후반이 겹친다 (해제 = 에폭 200/310). "해제" 와 "후반 학습률" 효과는 이 설계로 가를 수 없다 — 두 팔에 같게 작용한다는 가정만 쓴다. α 가 큰 것도 "최근 압력이 남는다" 와 "학습률이 낮아 늦은 변화가 지워지지 않는다" 를 구별하지 못한다.
6. 구조 지표는 학습 모드 배치 평균 (reg_neuron_detail) 이고 평가 모드 npz 와 정의가 다르다. 침묵 뉴런 % 는 배치 단위라 이미지·데이터셋 단위 침묵과 다르다. inter 의 17개 지표 z 는 다중 비교 보정 없이 보고했다.
7. best 에폭 기준은 310 에폭 최대값 선택이라 시드 잡음을 위로 끌어올린다. spikes 는 s_count 원값이고 npz 총합과의 11% 불일치 (09-15 보류) 는 해소되지 않았다.
8. 학습 시간은 서버의 동시 실행 런 수에 좌우된다. 혼잡도를 통제하지 않았다.
