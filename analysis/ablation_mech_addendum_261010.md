## 요약

1. **vmem 은 같은 ρ 에서 총 스파이크를 거의 바꾸지 않고, 발화율이 낮은 뉴런을 살려 둔다.** ρ 3e-3 에서 `- vmem` (n=1) 의 스파이크는 inter (원장 n=4) 대비 -1.2% (z=-0.5) 로 시드 산포 안이다. 대신 테스트셋 전체에서 한 번도 안 쏜 뉴런이 20.85% vs 19.42 ±0.13% (inter npz n=3, z=+9.6, 약 20,590개) 로 늘고, 늘어난 침묵은 **잔차 블록 안쪽 conv1 층** (conv2 단계 +20,864개, z=+4.3) 과 baseline 순위 발화율 0~5% 구간에 몰린다. 5~20%·20%+ 구간은 차이가 없다.
2. **'문턱 근처 뉴런을 살린다' 는 '발화율 낮은 뉴런' 으로 읽으면 맞고, '중간 발화율 뉴런' 이나 '입력층' 으로 읽으면 틀린다.** 차이가 큰 곳은 0~1%·1~5% 구간 (침묵 몫 +5.4·+2.4%p, z≈3.5~3.7, 자유도 2 라 p≈0.07) 이고, stem conv1 은 z=+2.1 로 불분명하다. 채널 단위 (죽은 채널 654 vs 638, 지니, 상위 10% 몫) 는 구분되지 않는다.
3. **final_step 을 빼면 스파이크가 뒤 스텝으로 조금 밀린다 — 방향만.** `- final_step` (n=1, 310,732/이미지) 의 t4 몫은 40.35% 로 inter 1.5e-3 (n=3, 430,731) 보다 +1.51%p 높지만, 그중 약 1.1%p 는 스파이크 수준 차로 예상되는 몫이다. 추세 대비 잔차는 +0.41 ±0.38%p (z=+1.1) 로 **판단 불가**, 단계별로 conv1 의 t4 몫만 +1.03%p (z=+6.2) 로 분명하다.
4. **스텝별 정확도는 n=1 이라 판단 불가.** `- final_step` T'=2/3/4 = 96.60 / 96.57 / 96.68. ablation_mech_261010.md 에서 바뀌는 문장은 6곳 (아래 3절). 핵심: 1d 의 '입력층 쪽 문턱 근처 뉴런' → '블록 안쪽 conv1 층의 저발화 뉴런', 2b 의 'final_step 고유 효과로 볼 근거 없음' → '빼면 조금 뒤로 밀린다 (방향만)', 요약 1 의 '같은 ρ 에서 5~6% 더 쏜다' 에 'ρ 3e-3 에서는 −1.2%' 단서.

## 정의

- **발화율** = 뉴런 하나의 테스트셋 총 스파이크 / (1만 장 × T=4). 0~1 사이.
- **침묵 뉴런** = 테스트 1만 장 전체에서 한 번도 안 쏜 뉴런 (원 문서 1d 의 "이미지당 침묵" 과 다르다).
- **이미지당 활성 뉴런 %** = Σ(그 뉴런이 쏜 이미지 수) / (1만 × 전체 뉴런 1,442,048).
- **순위 대응**: 층마다 발화율을 오름차순 정렬해 같은 순위 k 끼리 비교 (분위수 비교). **순위 구간** = baseline s11~13 의 같은 순위 발화율 평균이 속한 구간 (0, 0~1%, 1~5%, 5~20%, 20%+).
- **z (n=1 대 inter)**: (n=1 값 − inter 평균) / (inter 시드 SD·√(1+1/n)). inter 시드 n=3 이라 자유도 2 — |z|≥4.3 이어야 p<0.05 (t 분포). p 는 이 t 분포로 계산.
- **채널**: conv 층의 채널 하나 = 공간 위치 전체 합. fc1 은 뉴런 하나가 채널. 18층 4,736 채널. **죽은 채널** = 테스트셋 합 0. **지니**·**상위 10% 몫** = 층 안 채널 합의 집중도를 층 스파이크로 가중 평균.
- **층 종류**: stem = conv1_conv (1층), 블록 안쪽 = 각 잔차 블록의 첫 conv (`*_conv1_n`, 8층), 블록 출력 = `*_out_n` (8층), fc1.
- **스텝 몫** = 스텝 t 스파이크 / 4스텝 합. **최초 발화 스텝** = (뉴런, 이미지) 쌍이 처음 쏜 스텝 (쏜 쌍만). **T'=t 정확도** = `logits_t[:, t]` 의 argmax 정확도 (원 문서 6절과 같은 정의).

## [LIMITATION]

- **`- vmem`·`- final_step` 은 각 n=1** 이다. z 는 inter 시드 n=3 의 산포 (자유도 2) 기준이라 |z|<4.3 은 p≥0.05 다. 1절 결론은 합계 지표 (침묵 뉴런 %, 블록 안쪽 층 스파이크) 에만 기대고, 구간·층별 개별 값은 방향으로만 쓴다.
- inter 3e-3 s4 의 npz 가 없어 1절 inter 는 n=3 (s1~s3) 이다. 원장 스파이크 비교만 n=4.
- **뉴런 짝짓기는 순위 대응** 이다. "같은 뉴런이 더 쏜다" 가 아니라 "같은 분위의 뉴런이 더 쏜다" 다. 기능적 정렬 (클래스 반응으로 채널 매칭) 은 하지 않았다.
- **막전위는 측정하지 않았다.** "문턱 근처" 는 발화율이 낮다는 것으로 대신했다. 침묵 뉴런의 막전위 분포를 보려면 추출기에 막전위 저장을 더해야 한다 (코드 변경 — eip-code 몫).
- 2절은 같은 스파이크 짝이 아니다 (311K vs 431K npz). 추세는 두 묶음 평균을 잇는 직선의 외삽 (간격의 2배) 이고, 검사점 `- vmem` 에서도 |z|≈3 잔차가 나와 SE 가 작게 잡혀 있다. 크기는 말하지 않고 방향만 말한다. 같은 스파이크로 보려면 inter ρ 를 `- final_step` 288K 근처로 맞춘 런 (예: inter 5e-3 계열) 의 npz_t 가 필요하다.
- 2절의 검사점 `- vmem` 도 vmem 이 빠진 팔이라 "final_step 켜짐" 의 순수 대조가 아니다.
- 1b 의 층별 표는 18층 × 2지표를 검정했다. 다중 비교 보정은 하지 않았고, 개별 층 결과는 결론에 쓰지 않았다.
- npz 는 테스트셋 1회 추론이고 원장 스파이크 (검증, 베스트 에폭) 보다 5~8% 높다. 원 문서의 학습 모드 지표와도 정의가 다르다.
- R19·CIFAR-10·T=4, inter (ours_inter_ch) 한 방법만이다. intra 의 `- vmem` (원 문서: 같은 ρ −22.5%) 은 npz 가 없어 같은 분석을 못 했다.
